# 사장님 절세 노트 — 카드뉴스 모션 영상 (20초)

카드 8장이 2.5초마다 옆으로 넘어가는 릴스·쇼츠용 영상. 원본 카드뉴스 디자인(남색·금색 / 크림·빨강)을 그대로 따름.

1. 사장님, 보험료 세금공제 받고 계신가요?
2. 결론: 보장성보험료 세액공제는 근로소득자만 (소득세법 제59조의4)
3. 구분 기준: 환급금 ≤ 낸 보험료 → 보장성 / > → 저축성
4. 12% · 연 100만 원 한도 · 최대 12만 원 (지방세 포함 13.2만 원) — 숫자가 올라가는 효과
5. 소득 유형별 O/X 체크
6. 한눈에 정리: 보장성(낼 때 공제, 직장인만) / 저축성(받을 때 비과세) / 연금저축(사장님도 가능)
7. 저축성 비과세가 깨지는 3가지
8. "어떻게 들었냐"가 중요 → DM으로 "점검"
