# 인스타 릴스 캡션 — 사장님 절세 노트

## A안 · 기본형 (추천, 저장 유도)
```
사장님, 보험료 내시면서 "연말정산 때 돌려받겠지" 생각하셨나요? 🤔

결론부터 말씀드리면,
보장성보험료 세액공제는 근로소득이 있는 분만 받습니다.
사업소득만 있는 개인사업자·프리랜서는 해당이 안 됩니다.

✅ 보장성보험 → 낼 때 세액공제 (12%, 연 100만 원 한도) · 직장인만
✅ 저축성보험 → 받을 때 비과세 · 요건 지키면 누구나
✅ 연금저축 → 낼 때 세액공제 (연 600만 원 한도) · 사장님도 가능

⚠️ 저축성보험 비과세가 날아가는 3가지
· 10년 전에 해지할 때
· 계약자를 바꿀 때 (바꾼 날부터 10년 다시 시작될 수 있음)
· 기본보험료를 1배 넘게 늘릴 때

보험은 "들었다"보다 "어떻게 들었냐"가 중요합니다.
지금 보험증권 꺼내서 보장성인지 저축성인지,
계약자가 누구인지부터 확인해 보세요.

📌 연말정산 전에 다시 보려면 저장
📩 내 보험 세금 점검이 필요하면 DM으로 "점검"

조홍철 본부장 | 인카금융서비스 블레스본부
※ 2026년 10월 현행 세법 기준 일반 정보이며 특정 상품 권유가 아닙니다. 실제 세액은 개인별로 다르니 세무사와 확인하세요.

#사장님절세 #개인사업자절세 #보험료세액공제 #연금저축 #저축성보험비과세 #연말정산 #블레스본부
```

```

정답: 보장성보험은 ❌, 연금저축은 ⭕

사장님이 챙겨야 할 건
연금저축 연 600만 원 한도 → 최대 99만 원 절세 (16.5% 적용 시)

30초 영상으로 한 번에 정리했습니다.
📌 저장해 두고, 점검이 필요하면 DM으로 "점검"

※ 2026년 현행 세법 기준 일반 정보이며 특정 상품 권유가 아닙니다.

```
