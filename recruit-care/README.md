# 요양보호사 리크루팅 영상 (20초, 스카우트 톤)

간호사·간호조무사·치위생사 편과 같은 **스카우트 시리즈**입니다. "당신의 경력이 필요합니다 → 경력으로 인정합니다"를 전달합니다.

- **문구 출처**: 블로그 「요양보호사가 보험설계사로 전환하면 어떤 점이 좋을까?」 (돌봄 경험 = 상담 역량, 건강·질병 이해 → 실손·간병비·치매보험 상담, 공감 능력이 가장 강력한 무기)
- **음악**: 120 BPM, 정확히 20초, 처음부터 밝게 → 8초에 터짐 (직접 합성, 상업적 사용 가능)
- **비율**: 세로 9:16 (주력), 가로 16:9
- **주의**: 수입 약속·투잡·매일 DB 문구 없음

## 스토리보드

| 시간 | 장면 | 내용 |
|---|---|---|
| 0~4초 | WANTED | WANTED 글자 배경 + 구인 카드 · 하트 배지 · **돌봄을 아는 사람** |
| 4~8초 | 필요한 이유 | **요양보호사님, 당신의 경력이 필요합니다** · "간병·치매보험 상담은 돌봄을 아는 사람이 제일 잘하니까" |
| 8~11초 | 경력 인정 | 돌봄 현장에서 보낸 1 → 3 → 5 → **10** YEARS · 그 시간, 그대로 **경력으로 인정합니다** |
| 11~14초 | 경력 매칭 | 돌봄 경험 → 상담 역량 / 건강·질병 이해 → 간병·치매보험 상담 / 공감 능력 → 고객 신뢰 |
| 14~16초 | 지원 | 돌봄 경력 그대로 인정 · 1:1 전담 멘토링 · AI 자동화 도구 |
| 16~20초 | 행동 | **요양보호사 경력자 상담 받습니다** · @incarvip_bless DM 주세요 |
