# CEO 보고서 완료 기준

CEO는 바쁘다. **30초 안에 결론과 내가 결정할 것**을 알 수 있어야 한다.

## 반드시 이 순서로
1. **결론 한 줄** (헤드라인) — 무엇을 했고 결과가 무엇인지
2. **CEO가 결정할 것** — 승인/선택이 필요한 것 1개. 없으면 "없음"
3. **핵심 요약 3줄** — 딱 3개
4. **근거** — 요약을 뒷받침하는 사실·데이터 (항목당 2~3문장)
5. **리스크와 대응** — 무엇이 잘못될 수 있고 어떻게 막는지
6. **다음 행동** — 담당자 / 할 일 / 마감일 표

## 체크리스트 (비서실장 검수 항목)
- [ ] 결론 한 줄이 맨 위에 있다
- [ ] CEO가 결정할 것이 명확하다
- [ ] 핵심 요약이 정확히 3개다
- [ ] 근거 없는 수치·주장이 없다
- [ ] 다음 행동에 담당자와 마감일이 모두 있다

## 금지
- 직원 토론 내용을 그대로 붙여넣기
- 표 없이 긴 문단 나열
- "~할 수 있을 것으로 보입니다" 같은 흐릿한 문장
