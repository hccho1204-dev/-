# 완료 기준 (Definition of Done)

영상의 마지막 교훈: **"이 정도는 알아서 잘하겠지"는 통하지 않는다.**
직원 구조(토론·검수·승인)를 만들어도, 결과물의 기준을 안 주면 형편없는 보고서가 나온다.

그래서 이 시스템은:

1. **일하는 직원**은 작업 전에 해당 완료 기준을 읽고 작업한다.
2. **비서실장**은 이 기준의 체크리스트로만 검수한다. (기준에 없는 걸로 반려하지 않는다)
3. **CEO 보고서**는 AI가 마음대로 꾸미지 않고, `templates/ceo-report.html` 고정 양식에 내용만 채운다.

## 파일 구성

| 파일 | 언제 쓰나 |
|---|---|
| `threads-post.md` | 쓰레드 게시 업무 |
| `analysis.md` | 성과 분석·다음 콘텐츠 제안 업무 |
| `general.md` | 그 외 모든 업무 |
| `ceo-report.md` | 모든 업무의 최종 보고서 (항상 함께 적용) |
| `templates/ceo-report.html` | 최종 보고서 고정 디자인 |

## 기준 고치는 법

관리 화면 → **완료 기준** 탭에서 바로 수정하고 저장하면 다음 업무부터 적용됩니다.
`- [ ]` 로 시작하는 줄이 비서실장의 검수 체크리스트 항목이 됩니다.
마음에 드는 보고서가 있으면 그 특징을 여기에 문장으로 적어 두세요. 그게 "레퍼런스"입니다.
