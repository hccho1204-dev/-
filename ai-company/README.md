> 한줄요약: AI 직원 10명이 토론·배정·수행·검수하고 쓰레드까지 게시하는 "작은 AI 회사"의 설치법과 활용법이다.

# 🏢 AI 회사 (블레스 AI 컴퍼니)

나는 **비서실장 한 명에게만 지시**합니다. 나머지는 AI 직원들이 알아서 합니다.

```
👑 CEO(나) 지시
   ↓
🧭 비서실장이 토론 소집 → 관련 직원이 먼저 깊게 말하고, 나머지는 보고 짧게 반응
   ↓
📌 비서실장이 방향 정리 + 담당자별 업무 배정
   ↓
🛠 직원들이 작업 → 작업 폴더에 문서 저장 (맨 윗줄에 "한줄요약")
   ↓
🧭 비서실장이 "완료 기준"으로 검수 ──🔴 반려 → 👑 내가 보강 지시 → 다시 토론·수정·검수
   ↓ 🟢 통과
♟️ 전략실장 한수합(GPT)이 독립 검토 → 문제 제기 + 권고 (승인권 없음, 의견만)
   ↓
🧭 비서실장이 권고 반영 여부 판단 → 최종 보고서(고정 양식)
   ↓
👑 내가 승인 (또는 위험 낮은 일은 비서실장 전결)
   ↓
🚀 쓰레드에 실제 게시
```

## 1. 조직도

| 이름 | 직책 | 하는 일 | 모델 |
|---|---|---|---|
| 🧭 비서진 | 비서실장 | 토론 소집, 업무 배정, 검수·반려·승인 | 클로드 (강한 모델) |
| 🎬 조회수 | 콘텐츠 담당 | 기획, 첫 3초 훅 | 클로드 (절약 모델) |
| 📣 조팔로 | SNS 운영 매니저 | 쓰레드 운영, 게시 실행 | 〃 |
| 🎨 조영미 | 디자인 담당 | 썸네일, 첫 장면, 보고서 디자인 | 〃 |
| ✍️ 문체리 | 브랜드·문체 담당 | 게시 문구, 톤, 금지 표현 | 〃 |
| 🛠️ 안버그 | 개발 담당 | API, 영상 업로드 방식 | 〃 |
| 💰 마진율 | 커머스 담당 | 수익화 | 〃 |
| 📊 전환율 | 데이터 분석 담당 | 성과 지표, 분석 | 〃 |
| 🔎 김근거 | 리서치·컴플라이언스 | 사실 확인, 저작권, 규정 | 〃 |
| ♟️ 한수합 | 전략실장 | 독립 검토, 권고 (**승인권 없음**) | GPT |

> 비싼 모델은 **검수하는 비서실장**에만, 실무 직원은 **저렴한 모델**로 돌려 비용을 줄입니다.
> 전략실장만 GPT인 이유: 같은 모델끼리 검토하면 **함께 놓치는 부분**이 생기기 때문입니다.

## 2. 설치 (처음 한 번만, 약 10분)

### ① Node.js 설치 — 이 프로그램을 돌리는 엔진
1. https://nodejs.org 접속
2. 왼쪽 초록색 **LTS** 버튼을 눌러 다운로드
3. 받은 파일을 실행하고 **다음 → 다음 → 설치** (옵션은 건드리지 않아도 됩니다)

### ② 이 폴더를 내 컴퓨터로 가져오기
- **방법 A (가장 쉬움)**: 깃허브 저장소 화면 → 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기 → 안에 있는 `ai-company` 폴더를 바탕화면으로 옮기기
- **방법 B**: 클로드 데스크톱 → **Code** → 작업 폴더 선택 후 "이 저장소의 ai-company 폴더를 내 컴퓨터에 받아줘"라고 요청

### ③ 실행
| 컴퓨터 | 방법 |
|---|---|
| 윈도우 | `ai-company` 폴더 안의 **`start-windows.bat`** 더블클릭 |
| 맥 | **`start-mac.command`** 더블클릭 (처음엔 우클릭 → 열기) |

검은 창이 뜨고 브라우저에 **관리 화면(http://localhost:8787)** 이 열리면 성공입니다.
⚠️ 검은 창을 닫으면 회사가 멈춥니다. 쓰는 동안은 켜두세요.

### ④ 먼저 "체험 모드"로 구경하기 (API 키 없이)
키를 넣지 않으면 **체험 모드**(가짜 응답)로 돌아갑니다. 비용 0원으로 전체 흐름을 볼 수 있습니다.
1. CEO 홈 → 지시 내용에 `AI 뮤직비디오를 쓰레드에 올려줘. 첫 게시물이니까 리포스트와 좋아요를 극대화해줘` 입력
2. "결과물을 쓰레드에 게시하는 업무입니다" 체크 → **비서실장에게 지시하기**
3. 메신저에서 직원들이 토론하는 걸 구경 → 1차 검수에서 **반려**됨 (체험 모드는 일부러 한 번 반려합니다)
4. CEO 홈 → 보강 지시에 `반려 사유 해소하고 다시 진행해` → **보강 지시 내리기**
5. 재검수 통과 → 전략 검토 → 발행 큐에서 **승인하고 게시** → 모의 게시 완료

### ⑤ 실전 모드로 전환 (API 키 넣기)
1. https://console.anthropic.com 가입 → **API Keys** → **Create Key** → 복사 (`sk-ant-`로 시작)
2. 관리 화면 **소셜·설정** 탭 → 클로드 API 키 칸에 붙여넣기 → 저장
3. (선택) 전략실장을 GPT로: https://platform.openai.com → API keys → 키 복사 → OpenAI 칸에 저장
   - OpenAI 키가 없으면 전략실장도 클로드가 대신합니다.
   - 전략 검토 자체를 빼고 싶으면 `config/company.json`의 `"strategyEnabled": false`
4. 상단 배지가 **실전 모드**로 바뀌면 끝

> 💰 비용 감각: 업무 1건 = AI 호출 약 12~20회. API는 쓴 만큼 과금되니, 콘솔에서 **월 사용 한도**를 꼭 걸어두세요.
> 토큰을 아끼려면 **토론 강도: 가볍게**를 쓰세요 (담당자만 발언).

## 3. 쓰레드 연결 (가장 까다로운 부분)

### 3-1. 인스타그램 (선택)
쓰레드만 쓸 거면 건너뛰어도 됩니다. 나중에 인스타까지 연결하려면: 인스타 앱 → ☰ → **계정 유형 및 도구** → **프로페셔널 계정으로 전환** → 비즈니스 → 페이스북 연결은 건너뛰기.

### 3-2. 메타 개발자 등록 + 앱 만들기
1. https://developers.facebook.com → **로그인**(페이스북 계정으로 계속)
2. 처음이면 개발자 계정 생성: 휴대폰 인증(**앞자리 0 빼고** 입력, 문자가 안 오면 국제문자 차단 확인) → 이메일 확인 → 역할 **개발자**
3. **앱 만들기** → 앱 이름은 **영문**으로 (예: `BlessAICompany`)
4. 이용 사례: **Threads API 액세스** 반드시 체크
5. 비즈니스 포트폴리오: **아직 연결하지 않음** → 다음 → **앱 만들기**

### 3-3. 권한 추가
왼쪽 **이용 사례** → Threads API → **권한**에서 아래를 추가:
- `threads_content_publish` (게시)
- `threads_manage_replies` (답글 관리)
- `threads_read_replies` (답글 읽기)
- `threads_manage_insights` (성과 조회 — 성과 분석 업무에 필요)

### 3-4. 콜백 주소 등록 + 앱 ID/시크릿 복사
같은 화면 **설정**에서:
1. **콜백 URL(리디렉션)**, **제거 콜백 URL**, **삭제 콜백 URL** 세 칸 모두에 `https://localhost/threads-callback` 입력 → 저장
2. **Threads 앱 ID** 복사 → 관리 화면 소셜·설정 ①칸에 붙여넣기
3. **Threads 앱 시크릿 코드** → 시크릿 보기 → 비밀번호 입력 → 복사 → ②칸에 붙여넣기 → **저장**
   🔒 시크릿 코드는 절대 다른 사람에게 보여주지 마세요.

### 3-5. 테스터 등록 (내 쓰레드 계정 초대)
1. 메타 왼쪽 **앱 역할 → 역할** → **사람 추가** → 역할 **Threads 테스터**
2. 내 쓰레드 **사용자 이름**(쓰레드 앱 프로필 맨 위, @ 뒤 이름) 입력 → 추가
3. ⚠️ "양식을 저장할 수 없습니다"가 뜨면: **콜백 주소 3개를 모두 저장**했는지 확인 → 페이지 **새로고침 → 로그아웃 후 다시 로그인** → 다시 추가 (영상 속 해결법)
4. 쓰레드 앱(또는 웹) → **설정 → 계정 → 웹사이트 권한 → 초대** → 방금 앱의 초대 **수락**

### 3-6. 연결하기
1. 관리 화면 소셜·설정 → **연결하기** 클릭 → 쓰레드 로그인 창에서 **계속/허용**
2. **"사이트에 연결할 수 없음"** 화면이 뜹니다 → 정상입니다!
3. 그 화면의 **주소창 주소 전체**(`https://localhost/threads-callback?code=...`)를 복사
4. 관리 화면의 입력칸에 붙여넣고 **연결 완료** → `연결됨 @내아이디` 표시
5. **시험 게시**로 실제로 올라가는지 확인 (60일짜리 토큰이 저장되고 자동 갱신됩니다)

### 3-7. 영상은 왜 바로 안 올라가나요?
쓰레드 API는 영상 **파일**을 받지 않고, 쓰레드 서버가 가져갈 수 있는 **공개 인터넷 주소**만 받습니다.
- **추천: 수동 게시** — 발행 큐에서 AI가 확정한 문구를 **복사** → 쓰레드 앱에서 영상 첨부 → 게시 → "수동 게시 완료" 누르기. (AI가 문구·검수·기록을 다 하고, 나는 버튼만 누르는 구조)
- **고급: 공개 주소 만들기** — `cloudflared` 같은 터널 프로그램으로 임시 공개 주소를 만들어 소셜·설정의 `PUBLIC_URL`에 넣으면 영상도 자동 게시됩니다. 외부에서는 `content/videos` 폴더 영상만 보이고 관리 화면은 차단됩니다. 어려우면 클로드에게 "cloudflared로 PUBLIC_URL 만드는 법 알려줘"라고 물어보세요.

## 5. 🔑 가장 중요한 것: "완료 기준"

영상의 교훈: **"이 정도는 알아서 잘하겠지"는 통하지 않습니다.**
직원·토론·검수 구조를 다 만들어도, 결과물 기준을 안 주면 **형편없는 보고서**가 나옵니다.
그래서 이 시스템에는 처음부터 3가지 장치를 넣었습니다.

1. **완료 기준 파일** (`standards/`) — 직원은 작업 **전에** 읽고, 비서실장은 그 체크리스트(`- [ ]` 줄)로**만** 검수합니다.
2. **CEO 보고서 고정 양식** (`standards/templates/ceo-report.html`) — AI가 마음대로 꾸미지 않고 정해진 순서(결론 한 줄 → 내가 결정할 것 → 요약 3줄 → 근거 → 리스크 → 다음 행동)로만 채웁니다.
3. **성공·실패 기억** (`memory/lessons.md`) — 반려될 때마다 "다음에 막을 교훈"이 자동 기록되고, 새 업무 때 비서실장이 먼저 읽습니다.

### 보고서가 마음에 안 들 때 하는 법
- ❌ "보기 좋게 다시 만들어줘" (기준이 없어서 또 이상하게 나옴)
- ✅ **완료 기준** 탭 → `ceo-report.md`에 원하는 것을 **문장으로** 추가:
  ```
  - [ ] 숫자는 반드시 표로 정리한다
  - [ ] 전체 분량은 A4 한 장을 넘지 않는다
  - [ ] 내가 좋아하는 보고서 특징: 첫 화면에 결론과 숫자 3개만 크게
  ```
  → 다음 업무부터 직원은 이 기준으로 만들고, 비서실장은 이 기준으로 반려합니다.

## 6. 내 회사에 맞게 바꾸기

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 회사 이름, 브랜드 정체성, 말투, 금지 표현 | `config/company.json` |
| 사용 모델, 전략 검토 켜기/끄기, 자동 재작업 횟수 | `config/company.json` → `models`, `policy` |
| 직원 이름·역할·성격, 직원 추가/삭제 | `config/agents.json` |
| 합격 기준 | 관리 화면 **완료 기준** 탭 |

직원이 너무 많다고 느껴지면 `agents.json`에서 지워도 됩니다. 최소 구성은 **비서실장 + 직원 2~3명**, 전략실장 끄기(`strategyEnabled: false`)입니다.
파일을 고치는 게 어려우면 클로드 코드에 이 폴더를 열고 **"직원 중 마진율을 빼고 보험 광고심의 담당을 추가해줘"** 처럼 말로 시키세요.

## 7. 막혔을 때

| 증상 | 해결 |
|---|---|
| 더블클릭해도 창이 바로 꺼짐 | Node.js 미설치 → 2-①부터 |
| 관리 화면이 안 열림 | 검은 창이 켜져 있는지 확인 → 브라우저에 `http://localhost:8787` 직접 입력 |
| "클로드 호출 실패(401)" | API 키 오타 → 소셜·설정에서 다시 저장 |
| "클로드 호출 실패(400) … credit" | 콘솔에서 크레딧 충전 |
| 업무가 ⚠ 오류로 멈춤 | 작업 큐 → **다시 시도** (멈춘 단계부터 이어서 함) |
| 쓰레드 "redirect_uri" 오류 | 메타 설정의 콜백 주소와 소셜·설정 ③칸이 **글자 하나까지 똑같은지** 확인 |
| 테스터 추가 시 "양식을 저장할 수 없음" | 3-5의 ③ 참고 (새로고침 → 재로그인) |
| 그래도 모르겠다 | **모르면 AI에게 묻고, 막히면 화면을 캡처해서 보여주세요.** 클로드 코드에서 이 폴더를 열면 `CLAUDE.md`를 읽고 구조를 이해한 상태로 답합니다 |
