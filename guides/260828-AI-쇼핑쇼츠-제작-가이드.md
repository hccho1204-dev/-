# AI 쇼핑 쇼츠 제작 가이드 — 제품 링크 1개로 15초 광고 영상까지

> **모델 섭외·제품 구매·촬영 없이, 제품 링크 하나와 제품 이미지 몇 장으로 쇼핑 쇼츠를 만드는 전체 워크플로우입니다.** Claude 한 창에 AI 이미지·영상 생성 도구(Topview)를 MCP로 연결해 **리서치 → 광고 기획 → 캐릭터 시트 → 스토리보드 → 영상 생성**까지 이어서 진행합니다. 핵심은 "컷마다 얼굴과 제품이 바뀌는 문제"를 잡는 **일관성 고정**입니다.

---

## 1. 왜 쇼핑 쇼츠인가

일반 쇼츠는 수익 구조가 하나입니다. 조회수가 나오면 광고비가 들어오고 끝입니다.

쇼핑 쇼츠는 여기에 하나가 더 붙습니다.

| 구분 | 광고 수익 | 판매 수수료 |
|---|---|---|
| 일반 쇼츠 | O | X |
| 쇼핑 쇼츠 | O | O (제휴 링크 구매 발생 시) |

영상 하나로 수익이 두 번 발생하기 때문에 제작 편수가 빠르게 늘고 있는 포맷입니다. 조회수도 수십만~수백만 단위가 흔합니다.

> ⚠️ 다만 조회수와 수수료는 **보장되는 수익이 아니라 결과값**입니다. "이렇게 하면 얼마 번다"가 아니라 "제작 원가를 0에 가깝게 낮춰 시도 횟수를 늘린다"가 이 워크플로우의 실제 가치입니다.

---

## 2. 시작 전 반드시 알아야 할 3가지

이걸 모르고 만들면 결과물이 나와도 쓸 수가 없습니다.

1. **어떤 제품이 잘 팔리는가** — 제품 선정에서 이미 절반이 결정됩니다.
2. **어떤 도구로 빠르게 만드는가** — 창을 여러 개 띄우는 순간 속도가 무너집니다.
3. **인물·제품 일관성을 어떻게 유지하는가** — 이게 안 되면 컷을 이어 붙일 수 없습니다.

이 가이드는 위 3가지를 순서대로 해결하는 구성입니다.

---

## 3. 준비물

- 제품 링크 1개 (아마존 / 쿠팡 파트너스 / 본인 판매 제품)
- 제품 이미지 여러 장 (**정면·측면·후면·사용 장면** — 최소 3장 이상)
- Claude 계정
- Topview 계정 (AI 이미지·영상 생성 도구, MCP로 연결)

**제품 이미지를 1장만 넣으면 나머지 각도는 AI가 임의로 그립니다.** 손잡이 모양이 바뀌고 버튼 위치가 달라지는 원인이 대부분 여기에 있습니다.

---

## 4. 제품 선정 기준 — 딱 2가지만 봅니다

### 기준 1. Before / After가 눈에 바로 보이는 제품

"물이 뚝뚝 떨어지던 채소가 뽀송해진다"처럼 **화면에서 변화가 즉시 보여야** 구매로 이어집니다. 눈에 안 보이는 효능(성분, 체감형 기능)은 쇼츠에서 불리합니다.

### 기준 2. 후기가 많은 제품

리뷰가 곧 리서치 데이터입니다. 후기 수천 개 규모여야 "구매자들이 실제로 뭘 불편해하는지"를 뽑을 수 있습니다. 리뷰가 적으면 다음 단계인 리서치가 통째로 비어버립니다.

> 예시로 쓰기 좋은 카테고리: 채소 탈수기, 주방 소도구, 청소 도구, 수납 정리용품 — 전후 대비가 명확하고 리뷰가 두꺼운 생활용품군.

## 5. 세팅 — Topview MCP 연결 (최초 1회만)

1. Topview 사이트 가입 후 로그인
2. 좌측 하단 **스킬 / MCP / 플러그인** 항목 진입
3. 연결 방식 3가지 중 **MCP** 선택 → 우측에서 **Claude** 선택
4. 표시되는 주소를 **복사**
5. Claude → 좌측 하단 계정 → **설정** → **커넥터**
6. 우측 상단 버튼 → **커스텀 커넥터 추가**
   - 이름: `탑뷰`
   - 주소: 4번에서 복사한 URL
7. 추가 후 **"연결" 버튼을 한 번 더** 누릅니다 (여기서 끝내면 미연결 상태로 남습니다)
8. 계정 확인 → 승인 → 권한 요청은 전부 허용

세팅이 끝나면 이후에는 Claude 창만 열면 바로 사용할 수 있습니다.

## 6. STEP 1 — 리서치 (제품 링크 → 인사이트)

제품 링크를 채팅창에 붙여넣고, **구체적인 프롬프트**를 함께 넣습니다. 두루뭉술하게 물으면 두루뭉술한 답이 나옵니다.

### 📋 복사용 프롬프트

```
[제품 링크]

위 제품에 대해 아래 3가지를 조사해줘.

1. 구매자들이 가장 많이 언급하는 불만 3가지
2. 첫 3초에 시청자를 붙잡을 후킹 패턴 3가지
3. 경쟁 제품 광고들이 놓치고 있는 지점 3가지

조건:
- 각 항목은 "가장 중요한 3개"만. 개수를 늘리지 말 것
- 리뷰를 근거로 쓸 때는 반드시 작성자 아이디를 함께 표기할 것
- 확인되지 않은 내용은 지어내지 말고 "확인 불가"라고 명시할 것
- 결과는 채팅창에도 그대로 보여줄 것
```

### 왜 이렇게 쓰는가

| 조건 | 이유 |
|---|---|
| "3가지만" | 개수를 고정해야 결과가 정리됩니다 |
| "작성자 아이디 표기" | 근거가 실제 리뷰인지 검증 가능해집니다 |
| "지어내지 말 것" | 데이터가 없는 채널(예: 유튜브 댓글)은 "확인 불가"로 솔직하게 돌아옵니다 |
| "채팅창에도 보여줘" | 이 문장이 없으면 결과가 Topview 보드에만 쌓여 확인하러 왔다 갔다 해야 합니다 |

### 결과로 나와야 하는 것

- 아마존 리뷰 / 틱톡 데이터 기반 불만 top 3 (근거 리뷰 인용 포함)
- 3초 후킹 문구 후보
- **제품의 포지션 재정의** — 예: "이건 씻는 도구가 아니라, 말려서 신선도를 살리는 도구다"
- 경쟁사가 비어 있는 자리 — 예: 경쟁사는 전부 '자르는 기능'을 소구, '물기 제거'는 공백

번역투 문장은 그대로 쓰지 말고 한국어 구어로 다듬어 씁니다.

## 7. STEP 2 — 광고 기획 (인사이트 → 캠페인 3안)

리서치 결과를 **같은 대화창에서 그대로 이어받아** 기획으로 넘깁니다. 조사 따로, 기획 따로 하지 않는 것이 이 워크플로우의 핵심입니다.

### 📋 복사용 프롬프트

```
위 리서치 인사이트를 근거로 15초 쇼핑 쇼츠 캠페인을 3가지 스타일로 만들어줘.

1. UGC 스타일 (일반 사용자 후기 톤)
2. 언박싱 스타일
3. 제품 리뷰 스타일

각 안마다 포함할 것:
- 캠페인 이름
- 초 단위 타임라인 (몇 초에 무엇을 보여줄지)
- 컷별 자막 문구
- 하지 말아야 할 연출
- 쓰지 말아야 할 단어

조건: 광고티가 나는 구성은 피하고, 상황을 먼저 보여준 뒤 제품이 등장하는 순서로 짤 것
```

### 어떤 스타일을 고를까

| 제품 성격 | 추천 포맷 |
|---|---|
| 불편함이 명확한 제품 | 문제 제기형 (UGC) |
| 후기가 강한 제품 | 리뷰형 |
| 개봉 순간이 화려한 제품 | 언박싱형 |
| Before/After가 시간차로 드러나는 제품 | 비교형 (예: "3일 뒤 냉장고를 열어봤습니다") |

정답은 없습니다. **제품 성격을 보고 고르는 것**이 기준입니다.

---

## 8. STEP 3 — 캐릭터 시트 (⭐ 가장 중요)

컷마다 얼굴이 바뀌는 문제를 해결하는 단계입니다. **캐릭터 시트**는 한 인물의 정면·반측면·옆모습을 한 장에 담아두는 기준 이미지입니다.

### 📋 복사용 프롬프트

```
아래 인물의 캐릭터 시트를 만들어줘.

[인물 설정]
- 국적/연령: 한국, 20대 초반
- 역할: 대학생 인플루언서
- 머리: (길이/색/스타일)
- 표정: (밝은 미소 / 담담한 표정 등)
- 의상: (상의/하의/색상)
- 배경: (단색 스튜디오 등)
- 조명: (자연광 / 소프트박스 등)

[요구사항]
- 한 장 안에 정면 / 반측면 / 옆모습이 모두 들어갈 것
- 시안은 2개만 생성할 것 (여러 개 늘어놓지 말 것)
- ★ 이 인물을 앞으로 생성하는 모든 컷에서 동일하게 유지할 것
- 결과 이미지는 채팅창에도 함께 보여줄 것
```

### 체크 포인트

- **"모든 컷에서 동일하게 유지할 것"** — 이 한 줄의 유무가 결과를 완전히 갈라놓습니다.
- 생성 결과에 함께 나오는 **파일 ID가 이후 모든 컷의 기준값**이 됩니다. 반드시 보관하세요.
- 이 단계에서 대충 넘어가면 뒤에서 계속 되돌아오게 됩니다.

---

## 9. STEP 4 — 제품 고정

인물을 잡았으면 제품 차례입니다. 준비해 둔 **제품 사진을 전부 업로드**합니다. 정면·측면·사용 장면까지 모두 넣습니다.

요청 시 아래 두 줄을 반드시 포함합니다.

```
- 인물은 위에서 만든 캐릭터 시트와 동일 인물로 유지할 것
- 제품은 업로드한 사진과 동일한 제품으로 유지할 것 (형태·색상·버튼 위치 변경 금지)
```

**이 두 줄이 이 워크플로우 전체의 핵심입니다.**

---

## 10. STEP 5 — 스토리보드 6컷

### 📋 복사용 프롬프트

```
위 인물과 제품을 그대로 유지한 상태로, 스토리보드 6컷을 한 번에 만들어줘.

구성: 훅 → 문제 → 해결 → 결과 순서
각 컷마다 포함할 것:
- 몇 초 구간인지
- 화면에 무엇이 보이는지
- 자막(또는 나레이션) 문구
- 카메라 앵글 (6컷 모두 서로 다른 앵글로)

조건:
- 인물은 캐릭터 시트와 동일 인물
- 제품은 업로드 사진과 동일 제품
- 결과 이미지는 채팅창에도 보여줄 것
```

### 수정은 부분만

결과에서 앵글이 반복되거나 마음에 안 드는 부분이 있으면 **전체를 다시 만들 필요가 없습니다.** 말로 부분 수정만 요청하면 됩니다.

```
3번, 5번 컷의 앵글이 겹쳐. 6컷 전부 다른 앵글이 되도록 다시 잡아줘.
그리고 자막 대신 나레이션이 들어갈 자리로 구성해줘.
```

나레이션 대본까지 요청하면 컷별 대사, 강조 위치, 호흡 지점, 피해야 할 광고성 단어까지 함께 정리해줍니다.

## 11. STEP 6 — 영상 생성

> 💰 **크레딧 경고: 영상 생성이 크레딧을 가장 많이 소모합니다.**
> 반드시 **이미지 단계에서 100% 확정**한 뒤 영상으로 넘어가세요. 이 순서 하나로 비용이 크게 갈립니다.

### 📋 복사용 프롬프트

```
확정된 6컷을 그대로 영상으로 만들어줘.
- 영상 모델: Seedance 2.5
- 컷별 길이는 내용에 맞게 다르게 잡아줄 것
- 인물/제품은 기존과 동일하게 유지
```

### 결과 활용 원칙

**6컷을 만들었다고 6컷을 다 쓰지 않습니다.** 괜찮은 5컷만 쓰고 1컷은 다시 뽑습니다. 마음에 안 드는 컷 하나 때문에 전체를 다시 만들 이유가 없습니다.

### 나레이션 2가지 방법

| 방식 | 장점 | 단점 |
|---|---|---|
| AI 음성 (Topview) | 즉시 생성, 재수정 쉬움 | 한국어 발음·속도가 어색한 구간 발생 |
| 직접 녹음 | UGC 특유의 자연스러움 | 녹음 시간 필요 |

**UGC 느낌을 노린다면 직접 녹음을 권장합니다.** 스마트폰 녹음으로도 충분합니다.

## 12. 보드 관리 & 재활용

Topview 보드에 캐릭터 시트·스토리보드·영상이 자동으로 쌓입니다.

- 별도 저장·폴더 정리 불필요
- 각 생성물의 **사용 프롬프트가 그대로 보존** → 다음 제품에 그대로 재사용
- 보드에서 바로 부분 수정 가능 (얼굴만 교체, 앵글만 변경)
- 마음에 드는 이미지는 보드에서 바로 영상으로 전환

**인물과 제품을 이미 고정해뒀기 때문에, 같은 모델로 다른 버전을 무한히 뽑아낼 수 있습니다.** 실사 촬영이라면 제품 구매 → 모델 섭외 → 장소 대관 → 재촬영을 처음부터 반복해야 하는 부분입니다.

## 13. 솔직한 한계 3가지

### ① 한국어 발음
AI 음성의 속도와 억양이 어색한 구간이 나옵니다. → **직접 녹음 권장**

### ② 재생성이 필요합니다
6컷 뽑으면 5컷 정도 쓴다고 생각하세요. 입 움직임이 어색한 구간이 섞입니다. 한 번에 완벽하게 나오지 않습니다. **다만 이건 어떤 AI 영상 도구를 써도 동일합니다.**

### ③ 크레딧
영상 생성이 소모량 1위입니다. 요금제는 월간/연간이 있고, 연간에 무제한 사용 기간이 붙습니다. 영상을 지속적으로 만들 계획이라면 연간이 유리합니다.

> 결론: 완벽한 도구는 아닙니다. 다만 **리서치부터 영상까지 한 창에서 끝나는 구성**이라는 점이 이 워크플로우의 실질적인 이점입니다.

## 14. 전체 흐름 요약

```
제품 링크 1개
   ↓
① 리서치      제품 링크 → 불만 3 / 후킹 3 / 경쟁 공백 3
   ↓
② 광고 기획    인사이트 → 15초 캠페인 3안 → 1안 선택
   ↓
③ 캐릭터 시트  인물 고정 (정면·반측면·옆모습 + 파일 ID)   ⭐
   ↓
④ 제품 고정    제품 사진 다각도 업로드 + "동일 유지" 2줄   ⭐
   ↓
⑤ 스토리보드   6컷 (훅→문제→해결→결과) + 나레이션 대본
   ↓  ← 여기까지 이미지 단계에서 완전히 확정
⑥ 영상 생성    6컷 → 영상 (약 25~30초) → 5컷 채택
   ↓
편집 · 나레이션 · 업로드
```

## 15. 제작 체크리스트

**제품 선정**
- [ ] Before/After가 화면에 바로 보이는 제품인가
- [ ] 리뷰가 충분히 많은가 (리서치 가능 수준)

**세팅**
- [ ] Topview MCP 커넥터 추가 후 **"연결" 버튼까지** 눌렀는가
- [ ] 제품 이미지를 **3장 이상, 여러 각도로** 확보했는가

**프롬프트**
- [ ] 개수를 숫자로 지정했는가 ("3가지만")
- [ ] "근거 리뷰 아이디 표기 / 지어내지 말 것"을 넣었는가
- [ ] "결과를 채팅창에도 보여줘"를 넣었는가

**일관성 (⭐)**
- [ ] "모든 컷에서 동일 인물 유지" 문장을 넣었는가
- [ ] 캐릭터 시트 파일 ID를 보관했는가
- [ ] "업로드 사진과 동일 제품 유지" 문장을 넣었는가

**비용**
- [ ] 이미지 단계에서 완전히 확정한 뒤 영상으로 넘어갔는가
