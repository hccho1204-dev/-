# 인스타 캡션 — 결혼하는 자녀 증여 공제

```
결혼하는 자녀에게 1억 5천만 원,
세금 0원일 수도, 2,000만 원일 수도 있습니다 💍

차이는 금액이 아니라 '언제·누가·어떻게'에서 생깁니다.

✅ 언제 — 결혼식 날이 아니라 혼인신고일 전후 각 2년
✅ 누가 — 엄마·아빠가 따로 줘도 공제는 자녀 기준 합산 (두 배 X)
✅ 어떻게 — 세금이 0원이어도 신고! 증여일이 속한 달 말일부터 3개월

📌 기본공제 5,000만 원(10년) + 혼인·출산공제 1억 원
→ 요건을 충족하면 1억 5천만 원도 과세표준 0원 가능
→ 공제를 못 쓰면 산출세액 2,000만 원 (기한 내 신고 시 1,940만 원)

이체 버튼 누르기 전, 자료부터 꺼내 보세요.
자녀 통장 · 전세계약서 · 부부별 지원 계획 · 혼인신고 예정일 · 최근 10년 증여 이력

💾 자녀 결혼 앞두고 다시 보려면 저장
📩 우리 집 상황 점검이 필요하면 DM으로 "증여"

조홍철 본부장 | 인카금융서비스 블레스본부
※ 가상 사례 기반 교육용 자료이며 특정 상품 권유가 아닙니다. 2026년 11월 현행 세법(상증법 제53조·제53조의2·제68조·제69조) 기준이며, 실제 세액은 개인별로 다르니 세무사와 확인하세요.

```
