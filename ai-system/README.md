# 나만의 AI 에이전트 시스템 — SSR+ 세팅 가이드

AI가 똑똑해져도 내 일이 줄지 않는 이유는 하나다. **AI가 일할 환경을 안 깔아뒀기 때문.**
이 가이드는 그 환경을 4단계로 깐다.

| 단계 | 이름 | 한 줄 정의 | 이 저장소에 만든 것 |
|---|---|---|---|
| S | 스킬 | 업무 단축키 | `.claude/skills/` (skill-improver, connector-finder, extension-idea) |
| S | 세컨드 브레인 | AI가 내 자료를 알아서 찾는 지도 | `CLAUDE.md`(대문) + `ai-system/wiki/`(길잡이) |
| R | 루틴 | 정해진 시간에 단축키 누르기 | `ai-system/routines/` |
| + | 익스텐션 | AI의 손발(메일·캘린더·브라우저) | `ai-system/wiki/커넥터.md`, `dashboard.html` |

---

## 1단계. 스킬 — "두 번 시켰으면 스킬로"

| 레벨 | 할 일 | 신호 |
|---|---|---|
| 초급 | 기본 스킬 `skill-creator`로 말만 해서 스킬 만들기 | 같은 요청을 두 번 했다 |
| 중급 | 스킬 폴더에 참고 자료(양식·디자인 가이드·HTML 조각) 넣기 | 결과물 품질이 들쭉날쭉하다 |
| 고급 | 스킬을 고치는 스킬(`skill-improver`) + 자가 업데이트 | 양식이 바뀌어 스킬이 낡았다 |

### [프롬프트 1-1] 초급: 스킬 만들기
```
skill-creator를 사용해서 스킬을 하나 만들어줘.
- 스킬 이름: (예: recruit-dm)
- 하는 일: (예: 인스타 DM으로 들어온 채용 문의에 답장 초안 쓰기)
- 이렇게 말하면 발동: (예: "DM 답장 써줘", "채용 문의 답장")
- 입력: (예: 문의 내용 복사본)
- 출력 형식: (예: 3문장 답장 + 다음 행동 1줄)
- 꼭 지킬 규칙: (예: 수입 보장 표현 금지, 존댓말, 이모지 1개 이하)
만든 뒤 테스트 문의 2개로 직접 돌려보고 결과를 보여줘.
```

### [프롬프트 1-2] 중급: 스킬에 참고 자료 넣기
```
.claude/skills/<스킬이름>/ 스킬을 업그레이드해줘.
1. 지금 SKILL.md를 읽고, 결과물 품질을 좌우하는 기준(디자인, 말투, 양식)을 뽑아줘.
2. 그 기준을 별도 참고 파일로 분리해줘: style.md(톤·디자인), template.md 또는 template.html(양식), examples.md(잘 된 예시 2개).
3. SKILL.md에는 "작업 전 style.md와 template을 반드시 읽는다"는 줄만 남겨 짧게 만들어줘.
4. 내가 첨부한 자료(양식 파일, 예전 결과물)를 template와 examples에 반영해줘.
```

### [프롬프트 1-3] 고급 ①: 스킬에 자가 업데이트 기능 넣기
```
.claude/skills/<스킬이름>/SKILL.md 맨 끝에 "자가 업데이트" 섹션을 추가해줘.
내용: 작업이 끝나면 내가 고친 부분이 있었는지 확인하고, 있었다면
"이 수정을 스킬에 반영할까요?"라고 한 줄로 묻는다. 내가 "응"이라고 하면
해당 규칙을 SKILL.md 또는 참고 파일에 추가하고 맨 아래 변경 기록에 날짜와 한 줄 요약을 남긴다.
```

### [프롬프트 1-4] 고급 ②: 전체 스킬 개선하기
```
skill-improver 스킬로 <스킬이름>을 점검해줘.
이번 대화에서 그 스킬이 발동된 부분과 내가 고치라고 한 부분을 근거로
[문제 / 고칠 위치 / 수정 전 / 수정 후] 표를 만들어줘. 내가 "적용"이라고 하면 고쳐.
```

## 2단계. 세컨드 브레인 — "폴더 정리 대신 길잡이 파일"

| 레벨 | 할 일 | 신호 |
|---|---|---|
| 초급 | 작업 폴더 1개 + `CLAUDE.md`(또는 AGENTS.md)에 항상 지킬 지침 | 매번 같은 설명을 반복한다 |
| 중급 | 대문(CLAUDE.md) → 업무별 길잡이 → 하위 페이지, "나무위키" 구조 | AI가 파일을 못 찾는다 / 나도 못 찾는다 |
| 고급 | 나만의 탐색기(지식 그래프·계층 뷰·미리보기) | 노션·옵시디언 배우기 귀찮다 |

> 길잡이 파일 = 주제별로 파일 링크를 모아 둔 목차 페이지. 폴더가 엉망이어도 길잡이만 정확하면 AI가 바로 찾는다.

### [프롬프트 2-1] 초급: CLAUDE.md 만들기
```
이 폴더의 CLAUDE.md를 만들어줘. 나에게 질문을 1개씩 해서 아래 내용을 채워.
1. 나는 누구인가 (직업, 하는 일, 고객)
2. 답변 스타일 (언어, 길이, 형식, 금지 표현)
3. 항상 지킬 규칙 5개 이내
4. 자주 하는 업무 TOP 5
다 채우면 50줄 이내로 정리해서 저장해줘.
```

### [프롬프트 2-2] 중급: 길잡이 파일 세팅
```
이 폴더를 세컨드 브레인으로 정리해줘. 파일은 옮기지 말고 길잡이만 만든다.
1. 모든 파일을 훑어서 업무 분야별(예: 콘텐츠, 영업, 리크루팅, 운영)로 묶어줘.
2. 분야마다 ai-system/wiki/<분야>.md 길잡이 파일을 만들고, 파일마다 [날짜/주제/링크/한 줄 설명] 표로 정리해.
3. CLAUDE.md에 "업무별 길잡이" 표를 만들어 각 길잡이로 연결해. (CLAUDE.md = 대문)
4. CLAUDE.md 규칙에 "새 파일을 만들면 반드시 해당 길잡이에 한 줄 링크를 추가한다"를 넣어.
5. 마지막에 어느 길잡이에도 속하지 않은 파일 목록을 보여줘.
```

### [프롬프트 2-3] 고급: 나만의 탐색기 만들기
```
내 세컨드 브레인 탐색기를 HTML 한 장으로 만들어줘.
- 가운데 CLAUDE.md를 두고, 길잡이 파일과 그 안에 링크된 파일을 선으로 잇는 지식 그래프 뷰
- 같은 데이터를 폴더처럼 접었다 펴는 계층 뷰 (탭으로 전환)
- 검색창: 파일 이름과 길잡이 설명으로 찾기
- 노드를 누르면 오른쪽에 내용 미리보기
데이터는 CLAUDE.md와 ai-system/wiki/ 안의 링크를 읽어서 자동으로 만들어.
```

## 3단계. 루틴 — "오전 9시에 단축키를 눌러라"

| 레벨 | 할 일 | 단점·한계 |
|---|---|---|
| 초급 | Claude 데스크톱 앱 → 코드 탭 → 예약된 작업 → 새 작업 | 컴퓨터와 앱이 켜져 있어야 실행됨 |
| 중급 | 안 꺼지는 컴퓨터(남는 PC 또는 클라우드 서버)에 상시 에이전트 설치 + 파일 동기화(Syncthing) | 세팅이 조금 필요 |
| 고급 | 처음부터 클라우드에서 실행 (Claude Code 웹/클라우드 예약 작업) | 자료도 클라우드(저장소)에 있어야 함 |

> 지금 이 저장소는 이미 **고급 방식**에 가깝다. Claude Code 클라우드 세션은 컴퓨터를 꺼도 돈다. 대화창에서 "이 루틴을 매일 8시 47분에 예약해줘"라고 하면 클라우드 예약 작업으로 등록된다.

### 루틴 프롬프트 (그대로 복사해서 예약)
| 루틴 | 시간 | 파일 |
|---|---|---|
| 모닝 브리핑 | 매일 08:47 | [routines/모닝-브리핑.md](routines/모닝-브리핑.md) |
| 리크루팅 리드 점검 | 평일 13:23 | [routines/리크루팅-리드-점검.md](routines/리크루팅-리드-점검.md) |
| 주간 콘텐츠 기획 | 월 07:41 | [routines/주간-콘텐츠-기획.md](routines/주간-콘텐츠-기획.md) |
| 세컨드 브레인 정리 | 금 17:37 | [routines/세컨드브레인-정리.md](routines/세컨드브레인-정리.md) |

> 정각(9:00) 대신 8:47처럼 애매한 시간으로 잡는다. 정각은 사람들이 몰려 실행이 늦어질 수 있다.

### [프롬프트 3-1] 루틴 등록 (클라우드)
```
ai-system/routines/모닝-브리핑.md 안의 프롬프트를
매일 아침 8시 47분(서울 시간)에 실행되는 예약 작업으로 등록해줘.
Gmail과 Google Calendar 커넥터를 쓰도록 하고, 결과는 휴대폰 알림으로 받게 해줘.
```

### [프롬프트 3-2] 중급: 남는 PC에 상시 에이전트 + 동기화
```
집에 남는 윈도우 PC를 24시간 AI 루틴 서버로 쓰고 싶어. 비개발자 기준으로 번호 매겨 안내해줘.
1. 절전 모드 끄기, 자동 로그인, 원격 접속 설정
2. Syncthing으로 내 노트북의 작업 폴더(세컨드 브레인)를 그 PC와 동기화
3. 그 PC에 Claude Code(또는 상시 실행 에이전트)를 설치하고 예약 작업 등록
4. 잘 돌고 있는지 휴대폰으로 확인하는 방법
```

## 4단계. 익스텐션 — "AI에게 손발 달아주기"

| 레벨 | 할 일 | 예 |
|---|---|---|
| 초급 | claude.ai 설정 → 커넥터에서 클릭 연결 | Gmail, 캘린더, 드라이브, 노션 |
| 중급 | 기본에 없는 것은 MCP → CLI → API 순으로 찾아 연결 (`connector-finder` 스킬) | 건축물대장, 카카오, 네이버 키워드 |
| 고급 | 맞는 게 없으면 직접 만들기 (`extension-idea` 스킬) | 마크다운 뷰어, 브랜드 라이브러리, 대시보드 |

| 연결 방식 | 쉬운 설명 | 난이도 |
|---|---|---|
| MCP | Claude 전용 플러그. 꽂으면 바로 도구가 생김 | ★★ |
| CLI | 터미널 명령어 프로그램. Claude가 대신 입력 | ★★★ |
| API | 서비스의 데이터 창구. 열쇠(API 키) 필요 | ★★★★ |

### [프롬프트 4-1] 중급: 커넥터 찾기
```
connector-finder 스킬로 찾아줘.
연결하고 싶은 것: (예: 건축물대장 — 주소로 건물 층수·면적·용도 조회)
쓰는 상황: (예: 법인 고객 화재보험 상담 전에 건물 정보 확인)
무료 우선, 공식 우선으로 후보 3개를 표로 보여주고 1순위 연결 방법을 번호 매겨 알려줘.
```

### [프롬프트 4-2] 고급: 확장 기능 아이디어
```
extension-idea 스킬로 내 업무에 맞는 확장 기능 아이디어 5개를 표로 제안해줘.
CLAUDE.md와 ai-system/wiki/를 먼저 읽고, 내가 반복하는 수작업을 근거로 골라.
각 아이디어에 [해결하는 불편 / 형태 / 만드는 시간 / 효과]를 적어줘.
```

## 대시보드
[dashboard.html](dashboard.html) — 위 4단계를 한 화면에서 쓰는 사령실.
- 스킬 런처: 스킬 고르고 → 모델 고르고 → 프롬프트 적고 → 실행
- 루틴: 예약 시간표 + 등록 프롬프트 복사
- 세컨드 브레인: 지식 그래프 / 계층 뷰 / 검색 / 미리보기
- 익스텐션: 연결된 커넥터 현황
- 프롬프트 모음: 이 문서의 프롬프트 전부, 복사 버튼
