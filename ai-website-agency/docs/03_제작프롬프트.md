# 03. 홈페이지 제작 프롬프트 (Claude에 그대로 붙여넣기)

## 방법 A — 견본 수정 (가장 빠름, 10분)

1. `template/index.html`을 메모장(또는 VS Code)으로 연다
2. 맨 위 `const SITE = { ... }` 안의 글자만 가게 정보로 바꾼다
3. 저장 후 더블클릭 → 인터넷 창에서 확인

또는 Claude에게 시키기:

```
첨부한 index.html 파일의 맨 위 SITE 설정만 아래 가게 정보로 바꿔서
완성된 전체 파일을 다시 줘. 다른 코드는 건드리지 마.
메인 색상은 가게 분위기에 맞게 골라줘.

[02_고객발굴.md에서 정리한 가게 정보 표 붙여넣기]
```

## 방법 B — Claude로 새로 만들기 (고급, 20~30분)

```
너는 20년 경력의 웹디자이너이자 로컬 비즈니스 마케팅 전문가야.
아래 가게의 원페이지 홈페이지를 HTML 파일 1개로 만들어줘.

[가게 정보]
- 상호: 
- 업종: 
- 한줄소개: 
- 주소 / 전화 / 영업시간 / 휴무: 
- 대표 메뉴·서비스(이름/가격/설명): 
- 추천 리뷰 3개: 
- 분위기 키워드: 
- 인스타그램 / 네이버예약 / 카카오채널 주소: 

[디자인 요구사항]
1. 첫 화면: 3D 느낌의 움직이는 배경(마우스·스크롤에 반응하는 입체 효과) + 큰 상호명 + "전화하기", "예약하기" 버튼
2. 스크롤할 때 각 구역이 부드럽게 나타나는 애니메이션
3. 구역 순서: 소개 → 대표 메뉴(카드형) → 손님 후기 → 영업시간·오시는 길(네이버/카카오 지도 버튼) → 예약/문의
4. 휴대폰 화면 우선 설계, 하단에 항상 보이는 "전화 / 길찾기 / 예약" 고정 버튼
5. 외부 라이브러리 없이 HTML·CSS·JavaScript만 사용 (빠른 로딩)
6. 한글 폰트는 Pretendard, 색상은 분위기 키워드에 맞춰 선택
7. 사진 자리는 회색 박스 + "사진" 글씨로 비워두기 (나중에 교체)
8. <head>에 검색엔진 차단 태그(<meta name="robots" content="noindex">)를 넣어줘 — 미리보기용이라서
9. 과장 광고 표현(최고, 1위, 100% 등) 쓰지 마

완성된 코드 전체를 한 번에 줘.
```

## 수정 요청 프롬프트 모음

| 상황 | 복사해서 쓰기 |
|---|---|
| 색이 마음에 안 듦 | `메인 색상을 [고급스러운 네이비+골드]로 바꿔줘. 코드 전체 다시 줘.` |
| 더 화려하게 | `첫 화면 3D 효과를 더 입체적으로(떠다니는 도형 + 빛 번짐) 바꿔줘.` |
| 영어 버전 | `오른쪽 위에 KOR/ENG 전환 버튼을 넣고 모든 문구의 영어 버전을 추가해줘.` |
| 예약 폼 추가 | `예약 문의 폼(이름/연락처/날짜/인원/요청사항)을 넣고 Netlify Forms로 제출되게 해줘.` |
| 사진 넣기 | `사진 자리에 images/1.jpg ~ images/5.jpg를 순서대로 넣어줘.` |
| 계약 후 정식 오픈 | `robots noindex 태그를 지우고, 검색 노출용 title/description/오픈그래프 태그를 가게 정보로 채워줘.` |

## AI 이미지·영상 (선택, 프리미엄 패키지)

영상에서 언급된 **Higgsfield** 같은 AI 이미지·영상 도구를 Claude에 연결하면 첫 화면 배경 영상/3D 이미지를 만들 수 있습니다.

