# 02. 고객 발굴 — "리뷰 좋고 홈페이지 없는 가게" 찾기

## 1. 어디서 찾나

| 채널 | 방법 | 팁 |
|---|---|---|
| 네이버 지도 | "OO동 미용실" 검색 → 리뷰 많은 순 | 업체 정보에 "홈페이지" 항목이 없거나 인스타/블로그만 있으면 후보 |
| 카카오맵 | 같은 방식 | 평점(별점) 확인이 쉬움 |
| 구글 지도 | "hair salon near OO역" | "웹사이트" 버튼이 없는 가게 = 후보 (영상 원 방식) |
| 직접 산책 | 줄 서는 가게, 새로 연 가게 | 간판 사진 찍고 나중에 검색 |

## 2. 후보 점수표 (10점 만점, 7점↑만 제작)

| 기준 | 점수 |
|---|---|
| 평점 4.5 이상 | +2 |
| 리뷰(방문자+블로그) 100개 이상 / 50개 이상 | +2 / +1 |
| 홈페이지 없음 | +3 (있지만 낡음 +1) |
| 인스타그램 운영 중 (사진 확보 쉬움) | +1 |
| 예약·문의가 중요한 업종 | +1 |
| 사장님이 직접 매장에 있음 (결정권자 만나기 쉬움) | +1 |

> `tools/lead-tracker.html`에 입력하면 이 점수를 **자동 계산**합니다.

## 3. 정보 수집 체크리스트 (가게당 5분)

- [ ] 상호명 / 업종 / 한 줄 소개 (리뷰에서 자주 나오는 칭찬을 한 줄로)
- [ ] 주소, 전화번호, 영업시간, 휴무일
- [ ] 대표 메뉴·서비스 3~6개 + 가격
- [ ] 좋은 리뷰 3개 (짧고 구체적인 것)
- [ ] 사진 3~5장 (매장 외관, 내부, 대표 메뉴) — **미리보기용으로만 사용**
- [ ] 인스타그램 / 네이버 예약 / 카카오톡 채널 주소
- [ ] 가게 분위기 키워드 3개 (예: 따뜻한, 모던한, 고급스러운)

## 4. Claude에게 정보 정리 시키기 (복사해서 사용)

```
아래는 한 가게의 네이버 플레이스/리뷰에서 복사한 내용이야.
홈페이지 제작용으로 다음 항목을 표로 정리해줘:
상호, 업종, 한줄소개(20자 이내, 리뷰 칭찬 기반), 주소, 전화, 영업시간, 휴무,
대표메뉴 6개(이름/가격/한줄설명), 추천 리뷰 3개(40자 이내로 다듬기), 분위기 키워드 3개,
어울리는 메인 색상(hex 코드).

[여기에 복사한 내용 붙여넣기]
```

## 5. 하루 루틴

| 시간 | 할 일 | 목표 |
|---|---|---|
| 오전 30분 | 후보 찾기 + 점수 매기기 | 10곳 |
| 오전 1시간 | 7점 이상 가게 홈페이지 만들기 | 3~5개 |
| 오후 2~4시 (한가한 시간) | 방문 또는 전화 | 5곳 연락 |
| 저녁 15분 | 영업 관리표 업데이트, 다음날 재연락 대상 체크 | — |

> 음식점은 **점심·저녁 피크(11~14시, 17~20시)에 절대 방문 금지.** 오후 3~4시가 최적.
