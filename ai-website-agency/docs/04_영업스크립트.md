# 04. 영업 스크립트

> 핵심 원칙: **"만들어 드릴까요?"가 아니라 "이미 만들어 왔어요. 한번 보세요."**
> 휴대폰에 미리보기 링크를 띄워 두고, 사장님 손에 직접 쥐여 드리는 것이 성사율을 가장 높입니다.

## 1. 방문 대본 (2분)

| 단계 | 대사 |
|---|---|
| 인사 (10초) | "사장님 안녕하세요, 바쁘신데 1분만 괜찮으실까요? 근처에서 가게 홈페이지 만드는 일을 하는 OOO입니다." |
| 칭찬 (15초) | "네이버 리뷰가 OOO개에 평점이 4.8이시더라고요. 특히 '○○이 맛있다'는 후기가 정말 많던데요." |
| 문제 (15초) | "그런데 검색해 보니 가게 홈페이지가 없으셔서, 제가 사장님 가게 걸 **미리 한번 만들어 봤어요.**" |
| 시연 (40초) | (휴대폰 건네며) "직접 한번 넘겨 보세요. 여기 누르면 바로 전화 연결되고, 이건 길찾기, 이건 예약이에요." |
| 제안 (20초) | "마음에 드시면 이걸 사장님 가게 정식 홈페이지로 열어 드려요. 보통 업체에 맡기면 200~300만 원인데, 저는 99만 원에 주소까지 다 해 드립니다." |
| 마무리 (20초) | "고민되시면 링크 문자로 남겨 드릴게요. 가족분들께도 보여 주세요. 모레쯤 다시 연락드려도 될까요?" |

## 2. 전화 대본 (방문이 어려울 때)

```
안녕하세요, OO가게 사장님 되시죠?
저는 동네 가게 홈페이지를 만드는 OOO입니다. 30초만 괜찮으실까요?

리뷰가 워낙 좋으셔서 제가 사장님 가게 홈페이지를 미리 하나 만들어 봤습니다.
문자로 링크 하나 보내 드려도 될까요? 보시고 마음에 안 드시면 그냥 넘기셔도 됩니다.
(동의 시) 감사합니다. 지금 바로 보내 드리고, 내일 오후에 짧게 한 번만 다시 연락드릴게요.
```

## 3. 문자/카톡 (동의 받은 뒤 발송)

```
[OO가게 홈페이지 미리보기]
사장님, 방금 통화드린 OOO입니다.
리뷰에 있던 칭찬들을 모아서 만들어 봤어요 🙂

▶ 미리보기: https://xxxxx.netlify.app

· 전화/길찾기/예약 버튼 바로 연결
· 휴대폰에 맞춘 화면
· 마음에 드시면 정식 오픈 99만 원 (주소·검색등록 포함)

편하게 보시고, 수정하고 싶은 곳 있으면 말씀만 주세요.
```

> ⚠️ 모르는 사람에게 **동의 없이 광고 문자를 보내는 것은 정보통신망법 위반**이 될 수 있습니다. 전화나 방문으로 먼저 동의를 받은 뒤 보내세요. 인스타 DM은 가게 공식 계정의 "문의 환영" 표시가 있을 때만 1회.

## 4. 인스타그램 DM (1회만)

```
안녕하세요 사장님! 피드 보고 팬이 됐어요 🙌
프로필 링크에 걸어 두실 수 있게 가게 홈페이지를 미리 하나 만들어 봤는데,
링크 보내 드려도 괜찮을까요? 부담 없이 구경만 하셔도 됩니다!
```

## 5. 거절 대응

| 사장님 말 | 대답 |
|---|---|
| "네이버 플레이스 있어서 필요 없어요" | "맞아요, 플레이스 정말 중요하죠. 다만 그건 네이버 규칙대로 움직이는 거라서, 인스타·카톡·단체 문의 때 보내실 **사장님만의 주소**가 하나 있으면 좋더라고요. 플레이스 링크도 이 안에 같이 넣어 드려요." |
| "비싸요" | "업체 견적은 보통 200만 원 이상이에요. 부담되시면 베이직 49만 원도 있고, 주소는 나중에 추가하셔도 됩니다." |
| "생각해 볼게요" | "그럼요. 링크는 계속 열어 둘게요. 목요일 오후에 한 번만 연락드려도 될까요?" (날짜를 꼭 정하기) |
| "관리할 시간이 없어요" | "그래서 월 관리가 있어요. 메뉴나 가격 바뀌면 카톡으로 사진만 보내 주시면 제가 바꿔 드려요." |
| "사기 아니에요?" | "당연히 걱정되시죠. 돈은 **정식 오픈하고 확인하신 다음에** 받습니다. 계약서도 드려요." |
| "필요 없어요" (단호) | "알겠습니다, 시간 내 주셔서 감사합니다! 미리보기는 오늘 바로 내릴게요." → **실제로 삭제하고 재연락 금지** |

## 6. 재연락 규칙

- 1차 연락 후 **2일 뒤 1회**, 그 후 **1주 뒤 1회**가 끝. 총 3회 넘기지 않기.
- 3회 무응답 → 미리보기 삭제, 관리표에 "종료" 표시.
