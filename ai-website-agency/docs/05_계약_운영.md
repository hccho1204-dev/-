# 05. 계약·납품·운영

## 1. 진행 절차

| 단계 | 할 일 | 소요 |
|---|---|---|
| ① 구두 동의 | 패키지 선택, 수정 사항 메모 | 당일 |
| ② 계약서 | 아래 간이 계약서 문자/출력으로 서명 | 당일 |
| ③ 선금 | 50% 입금 (베이직은 전액 후불 가능) | 당일 |
| ④ 자료 받기 | 정식 사진·로고, 사용 동의 | 1~2일 |
| ⑤ 수정·오픈 | 수정 2회 포함, noindex 제거, 도메인 연결 | 1~3일 |
| ⑥ 잔금 | 오픈 확인 후 50% | 오픈일 |
| ⑦ 관리 | 월 관리 신청 시 자동이체 | 매월 |

## 2. 간이 계약서 (복사해서 사용)

```
[홈페이지 제작 계약서]

발주자(갑): 상호 ______________ 대표 ______________ 연락처 ______________
제작자(을): 성명 ______________ 연락처 ______________ (사업자번호 ______________)

1. 제작 내용: ______ 패키지 (원페이지 홈페이지, 모바일 대응, ____________)
2. 금액: 금 ______________원 (부가세 □포함 □별도)
   - 선금 50% 계약일 / 잔금 50% 오픈일
3. 납기: 자료 전달일로부터 ___일 이내
4. 수정: 오픈 전 2회 무료, 이후 건당 3만 원 (월 관리 고객은 월 3회 무료)
5. 자료 책임: 갑이 제공한 사진·글·로고의 권리 문제는 갑이 책임진다.
6. 소유권: 잔금 지급 완료 시 홈페이지 파일과 도메인 소유권은 갑에게 넘어간다.
7. 월 관리(선택): 월 ______원, 해지는 1개월 전 통보. 해지 시 파일 전체를 갑에게 전달한다.
8. 을은 과장·허위 광고 문구를 사용하지 않으며, 업종별 광고 규정은 갑과 협의한다.

20__년 __월 __일
갑: ______________ (서명)      을: ______________ (서명)
```

## 3. 납품 기술 절차 (쉬운 버전)

1. **무료 주소 만들기**: [app.netlify.com/drop](https://app.netlify.com/drop) 접속 → `index.html`이 든 폴더를 끌어다 놓기 → `xxxx.netlify.app` 주소 생성
2. **주소 이름 바꾸기**: Netlify → Site configuration → Change site name → `가게영문명.netlify.app`
3. **정식 오픈 전**: `index.html` 맨 위 `SITE.preview` 값을 `false`로 변경 (검색 차단 해제)
4. **전용 도메인 (스탠다드↑)**: 가비아/후이즈에서 `가게명.com` 또는 `.kr` 구입 → Netlify → Domain management → Add domain → 안내대로 DNS 설정
5. **검색 등록**: [네이버 서치어드바이저](https://searchadvisor.naver.com), [구글 서치콘솔](https://search.google.com/search-console)에 주소 등록
6. **네이버 플레이스에 홈페이지 주소 추가**는 사장님 계정에서 → 옆에서 같이 해 드리기

## 4. 세금·사업자

| 항목 | 내용 |
|---|---|
| 사업자등록 | 홈택스에서 무료 신청, 업종 "응용소프트웨어 개발 및 공급업" 또는 "홈페이지 제작" |
| 간이과세자 | 연 매출 1억 400만 원 미만이면 가능, 부가세 부담 적음 |
| 프리랜서(3.3%) | 사업자 없이 시작 가능하나, 가게 사장님이 원천징수 신고를 해야 해서 불편 → 사업자등록 권장 |
| 영수증 | 현금영수증/세금계산서 발행 가능하게 준비 |
| 종합소득세 | 매년 5월 신고 |

> 세부 사항은 담당 세무사와 확인하세요.

## 5. 법·윤리 주의사항 체크리스트

- [ ] 계약 전 미리보기는 **noindex(검색 차단)** 상태 유지 — 견본은 `SITE.preview: true`로 자동 적용
- [ ] 미리보기 페이지 하단에 "제안용 미리보기 — 공식 사이트 아님" 표시 (견본 자동 표시)
- [ ] 거절 시 **당일 삭제**
- [ ] 가게 사진·리뷰 원문은 계약 후 사장님 동의 받고 사용 (리뷰는 요약·인용 수준으로)
- [ ] 병원·약국·보험·금융·건강식품은 업종별 **광고 심의 규정** 확인
- [ ] 광고성 문자는 **수신 동의 후** 발송
- [ ] "최고/1위/100%" 등 근거 없는 표현 금지
