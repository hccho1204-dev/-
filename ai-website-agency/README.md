# AI 웹사이트 에이전시 — 동네 가게 홈페이지 제작·판매 사업

> 참고 영상: [AI시대에 돈버는 방법을 알려준 교수님](http://www.youtube.com/watch?v=pyonHRqjtfc)
> 핵심: **리뷰는 좋은데 홈페이지가 없는 동네 가게**를 찾아 → **AI(Claude)로 5~30분 만에 홈페이지를 만들고** → **완성된 결과물을 먼저 보여주며** 판매한다.

---

## 한 장 요약

| 항목 | 내용 |
|---|---|
| 고객 | 네이버/카카오/구글 지도에 평점 4.5↑, 리뷰 50개↑인데 홈페이지가 없는 가게 |
| 상품 | 원페이지 홈페이지 (모바일 최적화 + 애니메이션 + 전화/예약 버튼) |
| 가격 | 제작 49만~149만 원 + 월 관리비 3.3만 원(선택) |
| 원가 | 거의 0원 (Claude 구독료, 무료 호스팅 Netlify) |
| 차별점 | "만들어 드릴게요"가 아니라 **"이미 만들어 왔어요"** 로 시작하는 영업 |
| 목표 | 월 10건 판매 → 제작비 약 700만 원 + 누적 월 관리비 |

| `docs/04_영업스크립트.md` | 방문·전화·문자·DM 대본, 거절 대응 | 영업할 때 |

> 파일 여는 법: `.html` 파일은 **더블클릭하면 인터넷 창(크롬 등)에서 바로 열립니다.** `.md` 파일은 GitHub에서 보면 표/목차가 예쁘게 보입니다.

## 따라하기 5단계

1. **가게 찾기 (30분)** — `docs/02_고객발굴.md`의 방법으로 후보 10곳을 찾아 `tools/lead-tracker.html`에 입력
2. **정보 모으기 (가게당 5분)** — 상호, 주소, 전화, 영업시간, 대표 메뉴, 좋은 리뷰 3개, 사진 3~5장
3. **홈페이지 만들기 (가게당 10~30분)** — 두 가지 방법 중 선택
   - 쉬운 방법: `template/index.html` 맨 위 `SITE` 부분의 글자만 바꾸기
   - 고급 방법: `docs/03_제작프롬프트.md`의 명령문을 Claude에 붙여넣기
4. **미리보기 링크 만들기 (5분)** — [app.netlify.com/drop](https://app.netlify.com/drop)에 폴더를 끌어다 놓으면 무료 주소 생성
5. **보여주고 팔기** — `docs/04_영업스크립트.md` 대본대로 사장님께 휴대폰으로 보여주기 → 계약은 `docs/05_계약_운영.md`

## 꼭 지킬 것 (중요)

- 미리 만든 홈페이지는 **사장님 허락 전까지 검색에 노출하지 말 것** (견본 템플릿에 검색 차단 설정이 기본으로 들어가 있음)
- 가게 사진·로고·리뷰는 **계약 후 사장님 동의를 받고** 정식 사용
- 공식 가게 사이트인 것처럼 속이거나, 거절한 가게에 계속 연락하지 말 것
- 수입이 생기면 **사업자등록 + 종합소득세 신고** (자세한 내용은 `docs/05_계약_운영.md`)
