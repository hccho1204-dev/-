## 2. 올리는 순서 (따라 하기)

1. 인스타그램에서 **＋ → 게시물** 누르기
2. 카드 이미지 선택 → **다음**
3. **음악 추가**: 잔잔한 피아노나 어쿠스틱 곡 (인스타그램 추천곡 중에서 고르기)
4. 위 본문을 그대로 **복사 → 붙여넣기**
5. **공유** 누르기

## 4. 꼭 지킬 원칙

| 원칙 | 이유 |
|---|---|
| **직접 만든 카드만** 올리기 | 남의 게시물 재업로드는 수익화 제외·계정 정지 위험 |
| 돈·제도 정보는 **공식 사이트에서 확인** 후 게시 | 금액·조건은 해마다 바뀜 (복지로, 보건복지부, 국민연금공단) |
| 건강 정보는 **"의사와 상담하세요"** 문구 넣기 | 잘못된 의료 정보는 신고 대상 |
| 하루 **1~3개**부터 시작 | 꾸준함이 개수보다 중요. 익숙해지면 늘리기 |
| 같은 디자인 틀 유지 | 계정이 한눈에 알아보이면 팔로우가 늘어남 |
