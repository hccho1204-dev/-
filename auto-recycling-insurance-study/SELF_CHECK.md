# ✅ 자기점검(팩트체크) 원칙 — 강의 발송 전 반드시 수행

매 강의는 아래 5단계를 통과한 뒤에만 보낸다. 강의 맨 끝에 **자기점검 결과표**를 반드시 붙인다.

| 단계 | 점검 내용 | 통과 기준 |
|---|---|---|
| 1. 출처 확인 | 숫자·법·날짜마다 출처가 있는가? | 출처 링크 1개 이상 |
| 2. 교차 확인 | 중요한 숫자는 2곳 이상에서 확인했는가? | 기관마다 다르면 "범위"로 표기 |
| 3. 최신성 | 법·제도가 지금도 유효한가? (개정·시행일) | 시행일/발표일 명시 |
| 4. 쉬운 말 | 비개발자·비전문가가 이해할 수 있는가? | 전문용어는 괄호로 풀이 |
| 5. 보험 연결 | 오늘 내용이 '보험 참여'와 연결되는가? | "보험 포인트" 섹션 필수 |

## 신뢰도 표시
- ✅ **확인됨**: 공식 기관·법령·원문 또는 2개 이상 출처 일치
- ⚠️ **추정/범위**: 시장조사기관 추정치, 출처마다 차이 있음
- ❓ **추가 확인 필요**: 보도만 있고 원문 미확인 → 실제 사업 결정 전 재확인
