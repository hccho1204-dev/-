# 12일차 — 재활용 소재(철·알루미늄·플라스틱): 재생 플라스틱 의무가 왜 중요한가? (2026-10-17)

## 어제 퀴즈 정답
1. **SoH**(State of Health, 배터리 건강 상태).
2. **과거(사용 이력)를 모른다** → 위험을 계산할 데이터가 없다.
3. **새 배터리**였다. 재사용 배터리가 아니었는데도 큰 화재가 났기 때문에, 재사용 배터리는 더 엄격하게 봅니다.

> ⏱ 읽는 시간 12분 · 오늘의 한 줄: **"폐차에서 철은 이미 '돈'이고, 알루미늄은 '큰 돈'이고, 플라스틱은 '골칫거리'였다. 유럽이 재생 플라스틱 사용을 법으로 강제하면서, 골칫거리가 '팔리는 원료'로 바뀌기 시작했다."**

## 1. 오늘 꼭 알아야 할 3가지

| # | 핵심 | 쉬운 설명 |
|---|---|---|
| 1 | 철·알루미늄은 **이미 잘 재활용**된다. 특히 알루미늄은 새로 만들 때보다 **에너지를 약 90~95% 덜** 쓴다 | 금속은 녹여서 다시 쓰기 쉽고 값도 나간다 |
| 2 | 플라스틱은 종류가 섞이고 값이 싸서 **재활용이 잘 안 됐다** → 파쇄잔재물(ASR)로 매립·소각 | 2일차의 '마지막 5%' 문제의 주범 |
| 3 | 유럽은 새 차에 **재생 플라스틱 15%(2032년 9월~) → 25%(2036년 9월~)** 를 의무화. 그중 일부는 **폐차에서 나온 플라스틱**이어야 함 | "재활용 플라스틱을 꼭 사서 써라" → 폐차 플라스틱에 **수요**가 생김 |

## 2. 폐차 소재별 '성적표'

| 소재 | 재활용 상태 | 이유 |
|---|---|---|
| **철** | 잘 됨 | 자석으로 쉽게 골라낼 수 있고, 고철값이 있음. 폐차 보상금의 대부분이 고철값(2일차) |
| **알루미늄** | 잘 됨, 값도 높음 | 새로 만들려면 전기를 엄청 써야 해서, 재활용하면 에너지 약 90~95% 절감 |
| **구리 등 비철금속** | 잘 됨 | 값이 비싸서 분리할 이유가 충분 |
| **플라스틱** | 잘 안 됨 | 종류가 수십 가지로 섞여 있고, 새 플라스틱이 싸서 재생 플라스틱이 경쟁력이 없었음 |
| **유리·고무** | 잘 안 됨 | 값이 낮아 분리 비용이 더 듦(2일차) |

> ※ **재생원료(재생 소재)** = 버려진 제품에서 회수해 다시 원료로 만든 것. '버려진 뒤'에 나온 것만 인정하는 경우가 많습니다(공장에서 나온 자투리는 제외).

## 3. 세계: 유럽이 판을 바꾸다

| 항목 | 내용 |
|---|---|
| 규정 | **(EU) 2026/1738**, 2026년 7월 관보 게재, **8월 13일 발효**(4일차) |
| 재생 플라스틱 | 형식승인 기준 **2032년 9월 1일부터 15%**, **2036년 9월 1일부터 25%**(무게 기준) |
| 폐차 출신 비율 | 재생 플라스틱 중 **최소 20%** 는 폐차·중고 부품에서 회수한 것이어야 한다고 보도 (정확한 문구는 원문 확인 필요) |
| 철·알루미늄 | 유럽 집행위가 **2033년 8월까지** 재생 철강·알루미늄 최소 비율을 정하기로 함 |
| 인정 범위 | '소비 후(버려진 뒤)' 재생원료만 인정 |
| 업계 반응 | 부품업체들이 재생 플라스틱 확보 경쟁 시작 |

> ▶ 연결 고리: 1일차에서 "15%(약 6년 후), 25%(약 10년 후)"라고 배웠는데, 정확히는 **2032년 9월, 2036년 9월**부터 새로 승인받는 차종에 적용됩니다.

## 4. 한국은?

| 항목 | 내용 |
|---|---|
| 자동차 재생원료 의무 | **아직 확인된 의무 비율 없음**(이번 조사 기준) |
| 다른 분야 | 2026년 PET(음료병 등) 재생원료 10% 의무, 화장품 용기 등 PE·PP로 확대 예고. 정부 목표: 2030년 재생원료 200만 톤 사용 |
| 의미 | 한국 자동차·부품 회사도 **유럽에 수출하려면** 유럽 기준을 맞춰야 함 → 국내 폐차 플라스틱에도 수요가 생길 가능성 |

## 5. [보험 포인트] 소재가 '돈'이 되면 위험도 커진다

| 위험 | 실제 사례 | 보험 기회 |
|---|---|---|
| ① 파쇄장 화재 | 2025년 2월 미국 뉴저지 캠던의 대형 고철 파쇄 시설에서 큰 화재, **리튬이온 배터리**가 원인으로 추정. 2026년 5월 또 화재로 운영 중단. 2025년 5월 독일 올덴부르크 고철장 화재에 소방관 230명 이상 투입, 차량 수백 대 소실 | 파쇄·고철장 **화재보험 + 영업중단손해**. 배터리 분리 절차를 갖춘 곳이 보험 조건에서 유리 |
| ② 주민·환경 피해 | 캠던 화재 때 검은 연기로 주민 약 100명 대피, 시 의회가 운영 재개 여부 심사 | **환경오염·제3자 배상책임보험**. 사고 후 영업 허가까지 흔들릴 수 있음 |
| ③ 원료 품질 분쟁 | 재생 플라스틱이 '폐차 출신'인지, 규격에 맞는지 증명 필요 | 재생원료 공급업체의 **제품 배상·품질 보증** 관련 보험(18일차) |
| ④ 가격 변동 | 고철·알루미늄 시세에 따라 폐차장 수익이 크게 흔들림 | 보험으로 막기 어려운 위험 → 고객 상담 시 "보험으로 되는 것/안 되는 것" 구분이 신뢰를 줌 |

> ▶ 오늘의 생각거리: "폐차 플라스틱이 '쓰레기'에서 '팔리는 원료'가 되면, 폐차장 사장님의 창고에는 무엇이 더 많이 쌓일까? 그것은 어떤 새로운 위험을 만들까?"

## 6. 오늘의 용어 5개

| 용어 | 뜻 |
|---|---|
| 재생원료 | 버려진 제품에서 회수해 다시 만든 원료 |
| 소비 후(post-consumer) | 소비자가 쓰고 버린 뒤 나온 것. 유럽 재생 플라스틱 의무에서 인정하는 기준 |
| 닫힌 순환(closed loop) | 자동차에서 나온 소재를 다시 자동차에 쓰는 것 |
| 파쇄장(슈레더) | 차체를 잘게 부숴 금속을 골라내는 시설. 화재 위험이 큼 |
| 형식승인 | 새 차 모델이 판매 전에 받는 정부 승인. 유럽 재생 플라스틱 의무는 이 시점을 기준으로 적용 |
