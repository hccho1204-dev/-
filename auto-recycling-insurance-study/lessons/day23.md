# 23일차 — 데이터의 힘 (보험개발원·사고이력): 보험사는 무엇을 보고 값을 매기나? (2026-10-28)

## 어제 퀴즈 정답
1. **Ageas UK**(2020년 잔존물 처리 + 그린 부품 사업 통합).
2. **CAPA** 인증(미국 비순정 부품 품질 인증 기관).
3. **데이터의 힘**(보험개발원·사고이력) — 바로 오늘!

> ⏱ 읽는 시간 12분 · 오늘의 한 줄: **"보험은 결국 '숫자 장사'다. 사고차가 어디로 갔는지, 어떤 부품으로 고쳤는지, 그 사업장이 사고를 얼마나 냈는지 — 이 기록이 쌓일수록 보험료는 정확해지고, 기록을 가진 사람이 협상력을 가진다."**

## 1. 오늘 꼭 알아야 할 3가지

| # | 핵심 | 쉬운 설명 |
|---|---|---|
| 1 | 한국 **보험개발원**은 보험사들이 낸 사고·보험금 자료를 모아 **통계·요율 기준**을 만들고, **카히스토리**로 중고차 사고·침수 이력을 공개 | 보험업계 공동 '데이터 창고' |
| 2 | 미국은 보험사가 전손·잔존물 차량을 **매달 정부 시스템(NMVTIS)** 에 신고해야 함(위반 시 건당 벌금) | 사고차가 '세탁'되어 몰래 팔리는 것을 막는 장치 |
| 3 | 데이터는 **"위험을 줄였다는 증거"** 가 됨. 재활용 사업장도 사고·점검 기록이 있어야 좋은 보험 조건을 받음(19·20일차) | 기록 = 보험료 협상 카드 |

## 2. 쉬운 설명: 보험 데이터는 어떻게 흐르나?

| 단계 | 일어나는 일 | 데이터가 쌓이는 곳 |
|---|---|---|
| ① 사고 | 보험금 청구, 수리비 산정 | 각 보험사 → **보험개발원**에 제출 |
| ② 판정 | 수리 vs 전손(16일차) | 차량기준가액, 수리비 통계 |
| ③ 잔존물 | 전손차 매각·폐차 | 한국: 카히스토리 전손·침수 이력 / 미국: **NMVTIS** 신고 |
| ④ 수리 | 어떤 부품(순정·대체·중고)으로 고쳤나 | 수리비 데이터 → 부품 정책(17·22일차) |
| ⑤ 요율 | 다음 해 보험료 계산 | 통계를 바탕으로 보험사별 요율 결정 |

> ※ 요율 = 보험료를 계산하는 기준 가격표. "이런 차, 이런 사람, 이런 사업장은 얼마" 하는 표.

## 3. 세계는?

| 항목 | 내용 |
|---|---|
| 미국 NMVTIS(국가 자동차 이력 시스템) | 보험사는 **당해 연식 + 직전 4개 연식** 차량 중 전손·잔존물로 판정한 차를 **최소 매달** 신고. 차대번호(VIN), 판정 날짜, 인수처 등을 보고. 위반 시 **건당 1,000달러** 민사 벌금(2026년 연방관보 공지) |
| 미국 CCC 보고서(2026) | 2025년 수리 1건당 평균 수리비 **4,818달러**(+1.7%), 전손 비율 **23.1%로 사상 최고** |
| 대체부품 비중 | 2025년 교체 부품 금액 중 **비순정(대체) 부품 22.7%로 역대 최고**, 순정(OEM) 63.5% (CCC) |
| 텔레매틱스(주행 데이터) | 속도·급제동·주행거리 같은 운전 데이터로 보험료를 매기는 방식 확산. 북미 시장 2026년 약 1.4억 달러 → 2031년 약 4.7억 달러 전망(시장조사기관 추정) |

> ▶ 5일차·22일차의 숙제 해결: "미국 대체부품 비중 사상 최고"는 **CCC 2026 보고서의 22.7%** 로 확인됨. 단, **중고(재활용) 부품 비중**은 이번에도 찾지 못함.

## 4. 한국은?

| 항목 | 내용 |
|---|---|
| 보험개발원 역할 | 보험사가 제출한 사고 정보로 통계를 만들고, 카히스토리(중고차 사고이력) 운영 |
| 카히스토리 | **침수차 조회 무료**(차량번호·차대번호). 사고·소유 변경 등 종합 이력은 유료 |
| 침수 통계 | 최근 5년(2020~2024) 차량 침수 **3만6,214건**, 이 중 **전손 2만6,799건(74.0%)**. 7~10월에 95.6% 집중 |
| 한계 | **자비로 수리한 사고는 기록에 없음** → 국토교통부 '자동차365'(등록·검사·정비 이력)와 함께 보기 권장 |
| 해외 연계 | 2023년 보도: 중동 수출 중고차에 사고이력 정보 제공 시작 |
| 주행 데이터 특약 | 티맵·카카오내비 안전운전 점수 할인(UBI), 커넥티드카 할인 특약 등 운영 — 할인율은 보험사마다 다름 |

## 5. [보험 포인트] 재활용 사업에서 '데이터'로 돈 버는 법

| 데이터 | 누가 원하나 | 내가 할 수 있는 일 |
|---|---|---|
| 사업장 사고·점검 기록(화재 감지, 교육, 배터리 보관) | 보험사 인수 심사자 | 폐차장 고객에게 **"기록 노트"** 를 만들어 주고 갱신 때 제출 → 보험료 협상(19일차) |
| 잔존물 이력(전손차가 어디로 갔나) | 보험사, 중고차 구매자 | 전손차가 정식 폐차·재활용으로 갔다는 **추적 자료** = 신뢰 상품 |
| 부품 사용 기록(중고·대체·재제조) | 보험사 손해율 담당 | 정비소의 친환경 부품 사용 실적 → **탄소 감축·수리비 절감 증거**(13·22일차) |
| 침수·전손 이력 | 중고차 수출업체, 소비자 | 카히스토리 조회를 영업 도구로: "이 차는 이력 깨끗합니다" |

**영업 한 줄**
> "사장님, 보험사는 '말'보다 '기록'을 믿습니다. 지난 1년 사고 0건, 화재 점검 12회 기록이 있으면 갱신 때 조건을 다시 협상할 수 있습니다. 기록 정리는 제가 도와드릴게요."

> ▶ 오늘의 생각거리: "내 첫 고객(폐차장·정비소)에게 **어떤 기록 3가지**를 모으자고 하면, 보험사도 고객도 둘 다 이득일까?"
