# 4일차 — 유럽 EU 폐차 규정: 왜 유럽이 규칙을 만드는가? (2026-10-10)

## 어제 퀴즈 정답
1. **새 부품**. 품질인증부품은 재활용이 아니라 순정품보다 싼 새 부품입니다.
2. **출고 5년 이내 새 차**, 그리고 **안전 부품**(브레이크·휠·조향장치 등).
3. **25%**. 외장 부품을 대체부품으로 고치면 순정 가격의 25%를 돌려받습니다.

> ⏱ 읽는 시간 12분 · 오늘의 한 줄: **"유럽의 새 폐차 규정은 '차를 만들 때부터 버릴 때까지' 전부를 묶는다. 그리고 보험사에게 '이 사고차는 폐차인가, 중고차인가'를 판단하는 무거운 숙제를 줬다."**

## 1. 오늘 꼭 알아야 할 3가지

| # | 핵심 | 쉬운 설명 |
|---|---|---|
| 1 | 유럽은 25년 된 '폐차 지침'을 버리고 **더 강한 '규정'**(Regulation (EU) 2026/1738)을 만들었다. 2026년 8월 13일 발효 | '지침'은 나라마다 법을 따로 만들어야 하지만, '규정'은 유럽 전체에 그대로 바로 적용됩니다 |
| 2 | 핵심은 **설계부터 재활용까지 한 번에** 관리하는 것 | 재생 플라스틱 의무, 차량 디지털 여권, 자동차 회사 책임 확대, 고장 난 차 수출 금지 |
| 3 | **'사라지는 차'** 문제를 막으려는 법이다 | 유럽에서 매년 약 340만~470만 대가 등록 말소된 뒤 어디로 갔는지 알 수 없음 |

## 2. 왜 이런 법이 생겼나: '사라지는 차' 문제

1. 차주가 차 등록을 지움(말소)
2. 그런데 그 차가 **정식 폐차장에서 처리됐다는 기록이 없음**
3. 어디로 갔나? → 불법 해체장, 또는 **아프리카·중동 등으로 '중고차'라는 이름으로 수출**
4. 결과: 유해물질이 제대로 처리되지 않고, 유럽은 철·알루미늄·희귀금속 같은 자원을 잃음

> ※ 2일차에 배운 독일의 불법 해체(연 약 36만 대)도 이 문제의 일부입니다.

## 3. 새 규정의 주요 내용과 시간표

| 내용 | 무엇이 바뀌나 | 언제부터 (발효일 2026.8.13 기준) |
|---|---|---|
| 전반 적용 | 대부분의 의무 시작 | 발효 후 약 **2년** (보도마다 표현이 달라 확인 필요) |
| 자동차 회사의 순환 전략 | 각 회사가 재활용 계획을 공개 | 발효 후 **3년** 이내 |
| 생산자 책임 확대(EPR) | 자동차 회사가 폐차 처리 비용·체계에 책임. 차가 **어느 나라에서 폐차되든** 적용 | 시작 시점은 자료마다 달라 확인 필요 |
| 고장 난 중고차 수출 금지 | **도로를 달릴 수 있는 차만** 유럽 밖으로 수출 가능 | 발효 후 **5년** |
| 재생 플라스틱 | 새 차에 15% → 25%, 그중 일부는 폐차에서 나온 플라스틱 | 약 **6년 / 10년** 후 (2032년 / 2036년) |
| 디지털 순환 여권 | 모든 새 차에 '디지털 여권'(어떤 소재·부품이 들어갔는지 기록). 차주·정비소·재활용업체는 무료로 열람 | **2032년 9월 1일** |
| 적용 차종 확대 | 승용차·소형 화물차 → 트럭·버스·오토바이까지 | 단계적 |

> ※ **디지털 순환 여권** = 차의 '성분표'를 디지털로 담은 것. 재활용업체가 이걸 보면 어떤 부품을 떼어 다시 쓸 수 있는지 바로 압니다.

## 4. [보험 포인트] 유럽 보험업계가 걱정하는 것

새 규정은 **"이 차는 폐차(=쓰레기)인가, 고칠 수 있는 중고차인가"** 를 가르는 기준을 정합니다. 폐차로 판정되면 **반드시 정식 폐차장으로 가야 하고, 중고차로 팔거나 수출할 수 없습니다.**

| 구분 | 뜻 | 보험업계 입장 |
|---|---|---|
| **기술적 전손** | 물리적으로 고칠 수 없음 (예: 차체가 완전히 찌그러짐) | "이것만 폐차로 봐야 한다" |
| **경제적 전손** | 고칠 수는 있지만 수리비가 차값보다 비쌈 | "폐차로 자동 분류하면 안 된다. 수리비는 정비소·부품·차 나이에 따라 달라지는 숫자일 뿐" |

**유럽 보험업계(Insurance Europe, 독일 GDV)의 3가지 우려**
1. **판단 책임**: 보험사(또는 보험사가 고용한 손해사정인)가 "이 차는 폐차"라고 판정해야 하는 부담. 독일 GDV는 "보험금 심사를 넘어서는 일이다. 차주·정부·정식 폐차장이 정해야 한다"고 주장
2. **사고차 활용 제한**: 지금은 보험사가 사고차(잔존물)를 경매로 팔아 보험금 일부를 회수하는데, 폐차로 분류되면 그 길이 막힐 수 있음
3. **해결책 제안**: 수리비를 계산할 때 **중고·재활용 부품 가격도 넣을 수 있게** 해달라 → 그러면 수리비가 내려가서 '경제적 전손'이 줄어듦

> ▶ 연결 고리: 3일차에 배운 "어떤 부품을 쓰느냐가 수리비를 바꾼다"가 여기서 **'폐차냐 아니냐'까지 바꾸는 문제**로 커집니다.

**한국에 주는 힌트**
- 한국도 2일차에서 본 것처럼 전손차 일부가 불법 경로로 흘러간 과거가 있습니다
- 유럽처럼 **"전손 판정 → 폐차장 연결 → 기록"** 이 규칙으로 묶이면, 그 과정을 **투명하게 관리·증명해주는 서비스**의 가치가 커집니다
- 단, 2일차 Q&A에서 확인했듯 한국에서 **무등록 중개는 불법**이므로, 등록 폐차장·보험사와 손잡는 형태여야 합니다

## 5. 오늘의 용어 5개

| 용어 | 뜻 |
|---|---|
| 지침(Directive) vs 규정(Regulation) | 지침은 각 나라가 자기 법으로 옮겨야 하고, 규정은 유럽 전체에 그대로 바로 적용 |
| 생산자 책임 확대(EPR) | 물건을 만든 회사가 버려질 때의 처리까지 책임지는 제도 |
| 디지털 순환 여권 | 차에 들어간 소재·부품 정보를 담은 디지털 기록 |
| 기술적 전손 | 물리적으로 고칠 수 없는 상태 |
| 경제적 전손 | 고칠 수는 있지만 수리비가 차값보다 비싼 상태 |
