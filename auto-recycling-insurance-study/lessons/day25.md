# 25일차 — B2B 상품 기획: 재활용 사업장 패키지 — 한 장 견적표에 무엇을 담을까? (2026-10-30)

## 어제 퀴즈 정답
1. **GA**(법인보험대리점).
2. **1200%룰**(첫해 수수료 = 월 보험료의 12배 이내).
3. **Criterion**(영국 OneAdvent 계열 인수대행사).

> ⏱ 읽는 시간 12분 · 오늘의 한 줄: **"패키지는 '보험 상품을 많이 넣은 것'이 아니라 '사장님이 밤에 걱정하는 사고 순서대로 줄 세운 것'이다. 불(재산) → 멈춤(휴업) → 남에게 준 피해(배상·환경) → 직원·운송 → 새 의무(배터리)."**

## 1. 오늘 꼭 알아야 할 3가지

| # | 핵심 | 쉬운 설명 |
|---|---|---|
| 1 | 국내에는 화재·기계·**기업휴지**·배상책임을 한 증권에 묶는 **재산종합보험(패키지)** 이 이미 있음 | 새 상품을 '발명'할 필요 없이 **기존 상품을 업종에 맞게 조합**하면 됨 |
| 2 | 해외는 재활용 업종 **전용** 패키지가 생김(영국 Hiscox 인수 재산·설비·휴업 패키지, 2026년 4월 Wasteinsure 재출시 보도) | 보험사가 빠진 시장 → 전문 상품이 빈자리를 채움 |
| 3 | 패키지의 핵심은 **보험료보다 '인수 조건'**: 화재 감지·진압 설비, 배터리 분리 보관, 기록 | 19·23일차 '증거 패키지'를 상품 안에 넣는 것 |

## 2. 쉬운 설명: 폐차장·재활용 사업장 패키지 설계도

| 순서 | 사장님의 걱정 | 담보(보장 항목) | 배운 날 |
|---|---|---|---|
| ① | "공장이 다 타면?" | **화재·재산**(건물·설비·재고), 기계 고장 | 15·19일차 |
| ② | "불난 뒤 몇 달 문 닫으면?" | **기업휴지**(멈춘 기간의 이익·고정비) | 15일차 |
| ③ | "옆 공장·지나가던 사람이 다치면?" | **영업배상책임**(제3자 신체·재물) | 15일차 |
| ④ | "기름·냉매가 땅에 스며들면?" | **환경오염배상책임**(정화 비용·주민 피해) | 19일차 |
| ⑤ | "판 중고·재제조 부품이 사고를 내면?" | **생산물배상책임(PL)** | 18일차 |
| ⑥ | "직원이 해체 작업 중 다치면?" | 산재보험 + **사용자배상책임**(근재) | 19일차 |
| ⑦ | "배터리를 실어 나르다 불나면?" | 적재물·화물보험, 운송 배상 | 20일차 |
| ⑧ | "2027년 재사용 배터리 의무보험은?" | **재사용사업자 의무보험(공제)** — 시행령 확정 후 추가 | 20일차 |

## 3. 3단계 패키지 예시 (판매용 메뉴판)

| 등급 | 담는 것 | 맞는 고객 |
|---|---|---|
| **기본** | ① 화재·재산 + ③ 영업배상 | 소규모 폐차장, 첫 가입 고객 |
| **표준** | 기본 + ② 기업휴지 + ④ 환경오염배상 + ⑥ 근재 | 중견 폐차장·재활용 선별장 |
| **확장** | 표준 + ⑤ PL + ⑦ 운송 + ⑧ 배터리 | 부품 판매·배터리 회수·수출 업체 |

> ※ 실제 보험료·가입 한도는 보험사 심사(현장 조사)로 정해짐. 이 표는 **설계 순서**를 보여 주는 예시.

## 4. 세계는?

| 사례 | 내용 |
|---|---|
| 영국 DILM + Hiscox | 재활용·폐기물 사업장용 **재산·설비·휴업** 패키지(Waste Insure, Recyclesure) |
| 영국 Wasteinsure | 2026년 4월 재활용·폐기물 업종 보험 서비스 **재출시**(스킵 대여, 선별장, 처리 시설 등) |

| 미국 업계 | 보험사가 받아 줄지 말지는 **화재 감지·진압 기술**이 가르는 경우가 많음 |

## 5. 한국은?

| 항목 | 내용 |
|---|---|
| 재산종합보험 | 화재·기계·기업휴지·배상책임을 한 증권으로 통합(주로 중·대형 사업장 대상), 함께 들면 할인 효과 |
| 기업휴지 가입률 | 약 **21%**, 중소기업은 더 낮음(보험연구원 보고서 인용 보도, 과거 자료) |
| 환경책임보험(의무) | 위험도별 가입금액 **가군 300억·나군 100억·다군 50억**(소기업 나군 80억·다군 30억). 지정폐기물 처리시설 등이 대상 |
| 재활용 시설 화재 | 포항 재활용선별장(2025.10, 자연발화 추정·한 달 새 2번째), 원주(2026.2)·대구(2026.8) 재활용 업체 화재 보도 |
| 폐차장 의무보험 해당 여부 | 자동차 해체재활용업이 환경책임보험 의무 대상인지 **여전히 미확인** → 28일차 |

## 6. [보험 포인트] 패키지 제안서 1장 만드는 법

| 칸 | 내용 |
|---|---|
| 1. 사업장 진단 | 면적, 보관 차량 수, 배터리 보관량, 최근 3년 사고 |
| 2. 위험 순위 | 불 → 멈춤 → 배상 → 환경 → 직원·운송 |
| 3. 등급 선택 | 기본/표준/확장 중 추천 + 이유 |
| 4. 조건 개선 | 열감지 카메라, 배터리 격리 구역, 소화 설비, 기록 노트(23일차) |
| 5. 비교 | 2~3개 보험사 조건 비교(GA의 강점, 24일차) |
| 6. 갱신 약속 | 매년 사고·점검 기록으로 조건 재협상 |

**영업 한 줄**
> "사장님, 보험을 여러 개 따로 드는 대신 '불 → 영업 중단 → 남에게 준 피해' 순서로 한 장에 정리해 드릴게요. 빠진 구멍이 어디인지 한눈에 보입니다."

> ▶ 오늘의 생각거리: "내 첫 고객이 '기본'만 원한다면, 다음 갱신 때 '표준'으로 올리게 만드는 **한 가지 근거**는 무엇일까?"
