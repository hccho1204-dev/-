# 인스타그램 캡션 — 버팀에 관한 다섯 문장

## A안 · 기본형 (추천, 저장 유도)
```
오늘 걷다가 마음에 새긴 다섯 문장 🌾

1. 익을수록 고개를 숙이는 벼처럼, 버틴 시간은 조용히 여문다.
2. 물결이 흔들려도 집은 제자리를 지킨다.
3. 끝이 보이지 않는 길도 한 걸음씩 가면 결국 닿는다.
4. 깊은 맛은 모두 시간을 견딘 것들이다.
5. 흔들려도 괜찮다, 멈추지만 않으면 된다.

지치는 날 다시 꺼내 보도록 저장해 두세요 📌
가장 와닿은 문장 번호를 댓글로 남겨주세요 💬

#좋은글 #오늘의문장 #명언 #버팀 #힐링글귀 #가을풍경 #산책
```

## B안 · 짧은형
```
흔들려도 괜찮다,
멈추지만 않으면 된다. 🍂

오늘도 버티는 당신을 응원합니다.

#좋은글 #오늘의문장 #힐링 #버팀
```

## C안 · 이야기형 (공감 유도)
```
요즘 마음이 자꾸 흔들려서
일부러 천천히 걸었습니다.

누렇게 익은 벼, 물 위의 작은 집,
끝이 안 보이던 나무 길, 오래 익어가는 장독들.

다 버틴 것들이더라고요.

흔들려도 괜찮습니다.
멈추지만 않으면 됩니다. 🌾

당신의 오늘은 어땠나요?

#좋은글 #산책기록 #오늘의문장 #버팀 #가을 #힐링
```

## 올릴 때 팁
| 항목 | 방법 |
|---|---|
| 커버 | 13~16초 "흔들려도 괜찮다" 장면 |
| 첫 줄 | 피드에서는 첫 1~2줄만 보이므로 가장 강한 문장을 맨 위에 |
| 해시태그 | 5~7개 |
| 시간대 | 출근길(오전 7~8시)이나 잠들기 전(밤 10~11시) |
| 고정 댓글 | "1~5 중 몇 번이 와닿으셨나요?" → 댓글이 늘어날수록 노출에 유리 |
