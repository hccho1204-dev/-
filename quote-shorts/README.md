# 버팀에 관한 다섯 문장 — 명언 쇼츠 모션그래픽 (20초)

위 고정 제목 + 가운데 사진 + 노란 자막이 한 글자씩 써지는 쇼츠 형식. 세로 9:16 / 가로 16:9.

| 시간 | 사진 | 문장 |
|---|---|---|
| 0~3.3초 | 벼 들판 | 익을수록 고개를 숙이는 벼처럼, 버틴 시간은 조용히 여문다. |
| 3.3~6.7초 | 호수 위 집 | 물결이 흔들려도 집은 제자리를 지킨다. |
| 6.7~10초 | 나무 데크길 | 끝이 보이지 않는 길도 한 걸음씩 가면 결국 닿는다. |
| 10~13.3초 | 장독대 | 깊은 맛은 모두 시간을 견딘 것들이다. |
| 13.3~16.7초 | 호수와 도시 | "운명은 흔들리는 사람을 밀고, 버티는 사람을 비켜 간다." |
| 16.7~20초 | 엔딩 | 오늘도 버티는 당신을 응원합니다 · BLESS INSIGHT |

문장 수정: index.html 의 `SCENES` 만 고치면 됩니다.

```
python3 music.py   # 72BPM 로파이 피아노 (직접 합성, 저작권 걱정 없음)
node render.js     # out/quote_9x16.mp4, out/quote_16x9.mp4
```
