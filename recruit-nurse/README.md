# 의료 경력자 리크루팅 영상 (20초)

간호사·간호조무사·요양보호사 같은 의료 경력자가 인스타를 넘기다 **"이건 내 얘기다"** 하고 멈추게 만드는 영상입니다.

- **첫 문장**: "3교대 끝나고, 아이 얼굴 볼 시간이 없을 때"
- **음악**: 0~8초는 잔잔한 밤 분위기(시계 초침 소리, 심장 박동), 8초에 밝게 터지는 120 BPM 곡입니다. 코드로 직접 만들어서 상업적으로 써도 됩니다.
- **비율**: 세로 9:16 (릴스·광고용, 주력), 가로 16:9
- **주의**: 수입을 약속하는 문구는 넣지 않았습니다 (보험 리크루팅 광고 주의사항).

## 스토리보드

| 시간 | 장면 | 내용 |
|---|---|---|
| 0~4초 | 밤 · 시계 | 근무가 DAY → EVENING → NIGHT로 돌고, 시계가 아침 7시 퇴근에서 멈춤 · **3교대 끝나고,** |
| 4~8초 | 밤 · 근무표 | **아이 얼굴 ♥ 볼 시간이 없을 때,** · N N E D N E N 근무표 · "이번 주도, 다음 주도." |
| 8~11초 | 전환 (음악 터짐) | 의료 십자 배지 · **당신의 의료 경력이 무기가 되는 곳** |
| 11~14초 | 경력 매칭 | 의료 지식 → 보장 설명 전문가 / 환자 응대 → 고객 신뢰 / 공감 능력 → 상담 경쟁력 |
| 14~16초 | 지원 | BLESS본부가 함께합니다: 매일 고객 DB 제공 · 1:1 전담 멘토링 · AI 자동화 도구 |
| 16~20초 | 행동 | **의료 경력자 상담 받습니다** · @incarvip_bless DM 주세요 · "아이와의 아침을 되찾는 시작" |

※ 11~16초 문구는 블로그 글 「간호사가 보험설계사로 이직하면 좋은 이유」의 내용을 그대로 옮겼습니다.

## 활용 전략 (리크루팅 흐름)

| 단계 | 쓸 영상 | 올릴 곳 |
|---|---|---|
| ① 멈춤 | **이 영상** | 인스타 릴스, 광고 |
| ② 확인 | 쇼릴 + 키네틱 소개 영상 | 인스타 프로필 상단 고정 |
| ③ 결심 | 블로그 글 (간호사 이직) | 프로필 링크 |
| ④ 기대 | 키네틱 소개 영상 | 미팅 확정 문자에 첨부 |
