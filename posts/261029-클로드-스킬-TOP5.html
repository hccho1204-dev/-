GITHUB · CLAUDE SKILLS

요즘 깃허브에서 제일 많이 쓰는 클로드 스킬 5

스킬은 클로드에게 끼워 주는 '업무 매뉴얼'입니다. 한 번 설치하면 클로드가 그 방식대로 일합니다.

  1. 1

    슈퍼파워즈 Superpowers

    개발 순서

    기획 → 개발 → 테스트 → 리뷰까지 순서를 잡아 줍니다.

    이럴 때 클로드가 일을 건너뛰거나, 만들다 말고 엉뚱한 데로 샐 때.

    ★ 30만+ (원고 기준)
  2. 2

    앤트로픽 공식 스킬 Anthropic Skills

    문서 제작

    워드·엑셀·PPT·PDF 파일을 바로 만들어 줍니다.

    이럴 때 보고서, 견적표, 발표 자료를 파일로 바로 받아야 할 때.

    클로드 만든 회사가 직접 배포
  3. 3

    UI UX Pro Max

    디자인 규칙

    색·글꼴·여백 같은 디자인 규칙을 넣어 줍니다.

    이럴 때 홈페이지나 앱 화면이 "뭔가 허술해 보일" 때. 완성도가 확 올라갑니다.

    화면 만드는 작업 전용
  4. 4

    케이브맨 Caveman

    토큰 절약

    원시인처럼 짧게 말하게 해서 토큰(사용량)을 아껴 줍니다.

    이럴 때 사용 한도가 금방 차거나, 긴 설명 없이 결과만 받고 싶을 때.

    "나 고침. 버그 없음." 같은 말투
  5. 5

    테이스트 스킬 Taste Skill

    AI 티 제거

    AI가 만든 티가 나는 뻔한 디자인을 줄여 줍니다.

    이럴 때 보라색 그라데이션, 똑같은 카드 배치처럼 "AI가 만들었네" 소리를 듣기 싫을 때.

    랜딩페이지·포트폴리오에 효과

한눈에 비교

스킬한 줄 요약추천 대상
슈퍼파워즈개발 순서를 잡아 줌앱·프로그램 만드는 사람
앤트로픽 공식워드·엑셀·PPT 바로 생성사무·보고서 작업이 많은 사람
UI UX Pro Max디자인 규칙 주입홈페이지·화면 만드는 사람
케이브맨짧게 말해서 토큰 절약사용량 아끼고 싶은 사람
테이스트AI 티 나는 디자인 감소디자인 퀄리티가 중요한 사람

별 개수 등 숫자는 원고 기준이며, 시점에 따라 달라집니다.

설치 방법

  1. 내 컴퓨터에서 Claude Code를 엽니다.
  2. 아래 명령어를 한 줄씩 복사해 입력창에 붙여넣고 엔터를 누릅니다.
  3. Claude Code를 껐다가 다시 켭니다.

첫 줄은 "이 저장소를 목록에 추가해", 둘째 줄은 "거기서 이 스킬을 설치해"라는 뜻입니다.

슈퍼파워즈 obra/superpowers

/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

설치 후: "같이 기획부터 해 보자"처럼 말하면 알아서 작동합니다.

앤트로픽 공식 스킬 anthropics/skills

/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills

설치 후: "이 내용 PPT로 만들어 줘", "엑셀로 정리해 줘"라고 말하면 됩니다.

UI UX Pro Max nextlevelbuilder/ui-ux-pro-max-skill

/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill

설치 후: 화면·디자인을 부탁하면 자동으로 켜집니다.

케이브맨 JuliusBrussee/caveman

/plugin marketplace add JuliusBrussee/caveman
/plugin install caveman@caveman

설치 후: /caveman 입력 또는 "원시인처럼 말해". 강도는 lite · full · ultra 세 단계입니다.

테이스트 스킬 Leonxlnx/taste-skill

Claude Code 입력창이 아니라 명령창(터미널)에 입력 · Node.js 필요
npx skills add Leonxlnx/taste-skill

설치 후: "AI 티 안 나게 홈페이지 만들어 줘"라고 말하면 됩니다. 이름이 비슷한 복사본이 많으니 꼭 Leonxlnx 원본으로 설치하세요.

설치는 내 컴퓨터의 Claude Code에서 해야 남습니다. 클라우드 작업 공간은 작업이 끝나면 지워집니다.
