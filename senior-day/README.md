# 70대 어르신의 모벨릭스 하루 — 브이로그 모션그래픽 (20초, 에너지 버전)

모벨릭스 릴스(@mobelix09) 캡처 7장에서 인스타 화면 요소(상단 바, 하트·댓글 아이콘, 자막, 미리보기 창)를 잘라내고 **장면만** 써서 만든 하루 브이로그 영상입니다.

- **색**: 어르신 재킷의 주황 + 사진 속 노란 벽의 머스터드 + 크림 + 브라운
- **음악**: 132 BPM 우쿨렐레 스트럼 + 탬버린 + 마림바 + 4비트 킥, 정확히 20초, 직접 합성해서 상업적 사용 가능 (원본 릴스 음악은 쓰지 않음)
- **에너지 효과**: 사진 카드가 박자마다 통통 튐, 배경 점이 박자에 맞춰 커졌다 작아짐, 하트·음표가 계속 떠오름, 장면 전환마다 주황·노랑 링, 메시지는 한 줄씩 팡
- **캡션**: `CAPTION.md` (3가지)
- **글꼴**: Jua (무료, 상업적 사용 가능)
- **비율**: 세로 9:16 (주력), 가로 16:9
