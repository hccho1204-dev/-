# BLESS 주간회의 보드

팀원이 각자 주간 업무를 입력하면 회의실 한 화면에 실시간으로 모이고,
주간회의 자료 · 경영회의 보고 · 월간 보고서로 자동 정리되는 공유 웹페이지.

- 배포 주소: https://claude.ai/artifact/9zzCVckmWoSimFRn2KcTG1
- 저장소: 페이지 내장 공유 데이터베이스(`items` 컬렉션, 업무 1건 = 문서 1개)
- 화면: 내 업무 입력 / 회의실 화면(사람별, 상태별) / 보고서 만들기(3가지 서식, 한글·워드용 복사, HTML 파일 저장)
- 구분: 영업·계약, 상담·고객관리, 리크루팅, 교육·코칭, 조직운영, 이슈·건의 (index.html 의 `CATS`)
