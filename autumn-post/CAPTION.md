# 인스타 캡션 — 가을, 그 길 위에서

```
가을, 그 길 위에서 🍂

곧게 뻗은 길 끝에 파란 하늘이 열리고,
발끝마다 노랗게 쌓인 계절.

천천히 걸어도 괜찮은 길 위에서
오늘의 가을을 편지처럼 남겨둡니다 💌

🎵 가을 우체국 앞에서

#가을 #은행나무 #은행잎 #가을산책 #가을풍경 #단풍 #가을감성 #가을우체국앞에서
```

## 노래 넣는 법 (인스타 릴스)
1. 릴스 올리기 → 영상 선택 → 화면 위 ♫(음악) 누르기
2. "가을 우체국 앞에서" 검색 → 원하는 구간 선택
3. 볼륨 조절에서 영상 원래 소리(카메라 오디오)를 0으로 내리기
