# 모벨붕붕 추억여행 — 신나는 모션그래픽 (20초)

원본 영상(`src/source.mp4`, 사진 5장이 4초씩 넘어가는 차분한 슬라이드)의 **문구와 사진은 그대로 살리고**, 빠르고 신나게 다시 만든 버전입니다.

- **음악**: 150 BPM 통통 튀는 팝 비트 (마림바 멜로디 + 박수 + 반짝이 종소리 + '붕' 효과음), 정확히 20초, 직접 합성해서 상업적 사용 가능
- **색상**: 밤하늘 네이비 + 노랑 · 핑크 · 민트 팝 컬러
- **글꼴**: Jua (둥글고 귀여운 무료 글꼴, 상업적 사용 가능)
- **비율**: 세로 9:16 (원본과 같음, 주력), 가로 16:9

## 장면 구성 (1비트 = 0.4초)

| 시간 | 원본 문구 | 모션 |
|---|---|---|
| 0~1.6초 | (새로 추가) **모벨붕붕** | 웃는 달이 뜨고 글자가 통통, "붕!" 말풍선 2개 |
| 1.6~4.8초 | 밤이 켜지면, **추억도 깨어납니다!** | 정조테마공연장 폴라로이드가 흔들흔들, 별이 팡팡 |
| 4.8~8초 | 모벨붕붕과 **설레는 한 장면!** | 핑크 배경, 사진 두 장이 양쪽에서 착착, 하트가 떠오름 |
| 8~11.2초 | 네 바퀴에 담은 **오늘의 작은 여행** | 노랑 배경, 알록달록 바퀴 4개가 박자마다 콩콩 |
| 11.2~14.4초 | 함께한 순간이 **오래 남는 추억으로!** | "찰칵!" 플래시와 함께 사진 6장이 박자마다 쌓임 |
| 14.4~17.6초 | 모벨붕붕을 타고 **떠나는 추억여행!** | 민트 배경, 점선 길을 따라 자전거가 달리고 행궁·카페·추억 핀이 콕콕 |
| 17.6~20초 | 제품 문의는 DM으로 | 햇살 배경 + 콘페티 두 번 팡, @incarvip_bless |

## 다시 만드는 방법

```bash
cd video-fun
python3 music.py
node render.js
```
