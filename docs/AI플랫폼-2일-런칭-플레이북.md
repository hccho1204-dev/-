# AI 플랫폼 "주말 2일 런칭" 플레이북

> 출처: 유튜브 영상 전사(곽봉준 / 창업가·마케터) 요약·재구성
> 정리일: 2026-09-06
> 성격: **영상 화자의 주장 기반 정리**. 수치·모델명은 검증 필요(§7 참조)

---

## 0. 한 줄 요약

아이디어 → **쓰레드 반응 확인** → **30분 랜딩페이지** → **하루 3만원 광고 검증** → 통하면 **주말 2일 바이브코딩** → **국내/해외 결제 연동**.
비개발자가 1주일 안에 "이 아이템 될까 안 될까"를 데이터로 판정하는 절차.

---

## 1. 왜 지금인가 (전환기 반복 패턴)

| 시기 | 주력 채널 | 못 따라간 사업자 결과 |
|---|---|---|
| 초기 | 네이버 블로그 | 알고리즘 변경 → 상위노출 붕괴 |
| 중기 | 인스타그램 | 블로그만 고집한 대행사 폐업 |
| 후기 | 릴스(숏폼) | 이미지 피드만 하던 곳 이탈 |
| **지금** | **AI 개발(바이브코딩)** | **아직 안 움직인 사람** |

핵심 주장: **실력이 없어서가 아니라 "아직은 괜찮겠지"라고 안 움직여서 도태된다.**

---

## 2. 만든 것 (제품 정의)

프롬프트 한 줄 입력 → 전문가급 웹사이트 자동 생성 플랫폼.
단순 "예쁜 사이트"가 아니라 아래 3가지를 **자동 세팅**하는 것이 차별점.

| 자동화 항목 | 내용 |
|---|---|
| SEO | 구글·네이버 검색 노출 세팅 |
| AEO/GEO | ChatGPT·Claude가 우리 사이트를 추천하도록 최적화 |
| 마케팅 픽셀 | 메타·구글 픽셀 원클릭 설치 |

화자 주장: 1,000만원짜리 외주 홈페이지보다 퀄리티가 높고, 실제 사업용 사이트를 15분에 제작.

---

## 3. 검증 3단계 (개발 전에 반드시)

> 화자의 과거 실패: 몇 달 공들여 완성 → **아무도 안 씀** → 시간·돈 전부 손실.
> 그래서 "만들기 전에 검증"이 1순위 원칙이 됨.

### 3-1. STEP 1 — 쓰레드(Threads) 반응 테스트 · 비용 0원
```
이런 걸 만들려고 하는데 어떻게 생각해? 댓글 달아줘
```
- 결과: 업로드 직후 댓글 약 30개, "써보고 싶다" 반응 다수
- 판단: **관심은 있다.** 단, 좋아요 ≠ 결제

### 3-2. STEP 2 — 랜딩페이지 30분 · 비용 0원
Claude Code에 내린 지시(그대로 복사해서 쓰면 됨):
```
곧 출시할 이 플랫폼에 대기신청 명단(이메일)을 등록하는
간단한 랜딩 페이지를 만들어줘
```
그 뒤 ① 카피 수정 ② 이미지 첨부 → **총 30분 완료**

영어 못해도 되는 이유 — 추가 지시:
```
이 사이트를 해외 시장에 홍보하려고 해. 영어로 수정해줘
```

### 3-3. STEP 3 — 메타 광고 하루 3만원 · 국내 vs 해외 동시 집행

| 구분 | 클릭당 비용(CPC) | 3만원으로 도달 | 이메일 전환율 |
|---|---|---|---|
| 한국 | 250~350원 | 약 100명 | 낮음 |
| **해외** | **9원** | **약 3,000명** | **압도적으로 높음** |

→ **같은 돈·같은 노력, 시장만 바꿔서 효율 약 30배.**
→ 개발 착수 전에 "해외에서도 통한다"를 데이터로 확인.

**총 소요: 1주일 미만.** 통하면 만들고, 안 통하면 버린다.

---

## 4. 개발 (주말 2일, 바이브코딩)

### 4-1. 멀티 AI 오케스트레이션 구조

```
사용자 프롬프트 입력
        │
        ├─▶ [Claude]  → 카피라이팅 생성   (글은 Claude가 제일 잘 씀)
        ├─▶ [Gemini]  → 웹 디자인/레이아웃 (요즘 웹은 Gemini가 제일 잘 만듦)
        └─▶ [GPT Image] → 삽입 이미지 생성
                │
                ▼
        완성된 홈페이지
```
**핵심: 하나의 AI에 다 시키지 않는다. 잘하는 AI에게 각각 시킨다.**

### 4-2. "코드 흐름 이해"가 갈리는 지점 (가장 중요한 대목)

최상위 모델은 퀄리티는 좋지만 **속도가 느리고 서버가 자주 끊김.**

| 지시 방식 | 결과 |
|---|---|
| ❌ "이 문제 해결해줘" | AI가 엉뚱하게 해결함 |
| ⭕ "평소엔 최상위 모델을 쓰되, **서버가 불안정하면 자동으로 하위 모델로 전환**해라" | 안정적으로 동작 |

> 코드를 직접 짤 줄 알아야 한다는 뜻이 아니다.
> **어떤 순서로 어떤 지시를 내려야 하는지 "판단"할 수 있어야 한다는 뜻.**
> 이 판단 유무가 "팔리는 플랫폼"과 "그냥 뭔가 나온 것"의 차이.

### 4-3. 야간 배치 활용
자기 직전에 템플릿 제작 명령 → **아침에 일어나니 수준급 디자인 템플릿 40개 완성.**
(직원 19명 있을 때도 없던 경험 — 자는 동안 AI가 일함)

## 5. 결제 시스템 (수익화)

| 시장 | 수단 | 상태 | 비고 |
|---|---|---|---|
| 국내 | 토스페이먼츠 | 연동 완료 | 기존 플랫폼에서 이미 사용 중 |
| 해외 | **Lemon Squeezy** | 사업자 인증 진행 중 | 국가별 부가세·VAT를 **대신 처리** |

**해외 판매의 진짜 난관은 "돈 받기"가 아니라 "세금".**
- 나라마다 부가세율이 다르고, VAT 별도 신고가 필요한 나라도 있음
- 세무사도 각국 세법까지는 커버 못 함
- → **MoR(Merchant of Record) 방식** 결제사가 이걸 통째로 대행해 줌

## 6. 결론 — 오늘 당장 할 3가지

| # | 원칙 | 실행 |
|---|---|---|
| 1 | **개발 전에 검증** | 쓰레드 1줄 → 랜딩 30분 → 광고 3만원. 1주일이면 답 나옴 |
| 2 | **한국 시장만 볼 필요 없음** | CPC 250원 vs 9원. 영어 한 마디 몰라도 Claude가 번역 |
| 3 | **오늘 쓰레드에 한 줄 올리기** | "이런 서비스 있으면 쓸래? 댓글 줘" — 이거면 시작 |

## 7. ⚠️ 그대로 믿지 말고 검증할 것

정리하면서 확인이 필요하다고 판단한 부분입니다.

| 항목 | 왜 확인이 필요한가 |
|---|---|
| **해외 CPC 9원** | 메타 광고에서 극히 이례적인 수치. 저비용 국가 타겟 + 광범위 노출 최적화 조합일 가능성이 큼. **클릭 품질(실제 구매력)은 별개** — 전환율이 아니라 "결제율"까지 봐야 함 |
| **"해외 전환율이 압도적"** | 이메일 등록 전환율이지 **매출 전환율이 아님.** 화자도 "이제 남은 건 매출로 바꾸는 일"이라고 인정 |
| **모델명(오퍼스 4.6 / 제미나이 3.0 / GPT 이미지 2.0)** | 음성 전사 과정의 숫자 오류 가능성 있음. 실제 구현 시 현재 사용 가능한 모델 ID로 확인할 것 |
| **Lemon Squeezy** | 2024년 Stripe에 인수됨. 대안으로 Paddle, Stripe Tax, Polar 등도 동일한 MoR/VAT 대행 제공. 수수료율 비교 권장 |
| **"주말 2일"** | 검증·기획 기간은 제외한 순수 코딩 시간. 실제 총 소요는 더 길다 |

## 8. 본부(보험업) 적용안 — 이 프레임을 그대로 쓴다면

| 단계 | 보험 본부 버전 실행안 |
|---|---|
| 아이디어 | 예) "주민번호 6자리만 넣으면 보장분석 리포트 자동 생성" / "설계사 리크루팅 자가진단" |
| STEP 1 검증 | 쓰레드·인스타에 "이런 거 있으면 쓰실 분?" 1줄 게시 (설계사 대상이면 오픈채팅·슬랙도 가능) |
| STEP 2 랜딩 | Claude Code로 대기신청 랜딩 30분 제작 → Netlify 발행 (`bless-web-blog` 스킬 활용 가능) |
| STEP 3 광고 | 하루 3만원 메타 광고. **단, 보험 관련 문구는 광고심의 필터 필수** (`insu-ad-review-blog` 스킬) |
| 개발 | 카피=Claude / 화면=Gemini / 이미지=GPT 분업 구조 그대로 적용 |
| 수익화 | 국내 B2B(설계사 구독)면 토스페이먼츠, 해외면 MoR 결제사 |

**주의:** 보험 관련 서비스는 모집·광고 규제 대상입니다. 랜딩페이지 문구·광고 소재는 사전 심의 절차를 반드시 거쳐야 합니다.
