# 브랜딩 전문가 프로젝트 — 설치 방법

노희영 대표의 「AI 시대 브랜딩 법칙」(헤럴드 기업포럼 특별강연)을 바탕으로 만든 AI 브랜딩 전문가입니다.

## 들어 있는 파일

| 파일 | 용도 | 어디에 넣나 |
|---|---|---|
| `project-instructions.md` | 전문가의 성격·규칙 (지침) | Claude 프로젝트 → **지침(Instructions)** 칸에 붙여넣기 |
| `branding-knowledge.md` | 12법칙 상세·사례집·진단표·템플릿 (지식) | Claude 프로젝트 → **파일(Knowledge)** 에 업로드 |
| `../../.claude/skills/branding-expert/` | Claude Code용 스킬 원본 | Claude Code에서 자동 인식 |

## A. Claude.ai(웹/앱)에서 프로젝트 만들기

1. claude.ai 접속 → 왼쪽 메뉴 **프로젝트(Projects)** → **새 프로젝트 만들기**
2. 이름: `브랜딩 전문가` / 설명: `노희영식 AI 시대 브랜딩 법칙으로 진단·전략·시나리오 작성`
3. 프로젝트 화면 오른쪽 **지침 설정(Set project instructions)** 클릭
4. `project-instructions.md` 내용을 **전부 복사해서 붙여넣기** → 저장
5. **파일 추가(Add content)** → `branding-knowledge.md` 업로드
6. 끝. 이 프로젝트 안에서 새 대화를 열면 브랜딩 전문가로 동작합니다.

## B. Claude Code에서 쓰기

이 저장소를 열면 `branding-expert` 스킬이 자동으로 잡힙니다. "내 브랜드 진단해줘"처럼 말하거나 `/branding-expert`를 입력하세요.

## 이렇게 물어보세요 (예시)

| 하고 싶은 일 | 입력 예시 |
|---|---|
| 브랜드 진단 | "동네 베이커리 '○○당'을 진단해줘. 20년 됐고 최근 매출이 줄었어" |
| 페르소나 | "프리미엄 반려견 간식 브랜드의 페르소나를 만들어줘" |
| 리브랜딩 | "30년 된 우리 떡집 리브랜딩 하려는데 리노베이션 시트 작성해줘" |
| 신제품 검증 | "흑임자 크림 라떼 신메뉴 아이디어 검증해줘" |
| 런칭 계획 | "1인 비건 화장품 브랜드 런칭 계획 짜줘" |
| 위기 판단 | "경쟁사 논란이 터졌는데 우리 캠페인 그대로 진행해도 될까?" |
| 함께 고민 | "우리 브랜드 방향을 어떻게 잡을지 고민이야" → 질문으로 함께 생각 |

모든 답변 끝에는 **찌르는 질문 3개 + 이번 주 현장 액션 3개**가 붙습니다.

## 지식 파일 다시 만들기 (스킬 내용을 고쳤을 때)

```bash
bash projects/branding-expert/build-knowledge.sh
```
