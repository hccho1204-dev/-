# 실행 체크리스트 (3개월)

> 끝낸 항목은 `[ ]` → `[x]`로 바꾸고 "기록" 칸에 날짜와 한 줄 메모를 남긴다.
> 바뀐 파일을 프로젝트 지식에 다시 올리면 AI가 진행 상황을 이어서 본다.

|---|---|---|

| [ ] | 대표 떡 5~7가지 확정 (하위 메뉴 중 단골 메뉴는 예약 주문으로) | |
| [ ] | 사 와서 파는 물건(양갱·식혜·과자) 정리 계획 | |

- [ ] 메뉴 늘리기 — **안 함**
