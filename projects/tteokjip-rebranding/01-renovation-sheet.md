> **(가정)** 동네 시장 근처 1층 매장 / 2대째 운영 / 대표 메뉴: 인절미·꿀떡·백설기·절편 / 단골은 50~70대 / 명절·돌·제사 주문이 매출의 절반 / 최근 젊은 손님이 줄고 디저트 카페에 밀리는 중

## 0. 원칙: "고칠 것"이 아니라 "왜 좋아했나"부터 (법칙 10)

백설은 지겨워서 눈 마크를 버리고 빨간 로고로 다 바꿨다가 **기존 팬까지 한꺼번에 잃었다.** 30년은 다시 만들 수 없는 자산이다. 1단계를 다 채우기 전에는 간판·로고를 건드리지 않는다.

## 1단계. 손님이 우리를 좋아했던 이유

| # | 손님이 좋아했던 이유 | 근거 (확인 방법) |
|---|---|---|

## 2단계. 자산 분류

| 구분 | 항목 | 이유 |
|---|---|---|
| **반드시 지킬 것** | 가게 이름, 30년 레시피, 새벽에 찌기, 창업 연도 | 바꾸면 단골이 "그 집 맞아?"라고 의심함 (백설 테스트) |
| | 사장님 얼굴과 손 | 이 가게만의 이야기. 대신할 수 없음 |
| **힙하게 살릴 것** | 낡은 손글씨 간판·가격표 → 그 글씨체를 **그대로 로고·포장에** | 낡은 게 아니라 "진짜"의 증거 |
| | 김 나는 시루, 찌는 장면 → **보이는 주방, 찌는 시간 공지** ("오전 7시 인절미 나옴") | 손님이 사진기를 꺼내는 순간 (법칙 5) |
| | 상차림 상담 → **"기념일 떡 컨시어지"** (대신 챙겨 주는 서비스) | 다른 디저트 가게는 흉내 못 냄 |
| | 30년 단골 이야기 → 매장 벽 **"우리 동네 돌떡 연대기"** | 시나리오 작가식 이야기 (법칙 8) |
| **바꿀 것** | 비닐봉지·스티로폼 포장 → 한지 띠·종이 상자 | "갖고 싶다"는 포장에서 시작 (법칙 3) |
| | 현금만, 전화 주문만 → 카드·온라인 사전 주문 | 젊은 손님이 오기 어려운 이유 |
| | 메뉴판 "국산 쌀 100%, 위생 철저" → "아침에 찐 떡, 저녁엔 없어요" | 가게 입장 말투 금지 (법칙 4) |
| **정리할 것** | 팔리지 않는 메뉴 → **대표 떡 5~7가지로 줄이기** | 팔 게 많으면 힘이 흩어짐 (풀무원 vs CJ 두부) |
| | 양갱·식혜·과자 등 사 와서 파는 물건 | 떡집을 "잡화점"으로 보이게 함 (백설 확장 실패) |

## 3단계. 위험 체크 — "이걸 바꾸면 단골이 떠날까?"

| 바꾸려는 것 | 단골 반응 예상 | 위험도 | 판단 |
|---|---|---|---|
| 가게 이름 변경 | "주인 바뀌었나?" | 🔴 상 | **하지 말 것** |
| 로고를 세련된 영어로 | "우리 떡집이 아니네" | 🔴 상 | 하지 말 것. 손글씨를 살릴 것 |
| 퓨전 떡(말차 크림떡 등) 주력 | "그건 떡이 아니지" | 🟠 중 | 주력 X, 시즌 한정 1개만 |
| 포장 변경 | "예쁘네, 선물하기 좋다" | 🟢 하 | 진행 |
| 메뉴 줄이기 | 특정 떡 찾던 단골 아쉬움 | 🟠 중 | 단골 메뉴는 **예약 주문**으로 남기기 |
| 보이는 주방, 찌는 시간 공지 | "옛날 그대로네" | 🟢 하 | 진행 |
| 온라인 주문 | 영향 없음 | 🟢 하 | 진행 |

## 4단계. 포지션 (법칙 6, 9)

| 선택지 | 내용 | 판단 |
|---|---|---|
| ① 갖고 싶은 극 | "30년 새벽 떡" — 선물하고 싶은 동네 명물 | ✅ **이쪽** |
| ② 가성비 극 | 대형마트·프랜차이즈 떡과 가격 경쟁 | ❌ 체력 싸움에 짐 |
| 애매한 중간 | 카페처럼 꾸몄는데 맛은 옛날 그대로 | ❌ AI도 손님도 기억 못 함 |

**AI가 한 문장으로 소개하게 만들 문장**
> "○○동에서 30년째 **새벽에 쪄서 그날 다 파는** 떡집. 돌·제사 떡을 알아서 챙겨 준다."

**경쟁자를 위로 잡기**
| 단계 | 경쟁자 | 쓰는 법 |
|---|---|---|
| 같은 카테고리 | 옆 동네 떡집, 프랜차이즈 떡 | 의식할 필요 없음 |
| 최고 수준 (따라잡을 기준) | 서울 유명 노포 떡집, 백화점 명인 떡 | 포장·선물 경험을 이 수준의 80%까지 |
| 시간·지갑 경쟁자 | 동네 디저트 카페, 케이크집 | "생일 케이크 대신 떡 케이크", "오후 3시 갓 찐 떡" |
