# 30년 떡집 리브랜딩 프로젝트 — 설치 방법

브랜딩 전문가(노희영식 「AI 시대 브랜딩 법칙」)가 이 떡집 리노베이션만 전담하는 Claude 프로젝트입니다.

## 들어 있는 파일

| 파일 | 용도 | 어디에 넣나 |
|---|---|---|
| `project-instructions.md` | 전담 파트너의 규칙·원칙 | 프로젝트 **지침(Instructions)** 칸에 붙여넣기 |
| `01-renovation-sheet.md` | 리노베이션 시트 (기준안) | 프로젝트 **파일(Knowledge)** 에 업로드 |
| `02-action-tracker.md` | 3개월 실행 체크리스트 | 파일에 업로드 |
| `03-store-info.md` | 가게 실제 정보 입력 양식 | 채운 뒤 파일에 업로드 |
| `../branding-expert/branding-knowledge.md` | 12법칙·사례 원본 (선택) | 파일에 업로드하면 더 정확해짐 |

## Claude.ai에서 만드는 순서

1. claude.ai → **프로젝트(Projects)** → **새 프로젝트**
2. 이름: `30년 떡집 리브랜딩`
3. **지침 설정** → `project-instructions.md` 전부 복사해서 붙여넣기 → 저장
4. **파일 추가** → `01`, `02`, `03` 파일 업로드 (+ 선택으로 `branding-knowledge.md`)
5. 새 대화에서 시작
