# BLESS 키네틱 타이포그래피 모션 그래픽 (22초)

나를 소개하는 22초짜리 (비트 20초 + 엔딩 2초) 키네틱 타이포그래피 영상입니다. 키네틱 타이포그래피는 글자가 움직이며 메시지를 전달하는 디자인입니다.

- **색상**: 블랙, 화이트, 형광 핑크
- **음악**: 120 BPM의 경쾌한 비트를 코드로 직접 만들었습니다. 외부 음원이 아니어서 상업적으로 써도 됩니다.
- **싱크**: 0.5초(1박)마다 글자와 도형이 비트에 맞춰 움직입니다.
- **비율**: 가로 16:9 (1920×1080), 세로 9:16 (1080×1920), 30프레임

## 완성 파일 (`out/` 폴더)

| 파일 | 내용 |

| `kinetic_16x9.mp4` | 가로 영상 (유튜브, 발표용) |
| `kinetic_9x16.mp4` | 세로 영상 (릴스, 쇼츠, 카톡 프로필용) |
| `storyboard_16x9.png` / `storyboard_9x16.png` | 장면 10개를 한 장에 모은 스토리보드 |
| `music.wav` | 배경음악 원본 |

## 수정하는 방법 (Claude에게 이렇게 말하면 됩니다)

- "3번 장면 문구를 ○○로 바꿔줘"
- "핑크를 형광 연두로 바꿔줘"
- "인스타 아이디를 @○○○로 바꿔줘"
- "음악을 더 빠르게 (128 BPM)"

수정이 끝나면 아래 명령으로 다시 만들 수 있습니다.

## 직접 다시 만드는 방법

```bash
cd kinetic-motion
pip install numpy          # 처음 한 번만
python3 music.py           # 1) 음악 만들기
node render.js             # 2) 가로/세로 영상 + 스토리보드 만들기 (약 3분)
INSTA=@내아이디 node render.js   # 인스타 아이디를 바꿔서 만들기
```

- `index.html`을 브라우저로 열면 ▶ 재생 버튼으로 미리볼 수 있습니다. 음악까지 들으려면 `npx serve kinetic-motion`처럼 로컬 서버로 여세요.
- 폰트: Black Han Sans, Anton (둘 다 Google Fonts, 무료로 상업적 사용 가능)
