# 복붙용 프롬프트 6종 — Claude로 모션그래픽 만들기

> **설정**: 모델 Opus 5.5 · 사고 수준(노력) **높음 또는 엑스트라** 추천
> **소요 시간**: 1회 생성 10분 ~ 1시간 30분 (영상이 길수록 오래 걸림 → 시켜두고 다른 일 하기)
> **공통 꼬리말**: 모든 프롬프트 끝에 아래 [공통 규칙]을 붙이면 이 프로젝트 엔진으로 바로 렌더링되는 결과가 나옵니다.

```
[공통 규칙]
- motion-studio/engine/motion.js 엔진을 사용해서 projects/<폴더명>/index.html 하나로 만들어줘.
- 모든 움직임은 render(t) 안에서 시간 t(초)로만 계산해 (CSS animation, setTimeout 금지).
- 해상도 1920x1080, 30fps. 세로(1080x1920)로도 깨지지 않게 M.portrait 분기 넣어줘.
- 다 만들면 node render.js 로 MP4까지 렌더링하고, 주요 장면 캡처를 직접 확인해서 겹침·잘림 없게 고쳐줘.
```

## ① 대사 + 시간만 주기 (텍스트 없는 모션)
가장 쉬운 방법. 영상 대본이 있는데 "화면을 어떻게 보여줄지" 막막할 때.

```
아래 대사가 나오는 동안 화면에 깔릴 모션그래픽을 만들어줘.
길이: 11초
조건: 텍스트 없이 도형·아이콘·움직임만으로 대사 내용을 표현해줘. (자막은 내가 따로 넣을 거야)
대사 타이밍에 맞춰 장면이 바뀌게 해줘.

대사:
"우리가 항상 사용하는 PPT도 조금씩 조금씩 변화가 있었습니다.
오늘은 아직 많은 분들이 모를 수 있는 기능 세 가지를 알려드리겠습니다.
후딱 지나가니까 집중해 주세요."
```
👉 결과 예시: `projects/01-ppt-evolution`

## ② 레퍼런스 따라 만들기 (퀄리티 1등 방법)
**잘 만든 영상을 그대로 첨부**하는 게 핵심. 영상 파일을 올리면 Claude가 프레임을 하나하나 쪼개서 봅니다.

```
첨부한 영상을 레퍼런스로 참고해서 모션그래픽을 만들어줘.
- 따라할 것: 색감, 카메라 움직임, 전환 방식, 속도감, 질감
- 바꿀 것(주제): [예: 물방울 하나가 구름→비→강→바다로 여행하는 여정]
- 길이: [20]초
먼저 레퍼런스를 장면별로 분석한 표(시간/연출/전환)를 보여주고, 그 구조에 내 주제를 대입해서 만들어줘.
```
💡 레퍼런스 찾는 곳: Opus 5.5 모션그래픽 모음 사이트(영상 댓글 링크) → 마음에 드는 영상 다운로드 → 첨부

## ③ 음악에 맞추기 (가사 싱크)
```
첨부한 음악 파일과 가사에 맞춰 모션그래픽 뮤직비디오를 만들어줘.
- 박자(BPM)를 먼저 분석하고, 비트마다 화면이 튀거나 전환되게 해줘.
- 가사 단어가 나올 때 그 단어 뜻대로 화면이 움직이게 해줘. (spin이면 회전, zoom이면 확대, split이면 분할)
- 가사(시간 포함):
[0:00] ...
[0:04] ...
```
💡 가사를 "키프레임·커브·픽셀·줌·플립"처럼 **화면으로 보여줄 수 있는 단어**로 쓰면 결과가 훨씬 좋아집니다.
렌더링: `node render.js projects/<폴더>/index.html --audio song.mp3`

## ④ 나레이션 + 이미지 (교육 콘텐츠)
나레이션(무료 AI 음성) + 이미지 몇 장(무료 AI 이미지)만 준비 → Claude가 영상으로 엮음.

```
첨부한 나레이션 음성과 이미지 [6]장으로 모션그래픽 영상을 만들어줘.
- 나레이션 대본(시간 포함):
[0.0s] 1만 년 전, 사람들이 곡식을 쌓기 시작하자 쥐가 몰려왔어요.
[3.5s] 쥐를 쫓아 야생 고양이가 따라왔고, 사람들은 이 손님을 반겼죠.
[8.0s] 그리고 1만 년 뒤, 고양이는 이제 쥐 대신 소파를 지킵니다.
- 스타일: [종이가 찢어지며 다음 장면이 나오는 페이퍼컷 스타일 / 복스(Vox) 스타일 레트로 설명 영상]
- 이미지는 projects/<폴더>/assets/ 에 넣어둘게. 나레이션 문장마다 맞는 이미지를 배치해줘.
```

## ⑤ 광고 만들기 (실무용)
```
[서비스/브랜드명] 15초 광고 모션그래픽을 만들어줘.
- 서비스 설명: [예: 보험설계사에게 DB·AI교육·팀코칭을 지원하는 BLESS 본부]
- 나레이션:
  0초 "아직도 혼자 영업하세요?"
  3초 "DB는 없고, 교육은 없고, 버티는 건 혼자."
  6.5초 "BLESS 본부는 다릅니다. DB 지원, AI 영업 교육, 1:1 팀 코칭까지."
  11초 "함께 성장하는 보험설계사 본부, BLESS. 지금 상담 신청하세요."
- 구성: 문제 제기 → 공감 → 해결책 3가지 → 브랜드 + CTA(행동 유도 버튼)
- 가로 버전 만들고, 세로(릴스/쇼츠) 버전도 같이 렌더링해줘.
```
👉 결과 예시: `projects/02-bless-ad` (가로 + 세로)
