# 문답형(30문 30답) 작성 지침

참고 원본: 3칸 표(질문 / 답 / 꼬리질문), 한 편 = 문답 30개 ≈ 30분 촬영. 진행자가 질문을 읽고, 전문가가 답하고, 진행자가 꼬리질문(한 줄 정리·확인)으로 받아 다음 질문으로 넘어간다.

## 파일 형식 (정확히 지킬 것 — 파서가 읽음)

파일: `/home/user/-/보험콘텐츠/문답형/EPxx.md` (예: `EP01.md`)

```
# EP01. 보험, 뭐부터 들어야 하나요?

## PART 보험 순서의 기본
### 1
Q: 질문 문장 (시청자=사장님 입장, 구체적 상황 포함, 1~2문장)
A: 답 1문단 (첫 문장은 결론)
A: 답 2문단 (예시·이유)
A: 답 3문단 (실천 방법 / 주의점) — 2~3문단
F: 꼬리질문 (진행자가 핵심을 한 줄로 확인. "~겠네요?", "~군요?" 형태)
### 2
...
```

- `## PART` 4개로 나눈다 (문답 8/8/7/7개 정도). PART 제목은 짧은 소주제.
- 번호는 1~30 연속.
- **각 PART의 마지막 꼬리질문**은 다음 PART로 넘어가는 연결 멘트로 쓴다. 예: "OO까지 살펴봤는데요. 이제 실제로 받을 때 주의할 점도 궁금합니다."
- **30번 꼬리질문**은 마무리 멘트: 상담 신청으로 자연스럽게 연결 (예: "내 증권부터 꺼내서 같이 보면 되겠네요?").
- 마크다운 굵게(**), 표, 자막 지시 등은 넣지 않는다. 순수 텍스트만.

## 분량
- 한 편 Q/A/F 줄의 한글 음절 합계 **7,000~7,800**. 아래 명령으로 잰다:
```

import re,sys
for f in sys.argv[1:]:
    t=''.join(l for l in open(f,encoding='utf-8') if re.match(r'^[QAF]: ',l)); print(len(re.findall('[가-힣]',t)), f)" /home/user/-/보험콘텐츠/문답형/EP01.md
```
- 답 하나 ≈ 한글 170~230자, 2~3문단. 질문 ≈ 25~50자. 꼬리질문 ≈ 20~40자.
- 문답 개수는 정확히 30개.

## 말투 (참고 원본 기준)
- 전문가 답: 부드러운 존댓말. "~습니다", "~예요", "~거든요", "~고요", "~시면 좋겠습니다" 섞어서. 짧은 문장.
- 첫 문장은 결론 ("네, 가능합니다." / "꼭 그렇지는 않습니다." / "먼저 OO부터 확인하세요.").
- 예시는 구체적으로: "예를 들어 40대 카페 사장님이…", 금액은 "예시로" 표기.
- 질문은 시청자가 실제로 할 법한 말투: "~인가요?", "~해도 되나요?", "~라던데 진짜예요?"
- 독자: 마흔 살 동네 카페 사장님. 전문용어는 바로 풀어서.

## 금지
- 쓰지 말 것: "중요합니다", "다양한", "효과적인", "~수 있습니다". ("~수 있어요"는 편당 5번 이하로 최소화. "~하면 돼요", "~가능합니다", "~되기도 해요"로 바꿔 쓰기)
- 보험사·상품 실명 금지 ("A사"). 공공서비스명(내보험다보여, 내보험찾아줌, 실손24, 국민건강보험공단, 근로복지공단, 예금보험공사)은 허용.
- 수익·보장 단정 금지, 타사 비방 금지, 기존 계약 해지 유도 금지 (항상 "해지 전에 확인", "새 계약 확정 후 정리").
- 세금 이야기는 "세무사와 확인" 포함. 바뀌는 제도·숫자는 "최신 기준은 가입 전 꼭 확인하세요" 류의 문장 포함.
