# 1인 숏폼 5편 (레퍼런스형) — 장사가 안 돼서 보험 다 깨고 싶어요

> 레퍼런스(META WAVE 34초 릴스) 구조를 그대로 적용한 버전
> 흐름: 고생 → 위기 → 해법 → 증거 → CTA / 길이 약 34초

**상단 고정 제목 (영상 전체)**
1줄: 장사 안 될 때
2줄: 보험 깨기 전에 이것부터 ← 노란 바탕

**색 규칙**: 고생·위기 구간 흑백 / 숫자 노랑 / 강조 단어 빨강 / 해법부터 컬러

| 시간 | 화면 자막 (1~3단어씩, +아이콘) | 대사 |
|---|---|---|
| 0~2초 | 사장님! (가게 셔터 아이콘) | "사장님, 장사 안 돼서 보험 다 깨려고 하세요?" |
| 2~5초 | 매달 / 빠져나가는 / 보험료 (통장 아이콘) · **흑백** | "매달 빠져나가는 보험료, 진짜 아깝죠. 저도 알아요." |
| 5~9초 | 깨면 / 돌려받는 돈 / **절반도 안 돼요** (빨강) (찢어진 지폐) · **흑백** | "근데 깨면 낸 돈의 절반도 못 돌려받는 경우가 많아요." |
| 9~13초 | 다시 들려면 / 나이↑ 보험료↑ / **거절**까지 (빨강) (도장 X 아이콘) · **흑백** | "더 무서운 건, 다시 들려고 하면 비싸지거나 거절된다는 거예요." |
| 13~15초 | 그래서 / **깨지 말고 줄이세요** (컬러 전환 + 가위 아이콘) | "그래서 깨지 말고, 줄이세요." |
| 15~21초 | ① 겹치는 특약 빼기 / ② 보장금액 낮추기 / ③ 납입 쉬기 확인 (숫자 노랑, 체크 아이콘) | "겹치는 특약 빼고, 금액 낮추고, 납입 잠깐 쉬는 기능 있는지 보고요." |
| 21~24초 | 실손·진단비는 / **끝까지** (빨강) (방패 아이콘) | "실손이랑 진단비는 끝까지 남기세요. 사장님 아프면 가게도 멈춰요." |
| 24~29초 | [실제 사례] 월 **○○만 원 → ○○만 원** (숫자 노랑) / 보장은 그대로 (그래프↓ 아이콘) | "실제로 [실제 사례] 사장님도, 깨지 않고 보험료만 줄였어요." |
| 29~34초 | 댓글에 **"보험료"** (말풍선 아이콘) | "내 보험 뭘 빼야 할지 궁금하면 댓글에 '보험료' 남겨주세요. 줄이는 순서 보내드릴게요." |

> **[실제 사례]** 자리는 반드시 실제 상담한 고객 이야기로 채우세요 (고객 동의 받고, 이름·가게명은 빼기). 실제 사례가 아직 없으면 24~29초 구간을 통째로 빼고 30초 버전으로 올리세요. 지어낸 사례와 숫자는 쓰면 안 됩니다.

## 촬영·편집 체크 (장비: 휴대폰 + BOYA + LED 조명 1개 + 삼각대)

1. **구도**: 가슴 위까지, 위쪽 1/4은 고정 제목 자리로 비우기. 테이블 위 마이크 소품 하나 세우면 팟캐스트 느낌.
2. **조명**: LED를 얼굴 45도 옆, 눈보다 살짝 위. 3200~4000K 따뜻한 색. 천장 형광등 끄기.
3. **캡컷 순서**
   - 고정 제목 텍스트를 영상 전체 길이로 깔기 (2줄째 노란 바탕)
   - 자동 자막 → 1~3단어씩 쪼개기 → 키워드마다 스티커 아이콘
   - 2~13초만 흑백 필터 → 13초 "깨지 말고 줄이세요"에서 컬러 전환 (반전 포인트)
   - 숫자는 노랑, "절반도 안 돼요", "거절", "끝까지"는 빨강
   - 컷은 1~1.5초마다, 배경음악은 목소리보다 확실히 작게
4. **B-roll (선택)**: 계산기 두드리는 손, 증권 넘기는 손, 가게 셔터 장면 3초짜리 2~3개.
5. **올리기 전**: 소속 회사 광고 심의. "해지하지 마세요" 단정 대신 "깨기 전에 줄이는 방법부터" 유지. 상호(인카·블레스본부)를 넣을 경우 본사 준법 확인.
