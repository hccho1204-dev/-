# 보험 콘텐츠 제작안 (최종 정리본)

> 회의 미결 사항이던 "40편 기획안 / 25~30개 질문 / 20개 문답"을 아래 하나의 안으로 정리했다.

## 1. 제작 범위 확정안

| 항목 | 확정안 | 비고 |
|---|---|---|
| 문답 주제 | **25편** | 회의에서 나온 "25~30개 질문"의 최소치. 40편 중 판매 연결이 쉬운 25개만 추림 |
| 롱폼 (유튜브) | **25편 × 약 30분** | 1편 = 1주제. 대본은 `30분대본/` 폴더 |
| 숏폼 (쇼츠·릴스) | **편당 5개 = 총 125개** | 각 대본 끝 "숏폼 컷 5개" 표 참고. 첫 공개는 아래 4번의 5개 |
| 촬영 | 하루 3~4편씩, 총 7~8회 | 2026-11-09 이후 시작. 1편당 촬영 약 45~60분 (NG·재촬영 포함) |
| 촬영 형식 | 2인 문답 | 진행자(Q) = 시청자 입장 질문 / 전문가(A) = 보험 설명 |

**촬영 일정 예시 (주 2회 촬영 시 약 4주)**

| 회차 | 편 | 회차 | 편 |

| 3회 | EP08~10 | 7회 | EP20~22 |

- 공간 대여료는 회차마다 들어간다. 계약서에 "회차당 금액"인지 "시간당 금액"인지 꼭 적는다.
- 남는 15편(40편 기획안 잔여분)은 시즌 2로 보관한다.

## 5. 촬영 전 체크리스트 (화자1 연습용, ~11/06)

1. 25편 대본 읽고 말투로 바꿀 문장 표시
2. 숫자·제도 설명은 촬영 직전 최신 기준으로 한 번 더 확인 (법 개정 잦음)
3. 특정 회사·상품 이름 언급 금지 → "A사 상품" 식으로 처리
4. 영상 끝 고지 문구 자막 준비 (아래 6번)
5. 계약서: 공간 대여료(10만/12만원 중 확정), 촬영 시간, 원본 소유권, 초상권 사용 범위 명시
6. 의상 2벌 (롱폼 묶음 구분용, 선택)
