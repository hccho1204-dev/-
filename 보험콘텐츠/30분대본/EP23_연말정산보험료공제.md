# EP23. 연말정산, 보험료도 돌려받습니다 (30분 롱폼 대본)

> Q = 진행자 (시청자 입장, 편하게 묻고 반박도 함) / A = 전문가 (보험 설명)
> 촬영 형식: 2인 문답 / 예상 길이 약 30분
> ※ 공제 요건·한도는 연도별 세법 기준 → 촬영 직전 재확인 / 세무 처리는 세무사와 확인

| 항목 | 내용 |
|---|---|
| 타깃 | 직장인 (특히 맞벌이 부부, 자녀·부모 보험료를 내는 가장) |
| 핵심 메시지 | 보장성 보험료는 연 100만 원 한도 12% 세액공제 (장애인전용 별도 100만 원 한도 15%). 계약자·피보험자 조건을 맞춰야 받는다 |
| 썸네일 문구 3안 | ① 보험료 내고 12만 원 돌려받는 법 ② 남편 보험료 아내가 내면 공제 0원 ③ 연말정산 보험료, 계약자 한 줄이 갈랐습니다 |
| 판매 연결 | 가족 보험 계약자·피보험자 정리 상담 |
| 준비물 (자료화면·자막) | 공제 계산 그래픽 (100만 × 12%) / 계약자·피보험자 조건 표 / 맞벌이 부부 O·X 케이스 카드 / 홈택스 간소화 화면 (가림 처리) / 보험증권 계약자·피보험자 칸 확대 / 고지 문구 자막 |

## [00:00] 오프닝 훅

**Q:** 부부가 똑같이 매달 보험료 10만 원씩 냅니다. 남편은 연말정산에서 12만 원 돌려받고, 아내는 0원. 왜일까요?
**A:** 보험증권 맨 위 한 줄 때문입니다. '계약자'가 누구냐.
**Q:** 계약자 이름 하나로 12만 원이 갈려요?
**A:** 네. 그리고 이걸 모르고 몇 년째 놓치는 분이 정말 많습니다.
**Q:** 오늘 내 보험료, 제대로 돌려받는 법 알려드리겠습니다.
[자막: 계약자 한 줄 = 12만 원 차이]

## [00:30] 챕터 1. 보험료 세액공제, 기본 구조

**Q:** 기본부터요. 보험료도 연말정산에 들어가요?
**A:** 들어갑니다. '보장성 보험료 세액공제'라고 부릅니다.
**Q:** 보장성 보험이 뭐예요?
**A:** 아프거나 다치거나 사고 났을 때 보험금이 나오는 보험입니다. 실손, 암보험, 종신보험, 자동차보험, 운전자보험 같은 것들이요. 만기에 돌려받는 돈이 낸 보험료보다 많지 않은 보험입니다.
**Q:** 자동차보험도 돼요?
**A:** 네. 많이들 놓치는데 자동차보험도 보장성 보험입니다.
[자료화면: 공제 O 보험 아이콘 — 실손·암·종신·자동차·운전자 / 공제 X — 저축보험·연금보험]
**Q:** 얼마나 돌려줘요?
**A:** 1년에 낸 보험료 중 100만 원까지를 대상으로 12%를 세금에서 빼줍니다. 최대 12만 원입니다.
[자막: 보장성 보험료 연 100만 원 한도 × 12% = 최대 12만 원 — 촬영 시점 기준, 최신 기준 확인 필요]
**Q:** 저는 보험료가 1년에 300만 원인데요?
**A:** 그래도 100만 원까지만 봅니다. 300만 원 내도, 100만 원 내도 공제액은 12만 원으로 같습니다.
**Q:** 아, 한도가 있구나. 그럼 많이 낸다고 더 받는 게 아니네요.
**A:** 맞습니다. 대신 이 12만 원은 조건만 맞추면 거의 누구나 받는 돈입니다. 놓치기 아까운 돈이죠.
**Q:** 세액공제랑 소득공제는 뭐가 달라요? 늘 헷갈려요.
**A:** 소득공제는 세금 매기는 바탕 금액을 줄여줍니다. 세액공제는 다 계산된 세금에서 바로 빼줍니다. 보험료는 세액공제라서 12만 원이 그대로 세금에서 빠집니다.
[자막: 소득공제 = 세금 매기는 금액 ↓ / 세액공제 = 낼 세금에서 바로 ↓]

**Q:** 그럼 12만 원은 언제 들어와요? 통장으로 바로 와요?
**A:** 직장인은 보통 2월 급여나 3월 급여에 같이 정산돼서 들어옵니다. 회사마다 시기가 조금 다릅니다.
**Q:** 보험료 낸 걸 제가 따로 신고해야 해요?
**A:** 대부분 국세청 연말정산 간소화 서비스에 자동으로 뜹니다. 회사에 간소화 자료를 내면 끝입니다. 다만 안 뜨는 자료가 가끔 있어서, 뜬 내역이 내 보험 목록과 맞는지 한 번 대조해보시는 게 좋습니다.
[자료화면: 홈택스 간소화 '보험료' 항목 화면 (가림 처리)]

## [04:00] 챕터 2. 장애인전용 보험과 숫자 예시

**Q:** 장애인 보험은 따로 있다고 들었어요.
**A:** 장애인전용 보장성 보험은 별도 한도입니다. 연 100만 원 한도로 15%를 공제합니다. 최대 15만 원입니다.
[자막: 장애인전용 보장성 보험 연 100만 원 한도 × 15% (일반 보장성과 별도) — 촬영 시점 기준, 최신 기준 확인 필요]
**Q:** 일반 보험이랑 같이 받아요?
**A:** 네, 따로 계산합니다. 둘 다 있으면 일반 12만 원 + 장애인전용 15만 원, 최대 27만 원까지입니다.
**Q:** 장애인전용 보험은 어떻게 알아요?
**A:** 증권이나 보험사 납입증명서에 '장애인전용'으로 표시됩니다. 피보험자나 보험수익자가 장애인인 전용 상품이어야 합니다.
**Q:** 숫자 예시 하나 더 보여주세요.
**A:** 예시입니다. 직장인 C씨. 본인 실손과 암보험 월 6만 원, 자동차보험 1년 60만 원.
**Q:** 합치면요?
**A:** 6만 원 × 12개월 = 72만 원. 자동차보험 60만 원. 합계 132만 원. 한도가 100만 원이니 100만 원 × 12% = 12만 원입니다.
[자료화면: 72만 + 60만 = 132만 → 한도 100만 → 12만 원]
**Q:** 자동차보험 빠뜨렸으면 72만 원 × 12%라서 8만 6천 원 정도였겠네요.
**A:** 그렇죠. 간소화 서비스에 보통 자동으로 뜨지만, 확인 안 하면 모릅니다.
**Q:** 그럼 12만 원을 무조건 받아요?
**A:** 원래 낼 세금이 있어야 받습니다. 결정세액, 즉 계산된 세금이 이미 0원이면 돌려받을 게 없습니다. 소득이 낮은 사회초년생은 그런 경우가 있습니다.
**Q:** 그럼 그 사람은 보험료를 다른 가족 쪽으로 돌리는 게 나아요?
**A:** 계약자를 누구로 하느냐의 문제가 됩니다. 그게 다음 챕터 핵심입니다.

**Q:** 원래 낼 세금이 0원인 사람은 정말 하나도 못 받아요?
**A:** 예시로 보겠습니다. 사회초년생 H씨. 다른 공제를 다 빼고 나니 계산된 세금이 5만 원입니다. 보험료 공제가 12만 원이어도 5만 원까지만 빠집니다. 나머지 7만 원은 사라집니다.
[자막: 예시 — 세액공제는 결정세액 범위 안에서만 적용]
**Q:** 그럼 H씨 보험료는 부모님 쪽으로 돌리면 돼요?
**A:** H씨가 부모님의 기본공제 대상이 아니면 그것도 안 됩니다. 소득이 있는 성인 자녀는 보통 부모님 공제 대상이 아닙니다. 이럴 땐 무리하게 바꾸지 말고, 소득이 오르면 자연스럽게 공제받는다고 보시면 됩니다.

**Q:** 그럼 반대로 보험료가 100만 원이 안 되는 분은요?
**A:** 낸 만큼 12%입니다. 예시로 1년 보험료 50만 원이면 6만 원입니다. 한도를 채우려고 보험을 더 드실 필요는 없습니다. 보장이 필요해서 드는 게 순서고, 공제는 덤입니다.

## [07:00] 챕터 3. 계약자·피보험자 조건, 여기서 갈립니다

**Q:** 계약자, 피보험자. 단어부터 쉽게요.
**A:** 계약자는 보험을 계약하고 보험료를 내는 사람. 피보험자는 보험의 대상, 아프거나 다치면 보장받는 사람입니다.
[자료화면: 계약자 = 돈 내는 사람 / 피보험자 = 보장받는 사람]
**Q:** 공제 조건은요?
**A:** 두 개를 다 맞춰야 합니다. 하나, 계약자가 연말정산 받는 근로자 본인. 둘, 피보험자가 본인이나 기본공제 대상 가족.
**Q:** 기본공제 대상 가족은 누구예요?
**A:** 소득이 거의 없어서 내가 부양가족으로 올릴 수 있는 가족입니다. 대략 연간 소득금액 100만 원 이하, 근로소득만 있다면 총급여 500만 원 이하. 자녀는 20세 이하, 부모님은 60세 이상 같은 나이 요건도 있습니다. 배우자는 나이 요건이 없습니다.
[자막: 기본공제 대상자 요건(소득·나이) — 촬영 시점 기준, 최신 기준 확인 필요]
[숏폼①]
**Q:** 그럼 오프닝 사례요. 남편이 계약자, 피보험자는 맞벌이 아내.
**A:** 아내가 소득이 있어 남편의 기본공제 대상이 아닙니다. 그러면 남편도 못 받습니다. 아내는 계약자가 아니라서 못 받습니다.
**Q:** 둘 다 0원이에요?
**A:** 네. 돈은 내는데 공제는 아무도 못 받습니다.
**Q:** 해결책은요?
**A:** 아내 보험은 아내가 계약자가 되면 됩니다. 아내가 내고, 아내가 공제받습니다.
[자막: 맞벌이 부부 → 각자 보험은 각자 계약자로]
[/숏폼①]
**Q:** 계약자를 바꿀 수 있어요?
**A:** 대부분 계약자 변경이 됩니다. 피보험자 동의 같은 절차가 필요합니다. 보험을 깨고 새로 들 필요는 없습니다.
**Q:** 그 말 꼭 해주세요. 깨지 말라고.
**A:** 깨면 손해입니다. 계약자 변경으로 해결되는 경우가 대부분입니다.
**Q:** 아이 보험은요?
**A:** 아이를 기본공제로 올리는 부모가 계약자여야 합니다. 맞벌이라면 아이를 아빠 쪽에 올렸는데 계약자는 엄마로 돼 있으면 엄마는 공제를 못 받습니다.
**Q:** 아이 공제를 누구한테 올렸는지랑 계약자를 맞춰야 한다.
**A:** 정확합니다.

**Q:** 계약자 변경은 어디서 해요? 복잡해요?
**A:** 보험사 고객센터, 지점, 담당 설계사를 통해 합니다. 보통 기존 계약자, 새 계약자, 피보험자의 신분증과 동의가 필요합니다. 회사에 따라 앱으로도 됩니다.
**Q:** 바꾸면 보험료가 달라져요?
**A:** 계약자만 바뀌고 피보험자가 그대로면 보장과 보험료는 보통 그대로입니다. 다만 계약 내용에 따라 다르니 변경 전에 확인하세요.

## [10:30] 챕터 4. 가상 사례 — 맞벌이 D씨 부부의 1년

**Q:** 사례로 한 번에 정리해봐요.
**A:** 가상 사례입니다. 40대 맞벌이 D씨 부부. 남편 회사원, 아내 회사원, 초등학생 자녀 1명.
[자막: 가상 사례 — 실제 인물과 무관]
**A:** 보험은 이렇게 있습니다. 남편 본인 보험, 계약자 남편. 아내 보험, 계약자도 남편. 아이 보험, 계약자 아내. 아이는 연말정산 때 남편 쪽 부양가족으로 올렸습니다.
**Q:** 벌써 꼬인 게 보여요.
**A:** 하나씩 볼게요. 남편 본인 보험, 공제 됩니다. 아내 보험은 계약자가 남편인데 피보험자 아내가 기본공제 대상이 아니라서 안 됩니다.
**Q:** 아이 보험은요?
**A:** 계약자는 아내인데 아이는 남편의 부양가족입니다. 아내 쪽에서는 피보험자가 아내의 기본공제 대상이 아니라서 안 됩니다. 남편 쪽에서는 계약자가 아니라서 안 됩니다.
**Q:** 이것도 0원.
**A:** 결국 남편 혼자 본인 보험만 공제받고 있습니다. 남편 보험료가 이미 100만 원 넘으면 나머지는 완전히 날아갑니다.
[자료화면: 표 — 남편 보험 O / 아내 보험 X / 아이 보험 X → 정리 후 남편 O / 아내 O / 아이 O]
**Q:** 고치면요?
**A:** 아내 보험 계약자를 아내로 변경. 그럼 아내가 자기 100만 원 한도로 12만 원 받습니다. 아이 보험은 계약자를 남편으로 바꾸거나, 아이를 아내 부양가족으로 옮기는 방법이 있습니다.
**Q:** 어느 쪽이 나아요?
**A:** 남편 보험료가 이미 100만 원을 채웠다면, 아이 보험은 아내 쪽으로 모으는 게 낫습니다. 남편 한도는 이미 꽉 찼으니까요. 대신 아이 공제를 옮기면 다른 공제 항목도 같이 움직이니 전체를 보고 정하세요.
**Q:** 그럼 부부 합쳐서 최대 24만 원.
**A:** 네. 몇 년 놓쳤으면 수십만 원입니다. 뒤에서 놓친 해 돌려받는 법도 말씀드릴게요.
**Q:** 진행자로서 한마디. 12만 원 받자고 이렇게까지 해야 돼요?
**A:** 계약자 변경은 한 번만 하면 매년 자동입니다. 10년이면 부부 합쳐 최대 240만 원입니다. 한 번 서류 쓰는 수고치고는 큰돈이죠.
**Q:** 그렇게 들으니까 해야겠네요.

**A:** 사례 하나 더 볼게요. 가상 사례, 50대 외벌이 I씨. I씨는 회사원, 배우자는 전업주부, 대학생 자녀 둘, 70세 어머니와 함께 삽니다.
[자막: 가상 사례 — 실제 인물과 무관]
**Q:** 부양가족이 많네요.
