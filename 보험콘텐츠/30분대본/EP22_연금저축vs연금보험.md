# EP22. 연금, 보험으로 준비해도 될까요? (30분 롱폼 대본)

> Q = 진행자 (시청자 입장, 편하게 묻고 반박도 함) / A = 전문가 (보험 설명)
> 촬영 형식: 2인 문답 / 예상 길이 약 30분
> ※ 세액공제 한도·세율·비과세 요건은 세법 개정이 잦음 → 촬영 직전 최신 기준 재확인 / 세무 처리는 세무사와 확인

| 항목 | 내용 |
|---|---|
| 타깃 | 노후 준비를 시작하는 40~50대 직장인·자영업자 |
| 핵심 메시지 | 지금 세금 돌려받기 = 연금저축·IRP / 나중에 세금 안 내기 = 연금보험. 목적별로 나눠 담는다 |
| 썸네일 문구 3안 | ① 연금저축 vs 연금보험, 헷갈리면 이것만 ② 연말정산 148만 원 돌려받는 통장이 있습니다 ③ 연금보험 10년 안에 깨면 생기는 일 |
| 판매 연결 | 노후 자금 설계 상담 (연금 계좌 배분 점검) |
| 준비물 (자료화면·자막) | '두 갈래' 도식 (지금 환급 vs 나중 비과세) / 세액공제율 표 / 연금 수령 시 세율 표 / 연금보험 비과세 요건 체크박스 그래픽 / 50세 가상 인물 일러스트 / 고지 문구 자막 |

## [00:00] 오프닝 훅

**Q:** 연말정산 때 동료는 100만 원 넘게 돌려받는데, 저는 토해냈어요. 차이가 뭐였을까요?
**A:** 연금 계좌 하나 차이인 경우가 많습니다. 연금저축이랑 IRP에 넣은 돈은 세금에서 빼줍니다.
**Q:** 그럼 연금보험도 그래요?
**A:** 아닙니다. 연금보험은 지금 돌려받는 게 아니라, 나중에 세금을 안 내는 쪽입니다.
**Q:** 이름은 다 '연금'인데 구조가 반대라는 거네요. 오늘 이거 확실히 정리하겠습니다.
[자막: 같은 '연금', 세금 구조는 정반대]

## [00:30] 챕터 1. 연금, 크게 두 갈래입니다

**Q:** 처음 듣는 분 기준으로 갈게요. 연금 준비할 때 뭐가 있어요?
**A:** 집으로 치면 3층입니다. 1층은 국민연금. 2층은 회사 퇴직연금. 3층이 내가 따로 준비하는 개인연금입니다.
[자료화면: 3층 집 그래픽 — 1층 국민연금 / 2층 퇴직연금 / 3층 개인연금]
**Q:** 오늘 얘기하는 건 3층이죠?
**A:** 네. 3층에 연금저축, IRP, 연금보험이 있습니다.
**Q:** IRP는 뭐예요? 이름부터 어려워요.
**A:** 개인형 퇴직연금 계좌입니다. 퇴직금을 받아두는 통장이기도 하고, 내가 돈을 더 넣을 수도 있는 통장입니다.
**Q:** 그럼 세 개를 어떻게 나눠요?
**A:** 기준은 하나입니다. 세금을 언제 혜택 받느냐.
**A:** 연금저축과 IRP는 '지금' 혜택입니다. 넣는 해에 연말정산이나 종합소득세 신고 때 세금을 돌려받습니다. 대신 나중에 연금 받을 때 세금을 조금 냅니다.
**A:** 연금보험은 '나중' 혜택입니다. 지금 공제는 없습니다. 대신 요건을 채우면 나중에 받는 이자 부분에 세금이 없습니다.
[자료화면: 두 갈래 도식 — 지금 환급(연금저축·IRP) / 나중 비과세(연금보험)]
**Q:** 그럼 뭐가 더 좋은 거예요?
**A:** 더 좋은 건 없습니다. 목적이 다릅니다. 지금 세금을 줄이고 싶은지, 나중에 평생 받는 구조를 원하는지에 따라 다릅니다.
**Q:** 둘 다 원하면요?
**A:** 그래서 나눠 담는 겁니다. 오늘 결론이 그겁니다.

## [04:00] 챕터 2. 연금저축·IRP, 얼마나 돌려받나요?

**Q:** 숫자로 가볼게요. 얼마나 돌려받아요?
**A:** 연금저축은 1년에 600만 원까지 공제 대상입니다. IRP까지 합치면 900만 원까지입니다.
[자막: 연금저축 연 600만 원, IRP 합산 연 900만 원 한도 — 촬영 시점 기준, 최신 기준 확인 필요]
**Q:** 900만 원 넣으면 900만 원 다 돌려줘요?
**A:** 그건 아니고요. 넣은 돈의 일정 비율을 세금에서 빼줍니다. 소득에 따라 비율이 다릅니다.
**A:** 직장인 기준 총급여 5,500만 원 이하면 16.5%, 그보다 많으면 13.2%입니다. 지방소득세 포함 기준입니다.
[자료화면: 세액공제율 표 — 총급여 5,500만 이하(종합소득 4,500만 이하) 16.5% / 초과 13.2%]
**Q:** 계산해주세요.
**A:** 예시입니다. 총급여 5,000만 원 직장인이 900만 원을 꽉 채우면 900만 원 × 16.5%, 약 148만 원입니다.
**Q:** 148만 원이요? 꽤 크네요.
**A:** 총급여 7,000만 원이면 13.2%라서 약 118만 원입니다.
[자막: 예시 계산 / 실제 환급액은 결정세액 등 개인 상황에 따라 다름]
**Q:** 근데 저 같은 카페 사장님은요? 연말정산 안 하는데.
**A:** 자영업자도 됩니다. 5월 종합소득세 신고 때 공제받습니다. 종합소득금액 4,500만 원 이하면 16.5%가 적용됩니다.
**Q:** 아, 사장님도 되는구나.
**A:** 네. 다만 낼 세금이 원래 적으면 돌려받을 것도 적습니다. 결정세액, 즉 원래 낼 세금 범위 안에서만 빼줍니다.
**Q:** 그럼 받을 때는 세금 얼마나 내요?
**A:** 55세 이후 연금으로 받으면 연금소득세를 냅니다. 나이에 따라 대략 3.3%에서 5.5%입니다. 나이가 많을수록 낮아집니다.
**Q:** 16.5% 돌려받고 나중에 5.5% 내면 이득이네요.
**A:** 구조상 그렇습니다. 다만 연금 말고 중간에 빼서 쓰면 이야기가 달라집니다.
**Q:** 어떻게 달라요?
**A:** 공제받은 원금과 수익에 기타소득세 16.5%가 붙습니다. 돌려받은 걸 다시 토해내는 셈입니다.
[자막: 연금 외 수령(중도 인출·해지) 시 기타소득세 부과 — 촬영 시점 기준, 최신 기준 확인 필요]
**Q:** 그러니까 '노후까지 못 건드리는 돈'으로 넣어야 한다.
**A:** 정확합니다.

## [07:30] 챕터 3. 연금보험, 어떻게 작동하나요?

**Q:** 이제 연금보험이요. 지금 공제가 없는데 왜 들어요?
**A:** 두 가지 이유입니다. 비과세, 그리고 평생 연금.
**Q:** 비과세부터요.
**A:** 연금보험은 저축성 보험입니다. 일정 요건을 채우면 나중에 받는 이자 부분에 세금이 없습니다.
**Q:** 요건이 뭐예요?
**A:** 기본은 10년 이상 유지입니다. 여기에 월 적립식이면 5년 이상 매달 비슷한 금액을 넣고, 월 납입 한도가 있습니다. 한 번에 넣는 일시납이면 금액 한도가 있습니다.
[자료화면: 비과세 요건 체크박스 — 10년 이상 유지 / 월납 5년 이상 균등 납입 / 한도 이내]
[자막: 저축성보험 비과세 요건은 세법 개정에 따라 바뀜 — 촬영 시점 기준, 최신 기준 확인 필요]
**Q:** 은행 적금은 이자에 세금 떼죠?
**A:** 네. 이자소득세 15.4%를 뗍니다. 연금보험은 요건을 채우면 이 부분이 없습니다. 오래 묵힐수록 차이가 커집니다.
**Q:** 평생 연금은요?
**A:** 상품에 따라 '종신형'을 고르면 살아 계시는 동안 연금이 계속 나옵니다. 90세든 100세든요.
**Q:** 연금저축은 평생 안 나와요?
**A:** 연금저축은 내가 정한 기간 동안 쪼개 받는 방식이 기본입니다. 돈이 다 떨어지면 끝입니다. 종신형 연금보험은 오래 사는 위험 자체를 보험사가 집니다.
**Q:** 오래 사는 게 위험이에요?
**A:** 돈 입장에서는 그렇습니다. 계획보다 10년 더 살면 10년 치 생활비가 비거든요. 이걸 장수 위험이라고 부릅니다.
[자막: 장수 위험 = 모아둔 돈보다 오래 사는 위험]
**Q:** 수익률은 얼마나 돼요?
**A:** 상품마다 다릅니다. 금리형은 공시이율이 바뀌면서 쌓이고, 최저보증이율이라는 바닥이 있는 상품이 많습니다. 변액연금은 투자 성과에 따라 오르내립니다.
**Q:** 확정 수익은 아니네요.
**A:** 네. 확정된 수익을 약속하는 게 아닙니다. 그리고 초기에 사업비가 빠지기 때문에, 몇 년 안에 해지하면 낸 돈보다 적게 받습니다.
[자막: 연금보험은 확정 수익 상품 아님 / 조기 해지 시 원금 손실 가능]

## [11:00] 챕터 4. 가상 사례 — 50세 카페 사장 B씨의 연금 배분

**Q:** 실제처럼 한번 짜봐요.
**A:** 가상 사례입니다. 50세 카페 사장 B씨. 종합소득금액 약 4,000만 원. 배우자는 회사원. 노후 준비가 거의 없습니다.
[자막: 가상 사례 — 실제 인물과 무관]
**Q:** 저랑 비슷하네요. 뭐부터 해요?
**A:** 첫째, 국민연금 예상액부터 봅니다. 국민연금공단 앱에서 바로 나옵니다. B씨는 월 80만 원 정도로 나왔다고 하죠.
**Q:** 80만 원으로는 부족하죠.
**A:** 부부가 원하는 생활비가 월 250만 원이라면, 배우자 연금까지 합쳐도 빈칸이 생깁니다.
**Q:** 둘째는요?
**A:** 세액공제 한도를 봅니다. B씨는 종합소득 4,500만 원 이하라 16.5%. 다만 매달 넣을 여유가 50만 원이라고 하죠. 1년 600만 원입니다.
**Q:** 600만 원 넣으면요?
**A:** 예시로 약 99만 원 절세 효과입니다. 낼 세금이 충분하다는 전제입니다.
[자료화면: 600만 × 16.5% ≈ 99만 원 계산 그래픽]
**Q:** 연금보험은 안 들어요?
**A:** 여기서 판단이 갈립니다. B씨는 50세라 55세부터 연금저축 수령이 가능하고, 오래 묵힐 시간이 짧습니다. 매달 여유가 50만 원이면 일단 공제 혜택부터 챙기는 게 순서입니다.
**Q:** 그럼 연금보험은 아예 안 맞아요?
**A:** 여유가 더 생기면 검토합니다. 예를 들어 가게 보증금이나 퇴직금처럼 목돈이 생기면 일부를 종신형 연금보험에 넣어 '죽을 때까지 나오는 월급'을 만드는 식입니다.
**Q:** 아, 목돈은 연금보험, 매달 여유는 연금저축.
**A:** 그런 식으로 나눠 담는 겁니다. 정답은 사람마다 다릅니다. 나이, 소득, 다른 자산을 같이 봐야 합니다.
**Q:** 진행자로서 반론 하나. 차라리 그 돈으로 주식 하면 더 벌지 않아요?
**A:** 그럴 수도 있죠. 그런데 연금저축이나 IRP 안에서도 펀드나 ETF 투자가 됩니다. 세금 혜택을 받으면서 투자하는 겁니다. 문제는 투자 그 자체보다 '중간에 꺼내 쓰지 않는 구조'입니다.
**Q:** 강제 저축이네요.
**A:** 그게 연금 계좌의 진짜 힘입니다.

## [14:30] 챕터 5. 많이들 하는 오해 3가지

**Q:** 오해 정리 갈게요.
[숏폼①]
**A:** 첫째. "연금보험도 연말정산 공제된다." 아닙니다. 일반 연금보험은 세액공제가 없습니다. 연금저축'보험'이라는 이름의 상품만 연금저축으로 분류돼서 공제가 됩니다.
**Q:** 이름이 비슷해서 헷갈리네요.
**A:** 증권에 '연금저축'이라는 말이 있는지 보세요. 그게 기준입니다.
[자막: 오해① 연금보험 = 공제 X / '연금저축보험'만 세액공제]
[/숏폼①]
**Q:** 둘째는요?
**A:** "세액공제 많이 받으면 무조건 이득." 반은 맞습니다. 중간에 해지하면 공제받은 걸 다시 내야 합니다. 연금으로 받을 때도 세금이 있고요. 끝까지 유지할 돈만 넣어야 이득입니다.
**Q:** 셋째는요?
**A:** "연금보험은 원금 보장이다." 상품마다 다릅니다. 그리고 원금이 보장되는 상품이라도 초기에 해지하면 사업비 때문에 손해가 납니다. '만기까지 유지하면'이라는 조건이 붙습니다.
**Q:** 하나 더 있을 것 같은데요. "IRP는 직장인만 된다."
**A:** 좋은 지적입니다. 지금은 소득이 있으면 자영업자도 IRP 가입이 됩니다. 사장님들도 연금저축 600만 원에 IRP 300만 원 더해서 900만 원까지 공제를 노려볼 만합니다.
[자막: 자영업자 IRP 가입 가능 — 요건은 금융회사 확인]
**Q:** 그거 몰랐어요. 카페 사장님들 꼭 보세요.

## [18:00] 챕터 6. 받을 때의 세금, 미리 알아두세요

**Q:** 받을 때 이야기도 해주세요. 넣는 것만 생각하잖아요.
**A:** 이게 진짜 실력입니다. 연금저축과 IRP는 연금으로 받으면 연금소득세가 낮습니다. 그런데 1년에 받는 사적연금이 일정 금액을 넘으면 계산 방식이 달라집니다.
**Q:** 얼마요?
**A:** 현재 기준 연 1,500만 원입니다. 넘으면 종합과세나 별도 세율 중에 골라야 합니다.
[자막: 사적연금 분리과세 기준 연 1,500만 원 — 촬영 시점 기준, 최신 기준 확인 필요]
[숏폼②]
**Q:** 그럼 한꺼번에 많이 받으면 손해예요?

## [21:00] 챕터 7. 내 연금, 단계별 점검법

**A:** 4단계, 올해 넣은 금액이 공제 한도 600만 원, 900만 원 중 어디까지 찼는지 봅니다.

## [24:30] 챕터 8. 피해야 할 실수 & 시청자 자주 묻는 질문

**A:** 10년 요건을 못 채우면 이자에 세금이 붙습니다. 사업비 때문에 원금보다 적게 받을 가능성도 큽니다.
