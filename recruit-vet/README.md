# 수의사 리크루팅 영상 (20초, 스카우트 톤)

간호사·간호조무사·치위생사·요양보호사 편과 같은 **스카우트 시리즈**입니다. 수의사 편은 **펫보험 상담**을 연결고리로 삼았고, 배지는 **발바닥** 모양입니다.

- **문구**: 블로그에 수의사 편 글이 없어 새로 쓴 문구입니다 (확인 필요)
- **음악**: 120 BPM, 정확히 20초, 처음부터 밝게 → 8초에 터짐 (직접 합성, 상업적 사용 가능)
- **비율**: 세로 9:16 (주력), 가로 16:9
- **주의**: 수입 약속·투잡·매일 DB 문구 없음

## 스토리보드

| 시간 | 장면 | 내용 |
|---|---|---|
| 0~4초 | WANTED | WANTED 글자 배경 + 구인 카드 · 발바닥 배지 · **동물을 아는 사람** |
| 4~8초 | 필요한 이유 | **수의사님, 당신의 경력이 필요합니다** · "펫보험 상담은 동물을 아는 사람이 제일 잘하니까" |
| 8~11초 | 경력 인정 | 동물병원에서 보낸 1 → 3 → 5 → **10** YEARS · 그 시간, 그대로 **경력으로 인정합니다** |
| 11~14초 | 경력 매칭 | 질병·진료 지식 → 펫보험 설명 전문가 / 보호자 상담 경험 → 고객 신뢰 / 진료비 안내 경험 → 보장 분석 감각 |
| 14~16초 | 지원 | 진료 경력 그대로 인정 · 1:1 전담 멘토링 · AI 자동화 도구 |
