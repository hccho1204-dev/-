# 인동 가을소풍 1박 2일 워크숍 (안면도) — 일정 안내 모션그래픽 20초

| 시간 | 장면 |
|---|---|
| 0~3초 | 단풍잎이 떨어지며 "인동 가을소풍" + "1박 6끼" + "안면도로 떠나자!" |
| 3~5.5초 | 포스터 등장 + "10월 29일(목) 1박 2일" + "스트레스는 안면도에 두고 오자" |
| 5.5~11초 | DAY 1 일정 5개가 박자마다 하나씩 (버스가 따라 내려감) |
| 11~15초 | DAY 2 일정 5개 |
| 15~18초 | 지역별 조 편성 4개 카드 |
| 18~20초 | "스트레스는 안면도에 두고 오자!" + "함께라서 더 좋은 가을소풍 ♡" |

일정·조 편성 수정: index.html 의 `DAY1`, `DAY2`, `TEAMS` 만 고치면 됩니다.

```
python3 music.py   # 120BPM 마림바 팝 (직접 합성, 저작권 걱정 없음)
node render.js     # out/workshop_9x16.mp4, out/workshop_16x9.mp4
```
