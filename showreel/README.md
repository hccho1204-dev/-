# BLESS CREATIVE 포트폴리오 쇼릴 (20초)

포트폴리오를 모아 보여주는 20초짜리 영문 쇼릴입니다. 글자(타이포) 중심으로 만들었습니다.

- **음악**: 144 BPM의 신나는 하우스 비트를 코드로 직접 만들었습니다. 정확히 20초이고, 외부 음원이 아니어서 상업적으로 써도 됩니다.
- **제작 순서**: 음악 → 스토리보드 → 영상 렌더링
- **비율**: 가로 16:9, 세로 9:16, 30프레임

## 포트폴리오로 들어간 실제 작업물

| 구간 | 작업물 | 출처 |
|---|---|---|
| 01 Motion Graphics | 키네틱 타이포 영상 장면들 | `kinetic-motion/out/` 영상에서 장면을 뽑음 |
| 02 AEO Content | 리크루팅 블로그 글 11편 (실제 제목) | `posts/` 폴더 |
| 03 AI Native Workflow | 글쓰기·디자인·모션·자동화 아이콘 + 세로 영상 | 위 작업물 |

| 2 | 2.5~6.7초 | 01 Motion Graphics | 영상 장면 6개가 박자마다 **포물선**을 그리며 날아와 콜라주, 가운데 장면으로 줌인 |

## 다시 만드는 방법

```bash
cd showreel
python3 music.py      # 1) 음악
node render.js        # 2) 스토리보드 + 가로/세로 영상 (약 4분)
node render.js storyboard   # 스토리보드만 빠르게
```
