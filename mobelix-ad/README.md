# 모벨릭스 네발 전기자전거 광고 (20초, 힙한 버전)

화성행궁 일대에서 찍은 **실제 사진 5장**으로 만든 모션 광고입니다.

- **톤**: 블랙 · 화이트 · 애시드 라임, 진(zine) 스타일 모서리 정보, 스티커 라벨
- **음악**: 96 BPM 힙합/트랩 비트 (붐뱁 킥 + 트랩 하이햇 롤 + 808 베이스), 정확히 20초, 직접 합성해서 상업적 사용 가능
- **비율**: 세로 9:16 (릴스·스토리, 주력), 가로 16:9
- **사진**: `assets/p1~p5.jpg` (AI 이미지는 실제 제품과 모양이 달라 사용하지 않음)

## 스토리보드 (1비트 = 0.625초)

| 시간 | 장면 | 내용 |
|---|---|---|
| 0~2.5초 | 훅 | "두 발 말고," → **네 발** 쾅 → **MOBELIX** + 네 바퀴가 굴러 들어옴 |
| 2.5~7.5초 | 실사 몽타주 | 2비트마다 사진 컷 + 스티커: STABLE(네 바퀴라 안정적) · E-ASSIST(전기로 가볍게) · BIG BASKET(짐도 한가득) · RENT·BUY(렌탈도, 구매도) |
| 7.5~12.5초 | 화성행궁 | 위치 핀 + 정조테마공연장 사진 · **화성행궁에서 첫 라이딩** → 무사 캐릭터 사진 · **행궁동 한 바퀴** |
| 12.5~16.25초 | 그리드 | 사진 4분할이 반 박자마다 바뀜 · SLOW / RIDE / BIG / VIBE / 4 / WHEELS |
| 16.25~20초 | 엔딩 | 라임 배경 **MOBELIX** · 렌탈·구매 상담 · × BLESS 50+ 제휴 · 화성행궁에서 첫발 · @incarvip_bless |
