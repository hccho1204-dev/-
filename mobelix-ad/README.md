# 모벨릭스 네발 전기자전거 광고 (20초, 힙 · 다이나믹 버전)

화성행궁 일대에서 찍은 **실제 사진 5장**으로 만든 모션 광고입니다.

- **톤**: 블랙 · 화이트 · 애시드 라임, 진(zine) 스타일 모서리 정보, 스티커 라벨
- **음악**: 144 BPM 퐁크/트랩 비트 (카우벨 리프 + 16분 하이햇 + 808 슬라이드 + 스네어 롤), 정확히 20초, 직접 합성해서 상업적 사용 가능
- **다이나믹 효과**: 매 비트 컷 전환, 휙 넘기기(휩), 스피드 라인, RGB 잔상, 비트마다 줌 펀치와 화면 흔들림, 빌드업 스트로브
- **비율**: 세로 9:16 (릴스·스토리, 주력), 가로 16:9
- **사진**: `assets/p1~p5.jpg` (AI 이미지는 실제 제품과 모양이 달라 사용하지 않음)

## 스토리보드 (1비트 = 0.42초)

| 시간 | 장면 | 내용 |
|---|---|---|
| 0~2.5초 | 훅 | 박자마다 "두 발" → "말고," → **네 발!** 쾅 → MOBELIX 글자가 하나씩 떨어지고 바퀴 4개 굴러옴 |
| 2.5~7.5초 | 실사 몽타주 | **매 비트 사진 컷** (휩 + RGB 잔상 + 스피드 라인), 3비트마다 스티커: STABLE · E-ASSIST · BIG BASKET · RENT·BUY |
| 7.5~12.5초 | 화성행궁 | 사진 카드가 옆에서 날아오고 비트마다 튐 · **화성행궁에서 첫 라이딩** → **행궁동 한 바퀴** |
| 12.5~16.25초 | 그리드 | 사진 4분할 반 박자 교체 · 4 / WHEELS / BIG / VIBE / LET'S / RIDE / **3 · 2 · 1** (라임 스트로브 빌드업) |
| 16.25~20초 | 엔딩 | 라임 배경 MOBELIX · 비트마다 스티커 팡팡 · @incarvip_bless · 마지막 한 방에 바퀴 4개 + 충격파 |
