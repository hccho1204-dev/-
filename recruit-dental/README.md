# 치위생사 리크루팅 영상 (20초)

치과에서 일하는 치위생사가 인스타를 넘기다 **"이건 내 얘기다"** 하고 멈추게 만드는 영상입니다. 간호사 버전(`recruit-nurse`)과 구조가 같고, 첫 8초를 치위생사의 고민으로 바꿨습니다.

- **첫 문장**: "하루 종일, 허리 숙여 스케일링, 손목은 시큰, 허리는 뻐근할 때"
- **색상**: 앞부분은 차가운 진료실 톤(짙은 청록), 8초부터 블랙·화이트·핑크
- **음악**: 간호사 버전과 같은 곡 (0~8초 잔잔함 → 8초에 밝게 터짐)
- **비율**: 세로 9:16 (릴스·광고용, 주력), 가로 16:9
- **주의**: 수입을 약속하는 문구는 넣지 않았습니다. 진료 시간표(~18, ~21 야간진료, 토요진료)는 흔한 치과 일정을 보여주는 예시입니다.

## 스토리보드

| 시간 | 장면 | 내용 |
|---|---|---|
| 0~4초 | 진료실 · 치아 | 치아 주위로 SCALING이 박자마다 하나씩 쌓이고 09:00–21:00 · **하루 종일, 허리 숙여 스케일링,** |
| 4~8초 | 통증 · 시간표 | **손목은 시큰, 허리는 뻐근할 때,** (핑크 통증 표시) · 야간진료·토요진료 시간표 · "이번 주도, 토요일까지." |
| 8~11초 | 전환 (음악 터짐) | 치아 배지 · **당신의 치과 경력이 무기가 되는 곳** |
| 11~14초 | 경력 매칭 | 구강 질환 지식 → 치아보험 설명 전문가 / 환자 상담 경험 → 고객 신뢰 / 치료비 안내 경험 → 보장 분석 감각 |
| 14~16초 | 지원 | 내가 짜는 스케줄 · 1:1 전담 멘토링 · AI 자동화 도구 |
| 16~20초 | 행동 | **치위생사 경력자 상담 받습니다** · @incarvip_bless DM 주세요 · "허리 펴고, 내 시간을 되찾는 시작" |
