# 치위생사 리크루팅 영상 (20초)

치과에서 일하는 치위생사가 인스타를 넘기다 **"이건 내 얘기다"** 하고 멈추게 만드는 영상입니다. 간호사 버전(`recruit-nurse`)과 구조가 같고, 첫 8초를 치위생사의 고민으로 바꿨습니다.

- **방향**: 힘든 점을 강조하지 않고, **"당신의 경력이 필요합니다 + 그 경력을 인정합니다"**를 전달합니다
- **색상**: 처음부터 블랙·화이트·핑크로 밝고 자신감 있게
- **음악**: 120 BPM, 처음부터 밝은 코드 → 8초에 터짐
- **비율**: 세로 9:16 (릴스·광고용, 주력), 가로 16:9
- **주의**: 수입을 약속하는 문구는 넣지 않았습니다.

## 스토리보드

| 시간 | 장면 | 내용 |
|---|---|---|
| 0~4초 | WANTED | WANTED 글자가 흐르는 배경에 구인 카드가 등장 · 치아 배지 · **치과를 아는 사람** |
| 4~8초 | 필요한 이유 | **치위생사님, 당신의 경력이 필요합니다** · "치아보험 상담은 치과를 아는 사람이 제일 잘하니까" |
| 8~11초 | 경력 인정 (음악 터짐) | 치과에서 보낸 1 → 3 → 5 → **10** YEARS (박자마다) · 그 시간, 그대로 **경력으로 인정합니다** |
| 11~14초 | 경력 매칭 | 구강 질환 지식 → 치아보험 설명 전문가 / 환자 상담 경험 → 고객 신뢰 / 치료비 안내 경험 → 보장 분석 감각 |
| 14~16초 | 지원 | 치과 경력, 그대로 인정(처음부터 다시가 아닙니다) · 1:1 전담 멘토링 · AI 자동화 도구 |
| 16~20초 | 행동 | **치위생사 경력자 상담 받습니다** · @incarvip_bless DM 주세요 · "당신의 경력이 한 번 더 빛나는 시작" |
