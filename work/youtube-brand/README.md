# 유튜브 챕터 인트로 · 구독 아웃트로 (흑백, 시안 4개씩)

완성 영상은 `out/` 폴더에 있습니다. 1920×1080 · 30fps · 효과음 포함.

## 챕터 인트로 (3초)
| 시안 | 파일 | 느낌 |
|---|---|---|
| v1 와이프 바 | `out/intro-v1.mp4` | 흰 바가 화면을 가르고 지나가 제목 밑줄로 변신. 가장 차분하고 깔끔 |
| v2 빅 넘버 | `out/intro-v2.mp4` | 거대한 외곽선 "01"이 검정으로 차오르고 제목이 옆으로 밀려 들어옴 (흰 배경) |
| v3 반전 스플릿 | `out/intro-v3.mp4` | 흰 판이 지나가며 글자 색이 흑↔백으로 뒤집힘. 가장 임팩트 강함 |
| v4 그리드 카운터 | `out/intro-v4.mp4` | 격자가 그려지고 번호가 00→01로 넘어감, 글자가 위에서 떨어짐 |

## 문구 바꾸기 (예: CHAPTER 02, 다른 제목)
`build.py` 맨 위 `TEXT`만 고치고 다시 만들기:
```bash
cd work/youtube-brand/_shared && npm i pretendard gsap@3.14.2   # 처음 1번
cd .. && python3 build.py            # 8개 전부 (약 5분)
python3 build.py intro-v3            # 하나만
python3 build.py --audio-only        # 효과음만 다시 섞기
```
또는 클로드에게 "인트로 v3로 CHAPTER 02 '실전 사례' 만들어 줘"라고 말하면 됩니다.

## 참고
- 효과음은 ffmpeg로 직접 합성 → 저작권 걱정 없음. 음량은 본편 위에 얹기 좋게 -17~-23 LUFS, 피크 -3dB 이하.
- 아웃트로 v3: 유튜브 최종화면은 5~20초 필요. 영상 끝에 붙인 뒤 YouTube Studio에서 최종화면 요소를 그려진 칸 위치에 맞추면 됩니다.
- 캡컷 등 편집기에 그대로 올려 쓰면 됩니다.
