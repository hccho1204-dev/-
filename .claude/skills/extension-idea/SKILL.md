# 확장 기능 아이디어 & 제작 (extension-idea)

## 1단계: 불편함 찾기
아래 순서로 근거를 모은다.
1. `CLAUDE.md`와 `ai-system/wiki/` 길잡이를 읽고 사용자의 업무를 파악한다.
2. 최근 대화·파일에서 **반복되는 수작업**을 찾는다. (복사-붙여넣기, 같은 검색, 같은 표 만들기)
3. 사용자에게 질문 1개만 한다: "요즘 하루에 가장 귀찮은 일 하나만 말해 주세요."

## 2단계: 아이디어 5개 표로 제안
| # | 이름 | 해결하는 불편 | 형태(웹 화면/스킬/루틴) | 만드는 시간 | 효과 |
|---|---|---|---|---|---|

보험 영업 조직 예시:
- 리크루팅 문의 칸반 보드 (문의 → 상담 → 위촉 단계 이동)
- 보장 비교 계산기 (고객 상담 화면에 띄우기)
- 콘텐츠 캘린더 (블로그·숏폼 발행 일정 한눈에)
- 마크다운 뷰어 (파일 2~3개 나란히 보기)
- 브랜드 라이브러리 (로고·사진·영상 모음 + 복사 버튼)

## 3단계: 만들기
- 사용자가 고르면 바로 만든다. 기본 형태는 **HTML 한 장짜리 화면**(설치 불필요).
- 만든 파일은 `ai-system/` 아래에 두고 `ai-system/wiki/커넥터.md`의 "직접 만든 확장 기능" 표에 추가한다.
- 대시보드(`ai-system/dashboard.html`)에 바로가기 카드를 추가할지 묻는다.
