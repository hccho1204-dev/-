# memo-to-minutes — 사진 메모 → 회의록 워드

## 실행 순서

1. **자료 읽기**: 폴더 속 이미지(jpg/png/heic)와 텍스트 메모를 모두 읽는다. 이미지는 직접 보고 글자를 옮겨 적는다.
2. **못 읽은 글자 처리**: 흐리거나 애매한 글자는 추측하지 말고 `[판독불가]` 또는 `[?추정: ○○]` 로 표시.
3. **내용 분류**: 결정사항 / 할 일 / 논의만 된 것 / 다음 회의 안건.
4. **할 일 표 만들기**: 담당자·할 일·마감일·상태. 담당자나 마감일이 메모에 없으면 `미정`으로 두고 빈칸을 지어내지 않는다.
5. **워드 파일 저장**: `회의록_YYMMDD_주제.docx`

## 회의록 양식

```
[회의명]            일시: ○○○○.○○.○○   작성: Claude 초안
참석자: ○○○, ○○○

1. 회의 요약 (3줄)
2. 결정 사항
   - …
3. 팀원별 할 일
   | 담당자 | 할 일 | 마감일 | 비고 |
4. 미결 사항 / 다음 회의 안건
5. 원본 메모 판독 메모 ([판독불가] 목록)
```

## 규칙

- 담당자별로 묶어서 "누가 언제까지 무엇을" 한눈에 보이게.
- 마감일은 `10/14(화)`처럼 요일까지 표기.
- 채팅에는 담당자별 할 일 요약만 짧게 + 파일 경로. 바로 팀 메신저에 붙일 수 있는 5줄 공유문도 함께 준다.

## 프롬프트 예시

```
이미지 속 메모들을 정리해서 팀원들에게 공유할 수 있는 회의록으로 만들어줘.
팀원별로 어떤 업무를 언제까지 해야 하는지 알기 쉽게 정리하고 워드 파일로 만들어줘.
```

워드 생성 세부 기법은 `docx` 스킬이 있으면 함께 따른다.
