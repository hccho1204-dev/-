# orderblock-signal

"급등 직전 마지막 음봉 = 지지, 급락 직전 마지막 양봉 = 저항" 규칙(오더블록 기법)으로
국내 핵심 주도주의 **지지·저항 구간과 매수/매도 신호**를 계산하고, 백테스트로 성과를 검증하는 스킬.

## Trigger

다음 키워드가 포함된 요청에 트리거:
- "오더블록", "지지 구간", "저항 구간", "마지막 음봉", "마지막 양봉"
- "매수 신호", "매도 신호", "상승 신호", "하락 신호"
- "주도주 스캔", "신호 스캔", "차트 신호"
- "이 종목 지금 들어가도 돼?" + 차트 규칙 언급
- "백테스트", "값 다시 잡아줘", "국장에 맞게 최적화"

## 규칙 (5가지)

| # | 규칙 | 코드 설정값 |
|---|---|---|
| 1 | **지지 구간** = 급등 직전 마지막 음봉의 저가~고가 | 급등 = `surge_bars`개 캔들 동안 `surge_pct`% 이상 상승 |
| 2 | **저항 구간** = 급락 직전 마지막 양봉의 저가~고가 | 급락 = `surge_bars`개 캔들 동안 `drop_pct`% 이상 하락 |
| 3 | **매수** = 주가가 지지 구간에 되돌아온 뒤, 종가가 직전 3개 캔들 고가를 모두 돌파 | `break_n`=3, 터치 후 `touch_window`=5일 이내 |
| 4 | **매도** = 저항 구간에 닿은 뒤, 종가가 직전 3개 캔들 저가를 모두 이탈 | `break_n`=3 |
| 5 | **손절** = 보유 중 종가가 매수한 지지 구간 하단을 이탈 | 원 영상에 없는 안전장치 (필수) |

- 구간은 종가로 뚫리면 폐기, 최대 `zone_life`=250캔들(약 1년) 유지
- **국장 기본값**: 급등 10% / 급락 8% / 3캔들 / 돌파 3캔들 (미장보다 변동폭이 크고 가격제한폭 ±30%인 점 반영)
- 기본값을 믿지 말고 `optimize`로 종목군에 맞게 다시 잡는다

## 프로세스 (4단계)

### 1단계: 대상 확정
- 종목을 말하지 않으면 `references/universe.md`의 **핵심 주도주 26종목**(반도체·AI·로봇·2차전지·전력·원전)을 사용
- 사용자가 종목명만 말하면 6자리 코드로 바꿔서 실행
- 사용자가 CSV(증권사 HTS에서 내려받은 일봉)를 주면 `--csv`로 실행

### 2단계: 스캐너 실행
```bash
S=.claude/skills/orderblock-signal/scripts/ob_scanner.py
python3 $S scan 005930 006400 052690          # 현재 상태·지지/저항 구간
python3 $S backtest 006400 --days 1500        # 과거 성과까지
python3 $S optimize 005930 000660 006400 --days 2000   # 국장 맞춤 값 찾기
python3 $S demo                               # 인터넷 없을 때 동작 확인
```
- 외부 라이브러리 불필요 (파이썬만 있으면 됨). 데이터는 야후 파이낸스 일봉 사용
- 인터넷이 막혀 데이터를 못 받으면 → 사용자에게 HTS/네이버증권에서 **일봉 CSV**(date,open,high,low,close)를 받아 달라고 안내

### 3단계: 결과 정리 (아래 출력 형식)
- 🔔 신호(최근 3캔들 이내 발생)가 있는 종목을 맨 위로
- 👀 지지 구간 근접 종목(돌파 대기)을 그다음
- 나머지는 "관망"으로 한 줄씩

### 4단계: 현실 점검 문구 부착
- `references/reality-check.md`의 필수 경고 문구를 **반드시** 마지막에 붙인다
- 백테스트 수치가 단순보유보다 나쁘면 숨기지 말고 그대로 말한다

## 출력 형식

```
## 📡 오더블록 신호 리포트 (YYYY-MM-DD 종가 기준)

### 🔔 신호 발생
| 종목 | 신호 | 가격 | 근거 구간 | 손절선 |
|---|---|---|---|---|
| 삼성SDI | 매수 | 372,000 | 지지 358,000~366,500 (2026-08-12 음봉) | 358,000 이탈 |

### 👀 지지 구간 근접 (3캔들 돌파 대기)
| 종목 | 현재가 | 지지 구간 | 다음 저항 |

### 📊 백테스트 요약 (요청 시)
| 종목 | 거래수 | 승률 | 누적수익 | 최대낙폭 | 단순보유 |

⚠️ 이 신호는 과거 가격 패턴으로 계산한 참고 자료이며 투자 권유가 아닙니다. ...
```

## 실시간 알림으로 쓰려면

스킬 자체는 "물어볼 때 계산"하는 도구다. 매일 자동으로 받으려면:
1. 장 마감 후(예: 평일 16:00) 스캔을 돌리는 **예약 작업(Routine)** 을 만든다
2. 🔔 신호가 있을 때만 카카오톡/슬랙/메일로 보내도록 설정한다
3. 장중 실시간(분봉)은 증권사 API(한국투자증권 KIS 등)가 필요 — 별도 작업

## 체크리스트

- [ ] 잡주가 섞이지 않았는가 (`universe.md` 필터 기준)
- [ ] 신호마다 근거 구간(날짜·가격대)과 손절선을 함께 적었는가
- [ ] 백테스트 결과에 승률·최대낙폭·단순보유 비교가 있는가
- [ ] `optimize` 결과는 검증구간 수익률로 판단했는가
- [ ] 필수 경고 문구를 붙였는가
