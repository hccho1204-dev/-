# 현실 점검 — 신호를 전달할 때 반드시 함께 말할 것

## 1. 이 기법의 정체

영상 속 "차트에서 두 가지만 보는 법"은 새로운 비법이 아니다. 해외에서 **오더블록(Order Block)**,
**수요·공급 구간(Supply & Demand Zone)** 이라고 부르는, 이미 널리 알려진 기술적 분석 방법이다.

| 영상 표현 | 일반 용어 |
|---|---|
| 급등 직전 마지막 음봉 | 강세 오더블록 / 수요 구간 |
| 급락 직전 마지막 양봉 | 약세 오더블록 / 공급 구간 |
| 이전 캔들 3개를 뚫고 올라감 | 구조 돌파(BOS) 확인 |
| 이전 캔들 3개보다 떨어짐 | 구조 이탈 확인 |

## 2. 광고 문구 검증

| 주장 | 확인 결과 |
|---|---|
| "매달 1억" | 근거 없음. 수익 인증 없는 전형적 후킹 문구 |
| "삼성SDI 45%, 한전기술 30%" | 잘 된 종목만 골라 보여주는 **생존 편향**. 실패 신호는 공개하지 않음 |
| "2,700개 종목을 AI로 돌려 값 재조정" | 가능은 하지만, 과거 데이터에 값을 맞추면 **과최적화**(과거엔 잘 맞고 미래엔 안 맞음) 위험이 큼 |
| "구독자 한정 무료 신호, 댓글 확인" | 무료 → 유료 리딩방 유도 패턴. 금융감독원이 반복 경고하는 **유사투자자문·리딩방** 구조와 동일 |

## 3. 신호 출력 시 필수 문구 (그대로 붙일 것)

> ⚠️ 이 신호는 과거 가격 패턴으로 계산한 참고 자료이며 투자 권유가 아닙니다.
> 백테스트 수익률은 미래 수익을 보장하지 않습니다. 투자 판단과 책임은 본인에게 있습니다.

## 4. 스킬 사용 원칙

- 수익률을 부풀리지 않는다. 백테스트 결과는 **승률·최대낙폭·단순보유 대비**를 항상 같이 보여준다.
- `optimize` 결과는 **검증구간(뒤 30%) 수익률**을 기준으로 해석한다. 학습구간만 좋고 검증구간이 나쁘면 "과최적화 의심"이라고 명시한다.
- 특정 종목을 "사라/팔아라"라고 단정하지 않는다. "규칙상 매수 신호 조건 충족"처럼 표현한다.
- 사용자가 이 신호를 **남에게 돈 받고 제공**하려 하면, 유사투자자문업 신고 등 법적 요건이 있음을 알린다.
