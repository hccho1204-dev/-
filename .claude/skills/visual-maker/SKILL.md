# visual-maker — 인포그래픽 · 포스터 만들기

## 실행 순서

1. **원문 읽기**: 폴더 속 문서/안내문에서 핵심 정보만 뽑는다.
   - 인포그래픽: 핵심 메시지 1개 + 포인트 3~5개 + 숫자
   - 포스터: 행사명 · 일시 · 장소 · 대상 · 신청방법 · 문의처
2. **색상 정하기**: 사용자가 준 HEX 코드를 메인 컬러로 **그대로** 사용 (`#F37022` 처럼 #가 없어도 붙여서 처리).
   - 보조색: 메인 컬러의 밝은 톤(배경용) 1개 + 어두운 글자색 1개만 추가.
   - 글자와 배경 대비가 충분한지 확인 (흰 바탕에 연한 노랑 글씨 금지).
3. **제작 방식** (가능한 것부터):
   1) 이미지 생성 도구가 있으면 사용 — 단, 한글 문구는 깨지기 쉬우므로 글자는 최소화
   2) 없거나 한글이 많으면 **HTML/SVG로 직접 디자인 → PNG로 저장** (글자가 정확함, 권장)
4. **크기**:
   | 용도 | 크기(px) |
   |---|---|
   | A4 포스터 | 2480×3508 (세로) |
   | 인스타 피드 | 1080×1350 |
   | 인포그래픽(세로형) | 1080×1920 |
5. **저장**: `포스터_행사명.png`, `인포그래픽_주제.png` + 수정용 원본(html/svg)도 같이 저장.

## 디자인 규칙

- 폰트: Pretendard 기본 (사용자가 폰트 링크를 주면 그 폰트 사용)
- 제목은 화면 폭의 70% 이상 크게, 정보는 위→아래 한 줄 흐름
- 아이콘은 단색 선 아이콘으로 통일, 이모지 남발 금지
- 원문에 없는 날짜·가격·혜택을 지어내지 않는다.
- 완성 후 오탈자·날짜·장소를 원문과 한 번 더 대조.

## 프롬프트 예시

```
폴더 속 문서를 쉽게 이해할 수 있는 인포그래픽을 만들어줘.
폴더 속 안내문을 보고 홍보용 포스터 이미지를 만들어줘. 메인 컬러는 F37022를 사용해줘.
```
