# aside-browser — 어사이드로 로그인된 사이트 자동화

어사이드는 **사용자가 미리 로그인해 둔 브라우저**를 클로드가 대신 조작하게 해 주는 AI 브라우저다.
비밀번호는 어사이드 금고(Vault)에 있고 클로드에게는 보이지 않는다.

## 0단계: 연결 확인 (매번 가장 먼저)

```bash
command -v aside || ls "$HOME/.local/bin/aside"
aside --help
```

- `aside`가 없으면 → 사용자에게 `ASIDE_설치가이드.md`의 1~3단계를 안내하고 멈춘다. 직접 설치를 시도하지 않는다(어사이드 앱 본체는 사용자가 설치해야 함).
- `aside --help` 결과를 읽고 실제 하위 명령 이름을 확인한다. **이 문서의 명령과 다르면 `--help`가 정답이다.**
- 클라우드(원격) 세션이라면 어사이드는 사용자 컴퓨터에만 있으므로 쓸 수 없다고 알린다.

## 쓰는 방법 3가지 (상황별 선택)

| 방법 | 명령 | 언제 쓰나 |
|---|---|---|
| ① 한 줄 지시 | `aside "할 일을 자연어로"` | 단순 작업. 어사이드 에이전트가 알아서 수행 |
| ② REPL(정밀 조작) | `aside repl` | 캡처·정해진 순서대로 클릭/입력해야 할 때 |
| ③ MCP | `aside mcp` (클로드 코드에 등록) | 클로드가 도구처럼 직접 호출. 가장 편함 |

이어서 작업할 때는 `--session` 옵션으로 이전 세션을 계속 쓴다(`aside --help`로 정확한 형식 확인).

### ① 한 줄 지시 예시

```bash
aside "인스타그램에서 #AI자동화 인기 게시물 상위 9개 열고 각각 캡처해서 ./captures 에 저장"
```

### ② REPL 예시 (Playwright와 비슷한 문법)

```js
const tabs = await listBrowserTabs();
const tab = await attachBrowserTab(tabs[0].targetId);  // 이미 열린(로그인된) 탭에 붙기
await tab.goto('https://www.instagram.com/');
await tab.waitForLoadState();
await tab.screenshot({ path: 'captures/instagram-home.png' });
console.log(await tab.title(), await tab.url());
```

### ③ MCP 등록 (한 번만)

```bash
claude mcp add aside -- aside mcp
```

등록 후 클로드 코드를 다시 열면 어사이드 도구가 보인다. 이후로는 자연어로 시키면 된다.

## 반드시 지킬 규칙 (실수 목록)

1. **새 탭 말고 기존 탭에 붙어라.** REPL의 `openTab()`으로 연 탭은 명령이 끝나면 사라진다. 로그인 상태가 필요한 작업은 `listBrowserTabs()` → `attachBrowserTab()`로 기존 탭을 쓴다.
2. `title()`, `url()`은 **함수**다. 괄호를 붙여 호출한다.
3. `waitForLoad`는 없다. **`waitForLoadState`** 를 쓴다.
4. "완료했다"는 에이전트 보고를 믿지 말고 **결과 파일(캡처 이미지·CSV)이 실제로 생겼는지** `ls`로 확인한다.
5. 캡처·수집 결과는 작업 폴더 안 `captures/YYYYMMDD-주제/` 에 저장한다.
6. **바깥으로 나가는 행동은 먼저 묻는다.** 게시글 올리기, 댓글·DM 보내기, 결제, 설정 변경, 삭제는 사용자 확인 없이 하지 않는다. 조회·캡처는 바로 해도 된다.
7. 비밀번호·인증번호를 사용자에게 묻거나 파일에 적지 않는다. 로그인이 풀려 있으면 "어사이드에서 직접 로그인해 주세요"라고 안내한다.
8. 사이트 이용약관을 지킨다. 대량 수집(수백 건 이상)·자동 팔로우/좋아요 같은 스팸성 반복 행동은 하지 않는다.

## 자주 쓰는 업무 레시피

### A. SNS 레퍼런스 수집 (인스타·스레드·X)
1. 주제 키워드를 받는다.
2. 각 플랫폼에서 검색 → 반응 좋은 게시물 5~10개 선택.
3. 게시물마다 캡처 + 링크·좋아요·댓글 수·핵심 문구를 `captures/.../레퍼런스.md` 표로 정리.
4. 마지막에 "공통 패턴 3가지 + 내 콘텐츠에 쓸 아이디어 5개" 요약.

### B. 유튜브 스튜디오 주간 점검
1. 유튜브 스튜디오 → 분석 탭 캡처(최근 7일).
2. 조회수·시청 시간·구독자 증감·인기 영상 TOP5를 표로 정리.
3. 지난주 파일이 있으면 비교해서 "올라간 것 / 내려간 것" 한 줄씩.

### C. 판매자센터·관리자 페이지 확인
1. 주문·문의·정산 화면 캡처.
2. 미처리 건수만 숫자로 요약. **답변·처리 버튼은 누르지 않는다**(규칙 6).

## 막혔을 때

| 증상 | 조치 |
|---|---|
| `aside: command not found` | 어사이드 설정 → 개발자 → CLI 설치 후 터미널 재시작 |
| 로그인 화면이 뜸 | 사용자에게 어사이드에서 직접 로그인 요청 |
| 엉뚱한 창을 조작함 | 어사이드 창을 하나만 띄우고 다시 시도(마지막으로 클릭한 창에 붙음) |
| 명령이 응답 없이 멈춤 | Ctrl+C로 끊고 REPL 방식(②)으로 단계를 쪼개서 재시도 |
| CLI가 오래됨 | `aside --update` |
