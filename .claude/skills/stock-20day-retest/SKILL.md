# 20일 신고가 리테스트 종목 찾기 (stock-20day-retest)

> 핵심: **싸진 주식을 사는 게 아니라, 고점을 뚫고도 다시 무너지지 않는 주식을 산다.**
> 20일 신고가 돌파 → 조정 → 돌파 가격 방어 → 매수

## 전략 규칙 (스크리너가 그대로 계산함)

| 단계 | 쉬운 설명 | 계산 기준 (기본값) |
|---|---|---|
| ① 돌파 | 최근 20일 동안 제일 비쌌던 가격을 넘어서 마감한 날 | 종가 > 직전 20거래일 최고가(= **돌파 기준가**) |
| ② 조정 | 돌파 직후 바로 사지 않고 이틀 정도 쉬어가길 기다림 | 돌파 후 하락 마감한 날 2일 이상 |
| ③ 방어 | 조정 중에도 돌파 기준가 밑으로 안 떨어짐 | 돌파 이후 모든 종가 ≥ 돌파 기준가 |
| ④ 매수 | 지켜냈다고 판단하고 매수 | ①~③ 충족 + 오늘 반등(상승 마감)이면 "매수 신호" |

예) 20일 최고가 10만원 → 10만 5천원으로 돌파 → 이틀 조정(10만 2천원) → 10만원 밑으로 안 떨어짐 → 매수

## 결과 상태 구분

| 표시 | 의미 | 할 일 |
|---|---|---|
| ✅ 매수 신호(반등 확인) | 조정 끝나고 오늘 다시 올라감 | 매수 검토 1순위 |
| 🟢 매수 후보(방어 중) | 조정 2일 이상, 아직 기준가 위에서 버티는 중 | 반등 나오면 매수 |
| ⏳ 조정 대기 | 돌파 후 조정이 아직 부족 | 관심종목에 넣고 대기 |
| 🔔 오늘 돌파 | 오늘 막 신고가 돌파 | 바로 사지 말고 조정 기다리기 |
| (제외) | 돌파 기준가 밑으로 무너짐 = 가짜 돌파 | 목록에서 자동 제외 |

## 실행 순서

1. **범위 정하기** — 사용자가 말하지 않으면 기본값으로 바로 실행: 한국 시총 상위 300 + 미국 대형주 약 100개.
   특정 종목을 말하면 그 종목만 검사.
2. **라이브러리 설치** (처음 한 번)
   ```bash
   pip install -q pandas finance-datareader yfinance pykrx
   ```
3. **스크리너 실행** (스킬 폴더의 `scripts/retest_screener.py`)
   ```bash
   python scripts/retest_screener.py --market kr --top 300      # 한국
   python scripts/retest_screener.py --market us                # 미국
   python scripts/retest_screener.py --market all --only-buy    # 전체, 매수 신호·후보만
   python scripts/retest_screener.py --tickers 005930 000660 NVDA   # 특정 종목만
   ```
   옵션: `--max-days-after 7`(돌파 후 며칠까지 볼지) · `--min-pullback 2`(조정 일수) ·
   `--tolerance 0.01`(기준가 1% 아래까지 봐주기) · `--stop-buffer 0.03`(손절가 = 기준가 −3%)
4. **네트워크가 막혀 데이터가 안 받아질 때** (대체 경로, 순서대로 시도)
   - `UsStockInfo-get_historical_stock_prices` 같은 주가 조회 도구(MCP)로 최근 3개월 일봉을 받아 CSV(`Date,Open,High,Low,Close,Volume`)로 저장 → `--csv-dir 폴더`로 실행
   - 웹 검색으로 종목별 최근 20일 최고가·현재가를 확인해 위 규칙표대로 직접 판정
   - 사용자에게 증권앱 HTS의 조건검색 설정값을 안내(아래 "증권앱 조건검색" 참고)
5. **결과 정리** — 아래 출력 형식으로 보고.

## 출력 형식

1. 한 줄 요약: "검사 N개 중 매수 신호 X개, 후보 Y개, 대기 Z개"
2. 스크리너가 만든 표 그대로 (상태 순 → 기준가에 가까운 순 정렬)
3. 매수 신호·후보 상위 3~5개에 대해 한 줄 코멘트
   - 기준가 대비 거리(가까울수록 손절폭이 작아 유리), 돌파 거래량(2배 이상이면 신뢰도 ↑)
4. 매매 원칙 박스
   - **매수**: 조정 후 기준가 위에서 반등할 때
   - **손절**: 종가가 돌파 기준가 −3% 밑으로 마감하면 정리 (돌파 실패로 판단)
   - **목표**: 1차 목표 = 매수가 + 손실폭 × 2 (손익비 1:2)
5. 마지막 줄 고지: "이 결과는 조건에 맞는 종목을 기계적으로 찾은 것이며 투자 권유가 아닙니다. 최종 판단과 책임은 본인에게 있습니다."

## 증권앱 조건검색으로 따라 하기 (코드 없이)

| 조건 | 설정 |
|---|---|
| A | 최근 7봉 이내 [종가가 20봉 최고가 돌파] 발생 |
| B | 현재 종가 ≥ 돌파 당시 20봉 최고가 (돌파가 지지) |
| C | 최근 3봉 중 음봉 2개 이상 (조정 확인) |
| D | 거래대금 50억 이상 (유동성) |

## 주의사항

- 돌파일 거래량이 평소보다 약하면(1배 미만) 가짜 돌파 가능성 ↑ → 메모에 표시됨
- 현재가가 기준가보다 10% 이상 위면 손절폭이 커져 손익비가 나쁨 → 메모에 표시됨
- 시장 전체가 급락하는 날에는 신호가 무더기로 무너질 수 있으니 지수 흐름도 함께 확인
