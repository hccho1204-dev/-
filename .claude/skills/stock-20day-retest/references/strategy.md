# 캔디스 라우 '20일 신고가 리테스트' 전략 상세

## 원문 요지
- 최근 20일 최고가를 돌파한 종목을 찾되, 돌파 직후에는 바로 매수하지 않는다.
- 예: 10만원이 20일 최고가였다면, 10만원을 돌파한 뒤 이틀 정도 조정을 기다린다.
- 이때 다시 10만원 밑으로 무너지지 않으면 "돌파 가격을 지켜냈다"고 보고 매수한다.
- 즉, 20일 신고가 돌파 → 조정 → 돌파 가격 방어 → 매수.
- 핵심은 싸진 주식을 사는 게 아니라, 고점을 뚫고도 다시 무너지지 않는 주식을 사는 것.

## 왜 통하나 (쉬운 설명)
- 20일 최고가 근처는 "이 가격이면 팔겠다"는 사람이 몰려 있는 벽이다.
- 벽을 뚫은 뒤 잠깐 밀려도 벽 위에서 버틴다면, 예전의 '파는 벽'이 '받쳐주는 바닥'으로 바뀐 것이다.
- 그래서 바닥(돌파 기준가) 바로 위에서 사면 손절 폭은 작고, 다시 오를 때 얻는 폭은 크다.

## 스크리너 판정 로직
1. 최근 7거래일 안에서 가장 최근의 "새로운 돌파일"을 찾는다
   (전날은 돌파 상태가 아니었고, 그날 종가가 직전 20일 최고가를 넘은 날).
2. 돌파 기준가 L = 돌파일 직전 20거래일의 최고가(고가 기준).
3. 돌파 다음 날부터 오늘까지 종가 중 하나라도 L 밑이면 → 실패, 제외.
4. 돌파 후 하락 마감일 수 < 2 → 조정 대기 / ≥ 2 → 매수 후보, 오늘 상승 마감이면 매수 신호.
5. 손절가 = L × 0.97, 1차 목표 = 현재가 + (현재가 − 손절가) × 2.

## 예시 (10만원 사례)
| 날짜 | 종가 | 판정 |
|---|---|---|
| D-1 | 99,000 | 20일 최고가 100,000 |
| D (돌파일) | 105,000 | 🔔 오늘 돌파 |
| D+1 | 103,000 | ⏳ 조정 1일 |
| D+2 | 101,500 | 🟢 조정 2일, 100,000 위 방어 |
| D+3 | 103,500 | ✅ 반등 → 매수 신호 (손절 97,000 / 목표 116,500) |
| (만약 D+2 종가 98,000) | — | 제외 (돌파 실패) |
