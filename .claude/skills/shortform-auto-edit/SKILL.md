# shortform-auto-edit — 레퍼런스 학습형 숏폼 자동 편집

사람이 3~4시간 걸리던 숏폼 1편 편집을 **원본 한 개 → 약 7분, 약 500원**으로 끝내는 작업틀.
핵심은 하나다: **말로 설명하지 말고, 잘된 완성본(레퍼런스)을 보여 준다.**

## Trigger

- "숏폼 편집해줘", "이 원본 편집해줘", "쇼츠/릴스 만들어줘"
- "레퍼런스처럼 편집해줘", "편집 스타일 학습해줘"
- "효과음 넣어줘", "애플 느낌으로 바꿔줘" (같은 컷, 다른 모션그래픽)

## 전체 흐름 한눈에

| 단계 | 하는 일 | 처음 1번만? | 결과물 |
|---|---|---|---|
| A | 레퍼런스 학습 | ✅ 처음 1번 | `STYLE_GUIDE.md` |
| B | 원본 받아쓰기 | 매번 | `work/<이름>/words.json` |
| C | 테이크 정리 (재촬영·잡담 제거) | 매번 | `takes.json` |
| D | 호흡 압축 + 확대 컷 + 자막 | 매번 | `cut.mp4` |
| E | 모션그래픽 + 효과음 (HyperFrames) | 매번 | `final.mp4` |
| F | 자가 검수 (2초 간격 돌려보기) | 매번 | 고친 `final.mp4` |
| G | 실수를 규칙으로 | 실수 났을 때 | `references/mistake-log.md` 한 줄 |

## A단계 — 레퍼런스 학습 (처음 1번만)

`STYLE_GUIDE.md`가 이미 있으면 **이 단계를 건너뛴다.**

1. 사용자에게 레퍼런스 완성본 3~5개를 `refs/` 폴더에 넣어 달라고 한다.
   - 내 채널 완성본이 제일 좋다. 없으면 인스타·유튜브에서 "이런 느낌 좋다" 싶은 숏폼을 화면 녹화한 것도 된다.
2. 레퍼런스마다 실행:
   ```bash
   python3 scripts/transcribe.py refs/ref1.mp4 work/refs/ref1.words.json
   python3 scripts/analyze_reference.py refs/ref1.mp4 work/refs/ref1.words.json work/refs/ref1
   ```
   - 화면을 **1초 간격**으로 캡처 (`frames/`), 받아쓰기로 **단어마다 타이밍** 확보
   - 말 사이 빈틈, 말 속도(초당 글자), 컷 길이, 길이를 숫자로 뽑아 `stats.json` 저장
3. 1초 캡처 이미지를 직접 보면서 숫자로 안 잡히는 것을 적는다:
   - 자막: 색·그림자·크기(px)·위치(화면 높이 몇 % 지점)·한 줄 글자 수
   - 확대: 컷마다 몇 배로 번갈아 바뀌는지
   - 전환 효과: 있는지 없는지 (보통 **없이 바로 컷**)
   - 모션그래픽 종류: 상단 패널 / 하단 카드 / 도입 로고 팝업 / 그래프 / 흐름도 / 키워드 칩 등, 몇 초마다 바뀌는지
4. `references/style-guide-template.md` 양식을 채워 **작업 폴더 최상단에 `STYLE_GUIDE.md`로 저장**한다.
   이후 모든 편집은 이 파일만 기준으로 한다.

## B단계 — 원본 받아쓰기

```bash
python3 scripts/transcribe.py raw/원본.mp4 work/<이름>/words.json
```
단어 하나하나 시작·끝 시간이 들어간 시간표가 나온다. 이게 모든 편집의 기준이다.

## C단계 — 테이크 정리 (AI가 판단)

`words.json`을 문장 단위로 읽으면서 아래를 직접 판단해 `work/<이름>/takes.json`을 만든다.

| 상황 | 처리 |
|---|---|
| 같은 문장을 여러 번 다시 말함 | **가장 깔끔한 마지막 완성 테이크 1개만** 남김 (말 절음·더듬음 없는 것) |
| 문장 중간에 말을 절고 다시 시작 | 절은 앞부분 버리고 다시 말한 부분부터 살림 |
| 촬영 중 잡담, "다시 갈게요", 혼잣말 | 전부 제거 |
| 목표 길이 초과 | 핵심과 거리가 먼 문장부터 뺌 |

`takes.json` 형식 (남길 구간만, 시간순):
```json
{"keep": [{"start": 3.12, "end": 7.80, "text": "아 영상 편집자님들 정말 죄송합니다"}]}
```
**판단 근거를 표로 사용자에게 보여 준다** (버린 테이크 / 남긴 테이크 / 이유).

## D단계 — 호흡 압축 + 확대 컷 + 자막

```bash
python3 scripts/make_cutlist.py work/<이름>/words.json work/<이름>/takes.json work/<이름>/cutlist.json --max-gap 0.1 --pad 0.04
python3 scripts/render_cut.py raw/원본.mp4 work/<이름>/cutlist.json work/<이름>/cut.mp4 --zooms 1.2,1.4 --font-size 80 --y 0.55
```
- **호흡 압축**: 남긴 구간 안에서도 단어 사이 쉬는 틈이 `--max-gap`(기본 0.1초)보다 길면 잘라 붙인다
- **확대 컷**: 테이크가 바뀔 때마다 확대 배율을 번갈아 써서 몰입감을 준다 (전환 효과 없이 바로 컷)
- **자막**: `STYLE_GUIDE.md`의 한 줄 글자 수에 맞춰 짧게 끊어 타이밍에 맞게 입힌다
- 숫자(배율·폰트 크기·위치·빈틈)는 **반드시 `STYLE_GUIDE.md` 값으로 바꿔서** 실행한다
- 결과 길이를 확인하고 사용자 목표(기본 40~60초)를 벗어나면 C단계로 돌아간다

**말 속도 제안**: 원본 말 속도(초당 글자)가 레퍼런스보다 느리면 배속(예: 1.08배)을 **제안만** 한다.
목소리가 깨질 수 있으니 사용자가 OK할 때만 `--speed 1.08`을 붙인다.

## E단계 — 모션그래픽 + 효과음 (HyperFrames)

모션그래픽은 **HyperFrames** 스킬(HeyGen이 공개한 HTML 기반 영상 제작 도구)로 만든다.
설치·권한·사용법은 `references/hyperframes-setup.md` 참고.

1. 대본을 보고 장면마다 어울리는 그래픽을 **AI가 직접 기획**한다 (`STYLE_GUIDE.md`의 모션그래픽 종류·주기 기준):
   | 말하는 내용 | 그래픽 |
   |---|---|
   | 모델·가격·수치 비교 | 막대 그래프가 쭉 올라감 |
   | 단계·순서 설명 | 흐름도가 차례로 진행 |
   | 키워드 여러 개 나열 | 칩이 하나씩 "탁탁" 등장 |
   | 도입부 | 로고 팝업 |
   | 마무리 | 하단 카드 (영상 **끝까지** 유지) |
2. 글자·카드 등장은 **팝(뽀잉 튀어나오는) 효과**를 기본으로 쓴다.
3. 효과음: HyperFrames 효과음 라이브러리에서 그래픽 등장·전환 순간에 짧게 넣는다 (팝, 휙, 딸깍 등). 말소리보다 작게.
4. `cut.mp4` 위에 합성해 `work/<이름>/final.mp4`로 렌더한다.

**스타일 변형** ("애플 느낌으로", "키노트 스타일로" 등): 컷·자막은 그대로 두고 **모션그래픽만** 해당 스타일로 바꾼 두 번째 버전(`final_v2.mp4`)을 만든다.

## F단계 — 자가 검수 (말하기 전에 스스로 찾기)

```bash
bash scripts/qa_frames.sh work/<이름>/final.mp4 work/<이름>/qa 2
```
렌더 결과를 **2초 간격**으로 캡처해 전부 직접 본다. `references/qa-checklist.md`의 항목을 하나씩 확인하고,
걸리는 게 있으면 **사용자가 말하기 전에 고쳐서 다시 렌더**한다.
고친 내용은 결과 보고에 "스스로 찾아 고친 것"으로 따로 적는다.

## G단계 — 실수를 규칙으로

검수나 사용자 피드백에서 실수가 나오면 고치고 끝내지 말고 `references/mistake-log.md`에 한 줄 추가한다.
다음 편집부터 C~F 단계에서 이 목록을 먼저 읽고 시작한다.

## 결과 보고 양식

| 항목 | 값 |
|---|---|
| 원본 길이 → 완성 길이 | 3분 57초 → 52.7초 |
| 제거한 무음 구간 | 27곳 (최장 7.5초) |
| 버린 재촬영 테이크 | N개 |
| 자막 수 | 61개 |
| 모션그래픽 | 그래프 N · 흐름도 N · 칩 N · 카드 N |
| 효과음 | N개 |
| 스스로 찾아 고친 것 | 예: 마지막 카드가 2초 일찍 사라짐 → 끝까지 유지 |
| 제안 | 예: 말 속도 레퍼런스보다 느림 → 1.08배 제안 (현재 유지) |
| 걸린 시간 / 사용량 | 약 N분 |

## 필요한 도구

| 도구 | 용도 | 설치 |
|---|---|---|
| ffmpeg / ffprobe | 자르기·붙이기·자막·캡처 | 대부분 설치돼 있음 |
| faster-whisper (또는 openai-whisper) | 단어 단위 받아쓰기 | `pip install faster-whisper` |
| HyperFrames 스킬 | 모션그래픽·효과음 | "하이퍼프레임 스킬 설치해 줘" → 권한 허용 1번 |

## 세 줄 요약

1. 잘 나온 완성본을 **레퍼런스로 준다**
2. AI가 편집 스타일을 숫자로 학습해 **`STYLE_GUIDE.md`로 저장**한다
3. 그다음부터는 **원본만 넣으면** 약 7분 만에 완성본이 나온다
