# STYLE_GUIDE.md 양식

> A단계(레퍼런스 학습)에서 이 양식을 채워 작업 폴더 최상단에 `STYLE_GUIDE.md`로 저장한다.
> 괄호 안 값은 영상 예시(옥크드리 채널 레퍼런스 5개 분석 결과)다. **실제 분석값으로 바꿔 쓴다.**

## 0. 출처
- 분석한 레퍼런스: (ref1.mp4 ~ ref5.mp4, 5개)
- 분석일: YYYY-MM-DD

## 1. 길이·호흡
| 항목 | 값 | 근거 |
|---|---|---|
| 완성본 길이 | (40~60초) | stats.json duration 평균 |
| 말과 말 사이 최대 빈틈 | (0.32초 — 숨 쉬는 구간까지 사실상 다 잘라냄) | gap_max |
| 말 속도 | (초당 8.5~9자) | chars_per_sec |
| 평균 컷 길이 | (N초) | cut_len_avg |
