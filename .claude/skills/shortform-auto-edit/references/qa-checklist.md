# 자가 검수 체크리스트 (F단계)

`scripts/qa_frames.sh`로 2초 간격 캡처 후 **전부 직접 보고** 확인한다. 하나라도 걸리면 고쳐서 다시 렌더 → 다시 검수.

## 컷·소리
- [ ] 같은 문장이 두 번 나오지 않는다 (재촬영 테이크 중복 없음)
- [ ] 말을 절거나 더듬은 부분이 남아 있지 않다
- [ ] 단어가 중간에 잘려 끊기지 않는다 (앞뒤 여유 `--pad` 확인)
- [ ] 어색하게 튀는 장면 전환이 없다 (같은 배율 컷이 연달아 붙어 "점프"처럼 보이지 않음)
- [ ] 완성 길이가 목표 범위 안 (기본 40~60초)
- [ ] 효과음이 말소리를 덮지 않는다

## 자막
- [ ] 자막이 말과 맞는다 (0.2초 이상 어긋남 없음)
- [ ] 오타·받아쓰기 오류가 없다 (고유명사·숫자 특히)
- [ ] 한 줄 글자 수·크기·위치가 STYLE_GUIDE와 같다
- [ ] 팝 등장 효과가 적용돼 있다

## 모션그래픽
- [ ] 그래픽이 자막·얼굴을 가리지 않는다
- [ ] 그래프 숫자가 실제 말한 숫자와 같다
- [ ] **마지막 카드가 영상 끝까지 남아 있다** (일찍 사라지지 않음)
- [ ] 3~6초마다 레이아웃 변화가 있다 (STYLE_GUIDE 주기)
