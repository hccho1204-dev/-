# cardnews-daily — 매일 루틴 총괄 (팀장 담당)

직접 만들지 않는다. **어디까지 됐는지 보고, 다음 사람에게 넘긴다.**

## 1) 상태 점검
`cardnews-automation/sets/` 에서 오늘 날짜(`YYYY-MM-DD_`)로 시작하는 폴더를 찾고, 각 단계 판정:

| 단계 | 완료 조건 |
|---|---|
| ① 기획 | `plan.json`의 모든 장 headline 채워짐 + `memory/topics-used.md`에 오늘 줄 있음(=채택) |
| ② 이미지 | `images/01~09` 존재 → `check_set.py` 가 READY |
| ③ 디자인 | `output/` 에 이미지 9장 |
| ④ 업로드 | `topics-used.md` 업로드 칸이 `업로드완료` |

어제 이전 폴더 중 ③까지 됐는데 ④가 안 된 게 있으면 함께 알려준다 ("어제 거 아직 안 올리셨어요").

## 2) 보고 형식 (항상 이 표 + 다음 명령어)
```
📅 2026-09-24 (수) — 오늘 카테고리: 커리어/이직

| 단계 | 상태 |
|---|---|
| ① 기획 | ✅ |
| ② 이미지 | ⏳ 5/9장 |
| ③ 디자인 | — |
| ④ 업로드 | — |

👉 다음 할 일: 이미지 4장 더 (06~09)
```
그 아래 **복사용 명령어** 코드블록 1개 + 어디서 실행하는지(새 대화 / Cowork) 한 줄.

## 3) 오늘 폴더가 없으면
- brand.md 요일 카테고리 + topics-used.md(중복 제외) 기준으로 `cardnews-plan` 모드 A(주제 3개 추천)를 바로 실행.
- **예약 실행(사람이 없는 자동 실행)일 때**: 추천 1번 주제로 기획안까지 끝까지 작성·저장하고, "채택 대기" 상태로 둔다. 채택·이미지·디자인은 사람이 확인한 뒤 진행.

## 4) 사용자가 "올렸어" / "업로드 완료"
`topics-used.md` 오늘 줄 업로드 칸 → `업로드완료`. "수고하셨습니다. 내일 카테고리는 ○○입니다." 한 줄로 마무리.

## 주간 회고 (일요일 또는 "이번 주 정리")
- 이번 주 세트 목록 + 업로드 여부 표
- 사용자가 조회수/저장수를 알려주면 `memory/approved.md` 해당 항목에 `성과: 조회 00 / 저장 00` 추가 → 다음 기획 때 성과 좋은 후킹 유형을 우선 사용.
