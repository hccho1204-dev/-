# 상황별 말하기 예시 (복사해서 쓰기)

프롬프트 공식보다 중요한 것: **내가 원하는 걸 명확히 + 레퍼런스.** 추상적인 말("임팩트 있게")만으로는 부족하다.

## 1. 처음 세팅
```
이 폴더에 있는 영상 도구 안내 문서 확인하고, 리모션·하이퍼프레임·오픈몬테이지 중 없는 것만 한 번에 다 설치해 줘. 끝나면 점검표 보여 줘.
```

## 2. 유튜브 중간 인트로 + 아웃트로
```
내 유튜브 채널용 모션그래픽 2개 만들어 줘.
1) 챕터 시작 때 들어가는 중간 인트로 (3초, "챕터 1 핵심 정리"처럼 제목이 들어감)
2) 마지막 아웃트로 (5초, "영상이 도움이 됐다면 구독·좋아요·알림 설정")
채널 톤은 블랙 앤 화이트. 심플하지만 임팩트 있게.
가로 1920x1080, 30fps. 효과음도 넣어 줘. 시안은 각각 4개씩.
```

## 3. 모음 사이트에서 골라 재가공
```
이 링크 확인해 줘: <사이트 주소>
여기 모션그래픽 중에서 우리 컨셉(흑백 미니멀, 챕터 인트로)에 제일 맞는 후보 4개를 골라서 표로 보여 주고,
그걸 참고해 우리만의 영상으로 재가공한 시안 4개 만들어 줘.
```

## 4. 마음에 드는 게 이미 있음
```
이 3개 레퍼런스(refs 폴더) 같은 움직임인데, 비주얼은 흑백 미니멀로 바꿔서 시안 4개 만들어 줘.
```

## 5. 내 영상 포맷 그대로 복제
```
refs 폴더에 있는 내 채널 완성본 3개를 해부해서 VIDEO_SPEC 만들어 줘. 레이어 하나도 빠뜨리지 말고.
그다음 script.txt 대본으로 같은 스타일 영상 만들어 줘. 지루하지 않게 효과 풍성하게, 후킹 강하게.
```

## 6. 촬영본 위에 그래픽만
```
raw/촬영본.mp4 위에 하이퍼프레임으로 자막이랑 숫자 강조 그래픽 얹어 줘.
숫자 나올 때마다 크게 카운트업, 키워드는 칩으로 탁탁. 대본에 없는 숫자는 절대 넣지 마.
```

## 7. 주제만 주고 통째로 (오픈몬테이지)
```
오픈몬테이지로 "보험설계사 첫 달 수입 현실"을 주제로 45초 세로 설명 영상 만들어 줘.
조사 → 대본 → 나레이션 → 배경음악 → 자막까지. 스타일은 work/refs/ref1/VIDEO_SPEC.json 따라.
```

## 8. 야간 모드
```
오늘 밤에 이 3개 작업 걸어 둬:
1) 챕터 인트로 시안 4개  2) 아웃트로 시안 4개  3) script.txt 숏폼 1편
다 끝나면 비공개 업로드 준비까지만 하고, 아침에 볼 보고서 만들어 놔.
```

## 9. 고칠 때 (말 대신 숫자로)
| 이렇게 말하지 말고 | 이렇게 |
|---|---|
| "좀 더 빠르게" | "평균 컷 길이를 1.2초로" |
| "글씨 크게" | "자막 크기를 화면 높이의 7%로" |
| "덜 정신없게" | "장면당 등장 요소를 최대 3개로" |
| "다른 느낌으로" | "v2 그대로 두고 v5로 애플 키노트 스타일 하나 더" |
