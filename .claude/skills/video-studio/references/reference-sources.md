# 레퍼런스 찾는 곳·고르는 법

## 우선순위
1. **내 채널·우리 회사 완성본** — 제일 좋다. 이미 원하는 스타일이니 그대로 복제하면 된다.
2. **모션그래픽 모음 사이트** — 수백 개 예시와 프롬프트가 모여 있는 사이트 링크 하나만 있으면 충분.
3. **마음에 드는 유튜브·숏폼** — 화면 녹화해서 `refs/`에 넣는다.
4. 아무것도 없으면 → `motion-graphics/references/tone-cards.md`의 톤 코드 하나 고르기.

## 사이트 링크를 받았을 때 (클로드가 하는 일)
1. 사이트를 열어(브라우저 도구) 예시 목록을 훑는다.
2. 사용자 의도(채널 톤·용도·길이)와 비교해 **후보 3~4개**를 표로 고른다:
   | 후보 | 링크 | 왜 맞는지 | 가져올 요소 |
3. 각 후보의 영상·프롬프트를 저장하고, 영상이면 `decode_reference.py`로 해부한다.
4. 후보 하나를 그대로 베끼지 않고 **우리 톤으로 재가공**한 시안을 만든다.

## 좋은 레퍼런스 조건
| 조건 | 이유 |
|---|---|
| 길이가 만들 영상과 비슷 | 컷 속도가 그대로 옮겨진다 |
| 화면 방향이 같음 (세로/가로) | 레이아웃을 그대로 쓸 수 있다 |
| 3~5개 | 1개면 우연, 여러 개면 공통 패턴이 숫자로 보인다 |
| 사람 동작보다 글자·그래픽 위주 | 클로드가 잘 재현하는 영역 |

## 저작권
- 레퍼런스는 **스타일(숫자·구조)만** 학습한다. 문구·로고·캐릭터·음악은 가져오지 않는다.
- 스톡·음악은 라이선스가 확인된 것만 (OpenMontage 무료 소스 등).
