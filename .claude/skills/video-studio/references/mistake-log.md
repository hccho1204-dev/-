# 누적 실수 목록

> 검수·사용자 피드백에서 실수가 나오면 **한 줄 추가**한다. 모든 작업은 시작 전에 이 목록을 읽는다.
> 형식: `- [날짜] 무슨 실수 → 앞으로의 규칙`

- [기본] 대본에 없는 숫자를 그래픽에 지어 넣음 → 화면 숫자는 전부 대본·자료에서만. 렌더 후 check_numbers.py로 대조
- [기본] 0부터 올라가는 카운트업 중간에 "0원" 같은 가짜값이 오래 보임 → 카운트업은 0.6초 이내, 시작값을 최종값의 60% 이상으로
- [기본] 다시 생성할수록 컷이 점점 빨라짐 → VIDEO_SPEC의 shot_sec_mean ±30%를 매번 숫자로 확인
- [기본] 마지막 프레임이 검은 화면으로 끝남 → 마지막 장면은 끝까지 유지, 렌더 길이 = 컴포지션 길이 확인
- [기본] 한글 자막이 네모(□)로 나옴 → 렌더 전에 한글 폰트(Pretendard/Noto Sans KR) 로드 확인
- [기본] 사람·캐릭터가 걷는 동작을 코드로 만들려다 어색해짐 → 사람 동작은 실사/생성 영상 재료를 쓰고 편집만
