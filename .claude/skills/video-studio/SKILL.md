# video-studio — 클로드 영상 자동화 총괄 시스템

핵심 한 줄: **클로드는 영상을 "보는" 게 아니라 "읽는다".** 그래서 영상을 언어(코드·JSON)로 바꿔 줄수록 결과가 정확해진다.

## Trigger

- "영상 자동화 시스템", "영상 만들어줘", "모션그래픽 만들어줘"
- "리모션 / 하이퍼프레임 / 오픈몬테이지 설치해 줘", "PDF 보고 다 세팅해 줘"
- "이 레퍼런스처럼", "이 사이트에서 골라서 만들어 줘"
- "중간 인트로", "구독·좋아요 아웃트로", "시안 4개"
- "자기 전에 걸어 둘게", "밤새 렌더", "다 되면 업로드해 줘"

## 다른 스킬과 역할 나누기

| 상황 | 쓰는 스킬 |
|---|---|
| 촬영 원본(말하는 영상)을 숏폼으로 자르고 자막·효과 | `shortform-auto-edit` |
| 대본·목소리·음악으로 톤 맞춘 모션그래픽 + 2겹 검수 | `motion-graphics` |
| **위 둘을 포함한 전체 흐름 총괄, 설치, 레퍼런스 해부, 시안 병렬, 야간 작업, 업로드** | **이 스킬 (`video-studio`)** |

이 스킬은 필요하면 위 두 스킬을 불러서 쓴다. 검수 스크립트는 `motion-graphics/scripts/`를 그대로 재사용한다.

## 전체 흐름 (7단계)

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| 0 | 도구 점검·설치 (처음 1번) | `doctor.sh` 결과 전부 ✅ |
| 1 | 상황 판별: 내 영상 포맷 있음 / 없음 | 레퍼런스 확보 |
| 2 | **레퍼런스 → 언어로 해부** | `VIDEO_SPEC.json` |
| 3 | 도구 고르기 (리모션 / 하이퍼프레임 / 오픈몬테이지) | 작업 계획표 |
| 4 | 시안 3~4개 병렬 제작 | `work/<이름>/v1~v4/` |
| 5 | 렌더 + 2겹 검수 | `final.mp4` + 검수표 |
| 6 | 업로드 (사용자 확인 후에만) | 업로드 링크 |
| ★ | 야간 모드: 0~5단계를 대기열로 자는 동안 실행 | `night/report.md` |

## 0단계 — 도구 점검·설치 (처음 1번)

```bash
bash .claude/skills/video-studio/scripts/doctor.sh          # 뭐가 있고 뭐가 없는지 표로
bash .claude/skills/video-studio/scripts/setup.sh           # 없는 것만 한 번에 설치
```

| 도구 | 역할 (쉬운 말) | 설치 |
|---|---|---|
| Node.js 22+ | 리모션·하이퍼프레임이 돌아가는 엔진 | nodejs.org |
| FFmpeg | 영상 자르기·붙이기·변환 만능 칼 | ffmpeg.org |
| Python 3.10+ | 오픈몬테이지·분석 스크립트용 | python.org |
| **Remotion 스킬** | 영상을 **코드로** 만드는 도구. 글자·움직임·타이밍이 전부 코드라 클로드가 정확히 읽고 고침 | `npx skills add remotion-dev/skills` |
| **HyperFrames 스킬** | 웹페이지(HTML/CSS)를 그대로 영상으로. **촬영본 위에** 자막·숫자 강조·도식 얹기 | `npx skills add heygen-com/hyperframes --full-depth --yes` |
| **OpenMontage** | 주제만 주면 조사→대본→나레이션→음악→자막→렌더→품질검사까지 하는 **영상 공장** (파이프라인 12종) | `git clone https://github.com/calesthio/OpenMontage.git && cd OpenMontage && make setup` |

- 외부 프로그램 설치라 **권한 요청이 한 번 뜬다 → "허용"** 누르면 된다.
- 명령은 버전에 따라 바뀔 수 있다. 실패하면 기억에 의존하지 말고 각 공식 저장소 README를 읽고 다시 시도한다.
- 자세한 안내·윈도우 명령: `references/install-guide.md`

**토큰 아끼는 팁**: 설치 안내 PDF를 채팅에 첨부하지 말고 작업 폴더에 넣어 두고 "이 폴더 PDF 확인해서 다 세팅해 줘"라고 말한다.

## 1단계 — 상황 판별

사용자에게 묻지 말고 폴더를 먼저 본다.

| 상황 | 판단 기준 | 할 일 |
|---|---|---|
| A. 내 영상 포맷이 있음 | `refs/`에 내 채널·회사 완성본이 있음 | 내 영상을 2단계로 해부 → 내 스타일 그대로 복제 |
| B. 없음 | `refs/` 비어 있음 | 레퍼런스를 찾는다 (아래) |

**B일 때 레퍼런스 찾는 법** (`references/reference-sources.md`):
1. 모션그래픽 모음 사이트 링크를 받는다 → 클로드가 사이트 안 예시를 훑고 **의도에 가장 맞는 후보 3~4개**를 고른다.
2. 마음에 드는 유튜브·숏폼을 화면 녹화해 `refs/`에 넣는다.
3. 둘 다 없으면 톤카드(`motion-graphics/references/tone-cards.md`)에서 코드 하나를 고르게 한다.

## 2단계 — 레퍼런스를 언어로 해부 (이 시스템의 심장)

"이건 이렇게, 저건 저렇게" 말로 시키는 것보다 **예시를 숫자·코드로 바꿔 주는 게** 토큰도 덜 들고 결과도 정확하다.

```bash
python3 -I .claude/skills/video-studio/scripts/decode_reference.py refs/ref1.mp4 work/refs/ref1
```

스크립트가 기계로 뽑는 것 (객관 숫자):
- 장면 컷 시점·장면별 길이, 평균 컷 길이
- 장면별 대표 색 5개 (HEX), 밝기, 움직임 양
- 음량(LUFS), 화면 비율·fps·길이
- 장면별 대표 캡처 + 전체 모아보기 1장 (`sheet.jpg`)

그다음 **클로드가 캡처를 직접 보고** 숫자로 안 잡히는 것을 채운다 (주관 요소):
- 자막: 폰트 느낌·크기(화면 높이 대비 %)·위치·색·외곽선·한 줄 글자 수·등장 방식
- 그래픽 종류: 로고 팝업 / 막대 그래프 / 흐름도 / 키워드 칩 / 하단 카드 / 숫자 카운트업
- 움직임 말투: 팝(튀어나옴)·슬라이드·페이드·타이핑·마스크, 속도감(easing)
- 전환: 바로 컷 / 이어지기(요소가 다음 장면으로 넘어감)
- 소리: 효과음 위치(팝·휙·딸깍), 배경음악 분위기

결과는 `references/video-spec-schema.md` 형식의 **`VIDEO_SPEC.json`**. 이후 모든 제작은 이 파일만 보고 한다.
레이어를 **빠짐없이** 적을수록 결과에 반영된다 — 빠진 요소는 클로드도 빠뜨린다.

## 3단계 — 도구 고르기

`references/tool-routing.md` 기준. 요약:

| 만들 것 | 1순위 도구 |
|---|---|
| 처음부터 만드는 모션그래픽 (인트로·아웃트로·설명 애니메이션·자막 단어 하나하나 움직임) | **Remotion** |
| 내가 찍은 영상 **위에** 자막·숫자 강조·도식·칩 얹기, 10초 안팎 도식 | **HyperFrames** |
| 주제만 주고 대본·나레이션·배경음악·스톡 영상까지 통째로 | **OpenMontage** |
| 촬영 원본 컷 편집(무음·재촬영 제거) | `shortform-auto-edit` → 그 위에 HyperFrames |

여러 개를 이어 쓰는 기본 조합: **Remotion으로 뼈대 → HyperFrames로 촬영본 위 그래픽 → OpenMontage로 음악·스톡·나레이션.**

### 할 수 있는 것 / 못 하는 것 (기대치 맞추기)
| 잘함 | 어려움 |
|---|---|
| 글자·숫자·그래프·도형 움직임, 자막, 컷 편집, 레이아웃, 효과음 타이밍 | 사람·캐릭터가 걷고 뛰는 자연스러운 동작, 드라마·애니메이션 연기 |

→ "창작"이 아니라 **"편집"의 관점**으로 쓴다. 사람이 움직이는 장면이 꼭 필요하면 실사 촬영본이나 영상 생성 AI 결과물을 재료로 가져와 그 위에 편집한다.

## 4단계 — 시안 3~4개 병렬 제작

프롬프트 하나를 고쳐 가며 한 개씩 다시 뽑지 말고, **처음부터 옆으로 여러 개** 만든다.

1. `VIDEO_SPEC.json`을 기준으로 방향이 확실히 다른 시안 3~4개를 정한다 (예: 미니멀 / 대담한 타이포 / 그래프 중심 / 키네틱 자막).
2. 시안마다 **서브에이전트(Agent 도구)를 동시에** 띄워 각자 `work/<이름>/v1/` … `v4/`에 만든다. 서로 같은 파일을 건드리지 않는다.
3. 각 시안 미리보기(모아보기 1장 + 5초 GIF 또는 저화질 mp4)를 표로 보여 주고 고르게 한다.
4. 고른 시안만 고화질로 최종 렌더.

각 서브에이전트에게 주는 지시는 `templates/variant-brief.md` 양식으로 만든다 (목적 1 + 필수 5 + 나머지 자유).

## 5단계 — 렌더 + 2겹 검수

- 렌더 기본값: 세로 숏폼 1080×1920 / 가로 1920×1080, 30fps, H.264 + AAC.
- 검수는 **만든 에이전트가 아닌** 별도 서브에이전트 + 스크립트가 한다:
  ```bash
  bash .claude/skills/motion-graphics/scripts/contact_sheet.sh out/final.mp4 out/qa/sheet.png
  bash .claude/skills/motion-graphics/scripts/measure_video.sh out/final.mp4
  python3 .claude/skills/video-studio/scripts/compare_to_spec.py work/refs/ref1/VIDEO_SPEC.json out/final.mp4
  ```
- `compare_to_spec.py`는 완성본을 다시 해부해 **레퍼런스와 숫자로 비교**한다 (컷 길이·밝기·움직임·음량). 차이가 ±30% 넘는 항목은 고친다.
- 체크리스트: `motion-graphics/references/qa-checklist.md` + 아래 추가 항목
  | # | 항목 |
  |---|---|
  | S1 | VIDEO_SPEC.json의 레이어가 전부 들어갔나 (빠진 레이어 목록 작성) |
  | S2 | 대본에 없는 숫자·문구를 지어내지 않았나 |
  | S3 | 마지막 프레임이 잘리거나 검은 화면으로 끝나지 않나 |
  | S4 | 휴대폰 크기에서 자막이 읽히나 |
- 실수가 나오면 `references/mistake-log.md`에 한 줄 추가 (다음 작업부터 자동 반영).

완성본은 캡컷 등으로 불러와 사람이 마지막 디테일만 손봐도 된다.

## 6단계 — 업로드 (반드시 사용자 확인 후)

- 업로드는 **공개 행동**이다. 제목·설명·태그·공개 범위·채널을 표로 보여 주고 **"올려"라는 확인을 받은 뒤에만** 올린다.
- 연결된 업로드 도구(예: 소셜 게시 커넥터)가 있으면 그걸 쓰고, 없으면 업로드용 파일·제목·설명을 `out/upload/`에 정리해 두고 직접 올리는 방법을 번호로 안내한다.
- 야간 모드에서는 **기본값이 "비공개/예약 업로드 준비까지만"**. 사용자가 작업 파일에 `upload: public`을 명시했을 때만 공개 업로드한다.

## ★ 야간 모드 — 자기 전에 걸어 두고 아침에 확인

자기 전에 작업 파일만 써 두면, 클로드가 하나씩 꺼내서 끝까지 만든다.

1. `templates/night-job.md`를 복사해 `night/jobs/01-intro.md`처럼 작업마다 1개씩 만든다 (말로 시켜도 클로드가 대신 써 준다).
2. 실행:
   ```bash
   bash .claude/skills/video-studio/scripts/night_queue.sh night/jobs
   ```
   - 작업 파일을 순서대로 `claude -p`(사람 없이 혼자 도는 모드)로 실행한다.
   - 하나가 실패해도 다음 작업으로 넘어간다. 로그는 `night/logs/`.
3. 아침에 `night/report.md` 한 장만 보면 된다 (작업별 성공/실패, 결과 파일 경로, 검수 결과, 사람이 볼 것).

자세한 설정(컴퓨터 절전 끄기, 권한 미리 허용, 예약 실행): `references/night-mode.md`
