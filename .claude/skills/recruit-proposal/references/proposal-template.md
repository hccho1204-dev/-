## 본문 페이지 디자인 (2~3페이지)

### 헤더 (모든 본문 페이지)

```
┌──────────────────────────────────────┐
│ [오렌지 바] 높이 5mm                  │  ← #FF6B35
│                                      │
│  블레스본부 합류 제안서       p.N    │  ← #2D3748, 8pt

```

### 섹션 타이틀 스타일

오렌지 좌측 바 + 오렌지 언더라인으로 구분.

```
┌──────────────────────────────────────┐
│                                      │
│  █ 섹션 제목                         │  ← 좌측 오렌지 바(3mm) #FF6B35
│                                      │     14pt Bold, #2D3748
│  ─────────────────────────────────── │  ← 오렌지 언더라인 #FF6B35
│                                      │
└──────────────────────────────────────┘
```

### 수입 모델 표

깔끔한 표 형식. 강조 수치는 큰 폰트 + 오렌지.

```
┌──────────┬──────────────┬──────────────────────────┐
│   단계    │    기간      │     주요 수입원           │  ← 헤더: 배경 #FF6B35, 텍스트 #FFFFFF
├──────────┼──────────────┼──────────────────────────┤
│  🚀 초기  │  1~3개월     │  정착 지원 + 활동비      │  ← 홀수행: #FFFFFF
├──────────┼──────────────┼──────────────────────────┤
│  📈 성장기│  4~12개월    │  DB 활용 본격 영업       │  ← 짝수행: #F7FAFC
├──────────┼──────────────┼──────────────────────────┤
│  🏆 안정기│  1년~        │  리뉴얼 수입 + 신규 영업  │  ← 홀수행: #FFFFFF
└──────────┴──────────────┴──────────────────────────┘

⚠️ 상기 수입은 예시이며, 개인 역량과 노력에 따라 다를 수 있습니다.
                                          ← 8pt, #718096
```

표 규칙:
- 헤더: 배경 `#FF6B35`, 텍스트 `#FFFFFF`, Bold
- 짝수행: 배경 `#F7FAFC`
- 구분선: `#E2E8F0`, 0.5pt
- 강조 수치(금액 등): `#FF6B35`, 14pt Bold
- 면책 문구: 표 바로 아래, 8pt `#718096`
