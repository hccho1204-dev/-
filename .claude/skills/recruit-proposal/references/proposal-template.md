### 섹션 타이틀 스타일

```
┌──────────────────────────────────────┐
│                                      │
│  █ 섹션 제목                         │  ← 좌측 오렌지 바(3mm) + 제목
│                                      │     16pt Bold, #2C3E50
│  ─────────────────────────────────── │  ← 오렌지 언더라인
│                                      │
└──────────────────────────────────────┘
```

### 차별점 카드 스타일

5대 차별점은 카드형 레이아웃으로 표현:

```
┌─────────────────────────────┐
│ ① 매일 DB 제공              │  ← 오렌지 넘버링
│                             │
│ 메디컬DB, 리워드DB,         │  ← 본문 10pt
│ 보장분석DB 등 5종의         │
│ DB를 매일 제공합니다.       │
└─────────────────────────────┘
```

### 수입 모델 타임라인

```
  ●─────────────●─────────────●
  │ 초기         │ 성장기       │ 안정기
  │ 1~3개월      │ 4~12개월     │ 1년~
  │              │              │
  │ 정착 지원    │ DB 활용      │ 리뉴얼 수입
  │ + 활동비     │ 본격 영업    │ + 신규 영업
```

타임라인 색상:
- 원형 포인트: `#FF6B35`
- 연결선: `#DEE2E6`
- 텍스트: `#2C3E50`
