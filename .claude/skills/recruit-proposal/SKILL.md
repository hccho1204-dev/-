# recruit-proposal

블레스본부 설계사 모집 제안서 및 입사 안내서를 자동 생성하는 스킬.

## Trigger

다음 키워드가 포함된 요청에 트리거:
- "모집 제안서"
- "합류 제안서"
- "스카우트 제안서"
- "이직 제안"
- "입사 안내서"
- "채용 제안서"

## 프로세스 (5단계)

### 1단계: 대상자 정보 확인

사용자에게 다음 정보를 순서대로 확인한다:

| 항목 | 필수 여부 | 예시 |
|------|-----------|------|
| 대상자명 | 필수 | 김영희 |
| 대상자 유형 | 필수 | 손보 경력직 / 생보 경력직 / 경력단절 여성 / 간호사 / 요양보호사 |
| 현재 직업/경력 | 선택 | 간호사 5년차 / 손보 GA 3년 |
| 관심사/고민 | 선택 | 수입, 근무시간, 안정성 |
| 우대 자격 | 선택 | 세무사, 변호사, 노무사 등 |

### 2단계: 유형별 콘텐츠 자동 선택

대상자 유형에 따라 강조 포인트와 어조가 자동으로 결정된다.

#### 손보 경력직

| 항목 | 내용 |
|------|------|
| 핵심 메시지 | "더 높은 수수료, 더 많은 DB로 실적을 극대화하세요" |
| 강조 포인트 | 업계 최고 수준 수수료율, 매일 DB 지원, 자율 근무 |
| 어조 | 프로페셔널, 실적 중심 |

#### 생보 경력직

| 항목 | 내용 |
|------|------|
| 핵심 메시지 | "손보를 더해 수입을 다각화하세요" |
| 강조 포인트 | 손보 추가 수입, 크로스셀링 시너지, 기존 고객 활용 |
| 어조 | 성장 파트너십 |

#### 경력단절 여성

| 항목 | 내용 |
|------|------|
| 핵심 메시지 | "경력 단절이 아닌, 새로운 커리어의 시작" |
| 강조 포인트 | 유연한 근무시간, 1:1 밀착 교육, 정착 지원금, 육아 병행 |
| 어조 | 따뜻하고 공감적, 응원 |

#### 간호사 / 간호조무사

| 항목 | 내용 |
|------|------|
| 핵심 메시지 | "의료 지식이 최강의 영업 무기가 됩니다" |
| 강조 포인트 | 메디컬DB 활용, 의료 전문성 → 고객 신뢰, 건강·보험 컨설팅 |
| 어조 | 전문성 인정, 가능성 제시 |

#### 요양보호사

| 항목 | 내용 |
|------|------|
| 핵심 메시지 | "대면 소통 능력이 가장 큰 자산입니다" |
| 강조 포인트 | 시니어 고객층 접근성, 대면 커뮤니케이션 강점, 부업 가능 |
| 어조 | 격려, 현실적 가능성 |

### 3단계: 제안서 구성

```
1. 표지
   - "함께 성장할 파트너를 찾습니다"
   - 대상자명, 작성일자
   - 블레스본부 브랜딩

2. 맞춤 도입 메시지
   - 대상자 유형에 맞는 공감 인사
   - "왜 이 제안서를 보내게 되었는지" 설명
   - 1~2단락

3. 블레스본부 소개
   - 인카금융서비스 소속
   - "보험설계사 현실 연구소 - BLESS INSIGHT"
   - 모토: "우리가 가면, 길이 됩니다"
   - 2026 테마: "Always like the first time! I CAN DO IT"

4. 5대 차별점
   ① 매일 DB 제공 (메디컬DB, 리워드DB, 보장분석DB, 피싱·해킹보험DB, 법인DB)
   ② 투명한 수수료 구조
   ③ 1:1 전담 멘토링
   ④ AI 자동화 업무 도구
   ⑤ [대상자 유형별 추가 차별점]

5. 수입 모델
   - 초기 (1~3개월): 정착 지원 + 활동비
   - 성장기 (4~12개월): DB 활용 본격 영업
   - 안정기 (1년~): 리뉴얼 수입 + 신규 영업

   ⚠️ 면책: "상기 수입은 예시이며, 개인 역량과 활동량에 따라 차이가 있습니다"

6. 블레스본부에서 성공하는 3가지 이유
   - [대상자 유형에 맞는 성공 포인트 3가지]

7. 합류 프로세스 (5단계)
   ① 상담 신청 (카카오 오픈채팅 / 전화)
   ② 1:1 상세 상담
   ③ 본부 방문 및 시스템 체험
   ④ 합류 결정 및 등록
   ⑤ 온보딩 교육 시작

8. CTA
   - "지금 바로 상담을 시작하세요"
   - 카카오 오픈채팅 링크
   - bless-insight-recruit.netlify.app
```

### 4단계: PDF 생성

`references/proposal-template.md`의 디자인 가이드에 따라 PDF를 생성한다.

### 5단계: 검증

체크리스트의 모든 항목을 확인한다.

## 우대 뱃지

대상자가 아래 자격을 보유한 경우, 제안서 표지 또는 소개 섹션에 **우대 뱃지**를 표시한다:

| 뱃지 | 대상 |
|------|------|
| 🏅 손보 경력 우대 | 손해보험 영업 경력자 |
| 🏅 세무사 우대 | 세무사 자격 보유자 |
| 🏅 변호사 우대 | 변호사 자격 보유자 |
| 🏅 노무사 우대 | 노무사 자격 보유자 |

## 출력 형식

- **형식**: PDF 파일
- **파일명**: `제안서_대상자명_YYMMDD.pdf` (예: `제안서_김영희_260315.pdf`)
- **디자인**: 블레스 오렌지(#FF6B35) 메인 컬러

## 필수 규칙

### 면책 문구
- 수입 모델 섹션에 반드시 "예시이며, 개인 역량과 활동량에 따라 차이가 있습니다" 포함
- 확정적 수입 보장 표현 절대 금지

### 금지 사항
- 경쟁사 비방 금지
- 현 직장 이탈 종용 금지 ("지금 당장 그만두세요" 등)
- 비현실적 수입 약속 금지
- `brand-voice.md`의 금지 표현 목록 준수

### CTA
제안서 마지막에 반드시 포함:

```
지금 바로 상담을 시작하세요.

📌 카카오 오픈채팅 상담
📌 블레스본부 채용 안내: bless-insight-recruit.netlify.app
```

## 검증 체크리스트

- [ ] 대상자 유형에 맞는 콘텐츠가 선택되었는가
- [ ] 5대 차별점이 모두 포함되었는가
- [ ] 수입 모델에 면책 문구가 포함되었는가
- [ ] 합류 프로세스 5단계가 포함되었는가
- [ ] CTA(카카오 오픈채팅 + 채용 페이지)가 포함되었는가
- [ ] 경쟁사 비방 표현이 없는가
- [ ] 비현실적 수입 약속 표현이 없는가
- [ ] 블레스 오렌지(#FF6B35) 메인 컬러가 적용되었는가
- [ ] 우대 뱃지가 해당 시 표시되었는가
