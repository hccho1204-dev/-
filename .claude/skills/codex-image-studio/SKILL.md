# codex-image-studio

> 클로드 = 본체(맥락·기억·정리·HTML 결과물) / 코덱스 CLI = 카트리지(그림 그리는 손)
> "이 도면을 3개의 다른 컨셉으로 만들어줘" 한 줄이면, 모델이 알아서 컨셉을 나누고 그린다.

---

## 1. 왜 GPT(코덱스)로 그리나

| 도구 | 이미지 생성 | 특징 |
|---|---|---|
| GPT / 코덱스 | ✅ 최상위 | 도면 → 층 분리 → 공정 순서까지 "도해"로 그려줌. 이미지 평가 순위 1위권 |
| 제미나이 (나노바나나 프로) | ✅ | 곧잘 그림 |
| 코파일럿·메타 뮤즈·그록 | ✅ | 가능 |
| 미드저니·젠스파크·힉스필드 | ✅ | 이미지 전문 서비스 |
| 클로드 | ❌ (그림 X) | 인터랙티브 도형·HTML·아티팩트는 강함 → **결과물을 모아 정리하는 역할** |

**결론:** 그림은 GPT, 맥락·정리·발표자료 껍데기는 클로드. 이미 GPT 구독 중이면 추가 비용 없이 활용.

---

## 2. 이미지 만드는 3가지 방법

| 방법 | 어떻게 | 장점 | 단점 | 추천 상황 |
|---|---|---|---|---|
| ① GPT 데스크탑 앱 | 자료 올리고 "이 도면을 이미지 3장으로, 발표자료용" | 제일 쉬움 | 1장 세트에 약 5~10분. 수정할 때마다 또 5~10분 | 1~2장만 필요할 때 |
| ② 터미널 배치 | 터미널(CLI)에서 코덱스 여러 개를 동시에 돌림 | 수십~수백 장 동시 생성 | 생성량만큼 사용량 소모 | 썸네일·에셋 후보를 많이 뽑을 때 |
| ③ **클로드 + 코덱스 CLI (추천)** | 클로드 코드 안에 코덱스를 MCP로 연결 | 내 에이전트의 맥락·메모리 그대로 + 병렬 생성 + 결과를 HTML로 정리 | 최초 1회 설치 필요 | 본부 자료·보고서·교육자료 상시 제작 |

> **터미널(CLI)** = 마우스 대신 글자로 컴퓨터에 명령하는 까만 창. 클로드 코드는 여기서 돌아간다.
> **MCP** = 클로드에 다른 프로그램을 "카트리지처럼 꽂는" 연결 규격.

### 순차 vs 병렬

```
순차(코덱스 1개):  [그림1] → 맘에 안 듦 → [다시] → [다시]   = 시간 × 반복 횟수
병렬(코덱스 N개):  [그림1][그림2][그림3][그림4] 동시에        = 1장 시간으로 N장
```

수정 지시를 반복하는 것보다 **처음부터 여러 장 뽑고 고르는 것**이 빠르다.

## 3. 최초 세팅 (1회만)

### 3-1. 클로드 코드(터미널 버전) 설치

| 내 컴퓨터 | 터미널 열기 | 설치 명령어 |
|---|---|---|
| 맥 | `Cmd + Space` → "터미널" | `curl -fsSL https://claude.ai/install.sh \| bash` |
| 윈도우 | 먼저 **Git for Windows** 설치 (https://git-scm.com/downloads/win) → PowerShell 실행 | `irm https://claude.ai/install.ps1 \| iex` |

설치 후 터미널에 `claude` 입력 → 클로드 로고가 뜨면 성공.
(명령어가 바뀌었을 수 있으니, 막히면 클로드에게 "내 컴퓨터(맥/윈도우)에 클로드 코드 터미널 버전 설치 방법 알려줘"라고 물어보면 된다.)

> 윈도우에서 Git이 필요한 이유: 맥에는 기본으로 깔려 있지만 윈도우는 따로 설치해야 클로드 코드가 정상 동작한다.

### 3-2. 코덱스 CLI 설치 + 로그인

```bash
npm install -g @openai/codex
codex login
```

- `codex login` → 브라우저가 열리면 **ChatGPT 구독 계정**으로 로그인 (API 키 아님 → 구독 안에서 사용)
- `npm`이 없다고 나오면 Node.js(https://nodejs.org)부터 설치

### 3-3. 클로드에 코덱스 꽂기 (카트리지 연결)

가장 쉬운 방법 — 클로드 안에서 이렇게 말한다:

```
코덱스 CLI 연결해줘
```

직접 하려면 터미널에서:

```bash
claude mcp add codex -- codex mcp-server
claude mcp list          # codex 가 ✓ Connected 이면 완료
```

"클로드 코드에 코덱스 CLI를 연결했습니다" 메시지가 뜨면 끝.

## 4. 실행 워크플로우 (클로드가 따라야 할 순서)

### STEP 1. 원본 받기
- 입력: 링크(구글 특허 등), 이미지, PDF, 기존 HTML 장표, 글 설명 아무거나
- 원본이 웹 링크면 클로드가 먼저 도면/이미지를 내려받아 `outputs/<프로젝트명>/source/` 에 저장
- 도면에 번호(예: 101, 102…)가 붙어 있으면 **번호별 구성요소 목록**을 먼저 뽑아 둔다 (색 지정·라벨에 사용)

### STEP 2. 컨셉 3개 결정
사용자가 컨셉을 지정하지 않으면 기본값 3종으로 자동 분기:

| 컨셉 | 느낌 | 쓰기 좋은 곳 |
|---|---|---|
| A. 클레이 3D | 말랑한 점토 미니어처, 파스텔 | 교육자료·신입 온보딩·카드뉴스 |
| B. 글래스 다크 | 어두운 배경 + 반투명 유리 + 네온 엣지 | 임원 보고·VIP 제안서·표지 |
| C. 아이소메트릭 분해도 | 45° 입체, 층을 위로 띄워 분리 + 조립 순서 화살표 | 구조·공정·프로세스 설명 |

(필요하면 추가: 보고서용 문법(모노톤 다이어그램), 블루프린트, 미니멀 라인아트)

### STEP 3. 프롬프트 생성
`references/prompt-templates.md` 의 템플릿에 STEP 1의 구성요소·번호·색을 채워 넣는다.
**사용자에게 긴 프롬프트를 쓰게 하지 않는다.** 사용자는 한 줄만 말하고, 긴 프롬프트는 클로드가 만든다.

### STEP 4. 병렬 생성
- 컨셉마다 서브 에이전트 1개씩 띄워 **동시에** 코덱스(MCP)에 생성 요청
- 기본: 컨셉 3개 × 1장. "여러 개", "후보", "썸네일"이면 컨셉당 4~10장
- 저장 규칙: `outputs/<프로젝트명>/<컨셉>/<번호>.png`

### STEP 5. 클로드가 정리
- 생성된 이미지를 한 장의 HTML 갤러리(또는 장표)로 묶어 보여준다
  - 원본(Before) ↔ 결과(After) 나란히
  - 컨셉별 탭, 구성요소 번호 범례(색상표)
- 껍데기(HTML)는 클로드, 안의 그림은 코덱스
- 발표자료로 이어갈 땐 `bless-html-slides` 흐름으로 넘긴다

### STEP 6. 고르기 & 수정
- "B-2로 가자, 윗부분만 주황색" 처럼 **고른 것만** 다시 생성 (전체 재생성 X)
- 마음에 든 결과는 **역프롬프트**로 저장 → 다음에 같은 톤으로 재사용

```
방금 B-2 이미지를 똑같이 다시 만들려면 어떤 프롬프트를 넣어야 해? 그대로 복사해서 쓸 수 있게 줘
```

→ `references/prompt-library.md` 에 이름 붙여 누적.

## 5. 활용 시나리오 (블레스본부)

| 자료 | 원본 | 추천 컨셉 | 한 줄 요청 예시 |
|---|---|---|---|
| 본부 조회 장표 | 밋밋한 HTML 슬라이드 | 글래스 다크 | "이 장표 3페이지 그림을 3D 컨셉 3개로" |
| 보장분석 리포트 | 담보 구조 표 | 아이소메트릭 분해도 | "실손·진단비·수술비를 층으로 쌓은 구조도로" |
| 리크루팅 제안서 | 수수료·성장 단계 표 | 클레이 3D | "신입 1년 성장 단계를 계단형 3D로" |
| 카드뉴스·블로그 썸네일 | 제목 텍스트 | 3종 × 10장 배치 | "썸네일 에셋 30장 뽑아줘, 사람·소품 분리해서" |
| 상품 구조 설명 | 약관 도해 | 아이소메트릭 | "단기납 종신 납입→해지환급 흐름을 공정도처럼" |
| 브랜드 에셋 | 로고·컬러 | 전부 | "블레스 브랜드에 필요한 에셋 전부 만들어줘" |

**썸네일 방식:** 요소(사람·아이콘·배경·소품)를 따로따로 여러 개 만들어 두고 → 마음에 드는 것끼리 조합. 내가 원하는 모양을 나도 모를 때 특히 유용.

## 6. 비용 감각

| 항목 | 참고값 |
|---|---|
| 도면 1건 → 3컨셉 전체 작업 | 약 330k 토큰 ≈ API 환산 8달러 |
| 구독 요금제(클로드 + ChatGPT) 사용 시 | 추가 비용 없음 (사용량 한도 안에서) |
| 데스크탑 앱 1세트 | 약 5~10분 (예: 8분 45초) |
| 무료 GPT | 하루 몇 장 무료 → 먼저 써보고 점차 유료로 |

> 많이 생성할수록 사용량이 든다. 터미널이라 비싼 게 아니라 **장수만큼** 든다. 필요한 장수가 분명할 때 배치로.

## 7. 지켜야 할 것

1. **고객 개인정보(이름·주민번호·병력·증권번호)는 절대 이미지 프롬프트에 넣지 않는다.** 가명·예시 수치로 대체
2. 보험 상품 이미지에 들어가는 **숫자(보험료·환급률·보장금액)는 이미지가 아니라 HTML 텍스트로** 얹는다 → 수정·심의 대응 쉬움, AI가 숫자를 틀리게 그리는 문제 방지
3. 이미지 속 글자는 틀리기 쉽다 → 라벨은 최소화하고, 설명 글자는 클로드가 HTML로 덧입힌다
4. 광고·모집 자료에 쓰면 회사 광고심의 기준(과장·단정 표현 금지)을 그대로 적용 (`../tistory-aeo-post/references/brand-voice.md`)
5. 특허 도면 등 외부 자료는 출처를 장표 하단에 표기
6. 생성 결과는 매번 달라진다(LLM 특성) → 마음에 들면 바로 저장 + 역프롬프트 보관

## 8. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `claude` 입력해도 반응 없음 | 터미널 껐다 켜기 → 그래도 안 되면 설치 명령 다시 실행 |
| 윈도우에서 설치 실패 | Git for Windows 먼저 설치했는지 확인 |
| `npm: command not found` | Node.js 설치 후 터미널 재시작 |
| `claude mcp list` 에 codex 안 보임 | `claude mcp add codex -- codex mcp-server` 다시 실행 |
| codex 연결은 됐는데 이미지가 안 나옴 | `codex login` 다시 → ChatGPT 구독 계정인지 확인, `npm install -g @openai/codex@latest` 로 업데이트 |
| 결과가 너무 평범함 | 컨셉 이름을 명시 + `references/prompt-templates.md` 의 "금지 요소" 줄 포함 |
