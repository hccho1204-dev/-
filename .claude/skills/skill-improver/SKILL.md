# 스킬 개선기 (skill-improver)

스킬은 시간이 지나면 낡는다. (회사 양식 변경, 말투 변경, 같은 실수 반복)
이 스킬은 **실제로 쓴 기록**을 근거로 스킬을 고친다.

## 순서

1. **대상 스킬 확인**
   - 사용자가 이름을 말했으면 그 스킬. 아니면 이번 대화에서 발동된 스킬.
   - `.claude/skills/<이름>/SKILL.md` 와 같은 폴더의 참고 파일을 모두 읽는다.

2. **증거 모으기** — 이번 대화에서 아래를 찾는다.
   | 신호 | 예 |
   |---|---|
   | 사용자가 결과물을 고친 부분 | "제목 더 짧게", "로고 위치 바꿔" |
   | 같은 지적이 2번 이상 | 반복 실수 → 규칙으로 승격 |
   | 새 자료 제공 | 새 양식 파일, 새 가격표 |
   | 스킬 지시가 애매해서 되물은 부분 | 지시문 보강 필요 |

3. **개선안 표로 보여주기** (바로 고치지 않는다)
   | # | 문제 | 고칠 위치 | 수정 전 | 수정 후 |
   |---|---|---|---|---|

4. 사용자가 "적용"이라고 하면 파일을 고친다.
   - 규칙은 SKILL.md에, 긴 예시·양식·디자인 가이드는 별도 참고 파일(`style.md`, `template.html` 등)에 둔다.
   - SKILL.md 맨 아래 `## 변경 기록`에 `YYYY-MM-DD: 한 줄 요약`을 추가한다.

5. `ai-system/wiki/스킬-루틴.md` 표의 설명이 바뀌었으면 함께 고친다.

## 개별 스킬에 "자가 업데이트" 기능 넣기
다른 스킬 SKILL.md 끝에 아래 블록을 붙이면, 그 스킬이 스스로 업데이트를 제안한다.

```
## 자가 업데이트
- 작업이 끝나면 사용자가 고친 부분이 있었는지 확인한다.
- 있었다면 "이 수정을 스킬에 반영할까요?"라고 한 줄로 묻는다.
- "응"이라고 하면 이 SKILL.md(또는 참고 파일)에 규칙으로 추가하고 변경 기록을 남긴다.
```
