# notion-builder — 말로 하는 노션 페이지 제작

## 실행 순서

1. **요구사항 정리**: 목적, 기간(예: 오늘~올해 말), 체크할 항목, 보고 싶은 화면(표/달력/보드)을 한 줄씩 정리.
2. **구조 선택**:
   | 목적 | 만들 것 |
   |---|---|
   | 매일 체크 (습관) | 데이터베이스: 날짜 1행 = 하루, 항목마다 체크박스 열 + 달성률 수식 |
   | 할 일 관리 | 데이터베이스: 상태(시작 전/진행/완료) 보드 보기 |
   | 고객·DB 관리 | 데이터베이스: 이름·연락처·단계·다음 연락일 |
   | 일정·콘텐츠 | 데이터베이스 + 달력 보기 |
3. **만들기**: 부모 페이지(제목+이모지 아이콘+사용법 3줄) → 그 안에 데이터베이스 → 필요한 보기(표/달력/보드) 추가.
4. **행 미리 채우기**: 날짜형이면 기간 전체 날짜를 행으로 미리 생성 (너무 많으면 이번 달만 만들고 "매달 추가" 방법 안내).
5. **완료 보고**: 노션 링크 + "이렇게 쓰세요" 3단계 사용법.

## 습관 트래커 기본 템플릿

| 열 이름 | 종류 |
|---|---|
| 날짜 | 날짜 (제목 열은 `10/07(화)` 형식) |
| 10분 독서 / 5분 명상 / 30분 운동 … | 체크박스 (사용자 항목대로) |
| 달성률 | 수식: 체크된 개수 ÷ 전체 항목 수 → % |
| 메모 | 텍스트 |

보기: ① 이번 주(필터) ② 달력 ③ 전체 표

## 규칙

- 기존 페이지를 지우거나 덮어쓰지 않는다. 항상 새 페이지로 만든다.
- Notion이 연결 안 되어 있으면: claude.ai 설정 → 커넥터 → Notion 연결 → 공유할 페이지 선택 순서로 안내.

## 프롬프트 예시

```
노션에 매일 해야 하는 습관 관리 페이지를 만들고 싶어.
올해 말까지 매일 아래 세 가지 항목에 대해 내가 하고 나면 체크할 수 있는 페이지를 만들어줘.
10분 독서, 5분 명상, 30분 운동이야.
```
