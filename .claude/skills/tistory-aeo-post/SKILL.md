# tistory-aeo-post

블레스본부 Tistory 블로그 **"보험설계사 현실 연구소 - BLESS INSIGHT"**에 올릴 AEO 최적화 포스트를 자동 생성하는 스킬.

## Trigger

다음 키워드가 포함된 요청에 트리거:
- "블로그 글 써줘"
- "티스토리 포스트"
- "AEO 글"
- "보험 블로그"
- "포스트 작성"

## 타겟 독자

- 손해보험 경력직 설계사
- 경력단절 여성
- 간호사 / 간호조무사
- 요양보호사

## 프로세스 (4단계)

### 1단계: 주제 파악
- 사용자가 제시한 키워드 또는 주제를 분석
- 타겟 독자가 실제로 검색할 **질문형 키워드**를 도출
- 예시: "보험설계사 전업 현실", "간호사 보험영업 전환", "보험설계사 수입 구조"

### 2단계: AEO 구조 작성
- 아래 **본문 구조** 섹션에 따라 전체 포스트 작성
- `references/brand-voice.md`의 톤·금지 표현 규칙을 반드시 준수

### 3단계: 메타데이터 생성
- **title**: 질문형 또는 호기심 유발형 (60자 이내)
- **description**: 핵심 답변 요약 (120자 이내)
- **tags**: 관련 태그 10개 이상
- **카테고리**: 포스트 주제에 맞는 카테고리 제안

### 4단계: 검증 체크리스트
- 아래 **체크리스트** 섹션의 모든 항목 통과 확인

## AEO (Answer Engine Optimization) 핵심 원칙

포스트 최상단에 **"핵심 답변 블록"**을 배치한다. 이 블록은 AI 검색엔진(ChatGPT, Perplexity, Google SGE 등)이 직접 인용하는 구간이다.

핵심 답변 블록 규칙:
- 2~3문장으로 구성
- 질문에 대한 직접적이고 명확한 답변
- 전문성과 신뢰감을 전달
- `> ` 인용 블록 형식으로 표시

## 본문 구조

```
# [질문형 타이틀]

> **[핵심 답변 블록]**
> 2~3문장으로 질문에 대한 직접적인 답변을 제공합니다.

## 소주제 1: [구체적 현실 이야기]
- 타겟 독자의 공감을 이끄는 현실적 내용

## 소주제 2: [실질적 정보 제공]
- 수치, 비교, 구체적 팁 등

## 소주제 3: [실천 가능한 방법]
- 행동으로 옮길 수 있는 구체적 가이드

## 블레스본부는 이렇게 지원합니다
- 매일 DB 제공 시스템 안내
- 기타 차별점 소개

## 자주 묻는 질문 (FAQ)
**Q1. [질문]**
A. [답변]

**Q2. [질문]**
A. [답변]

**Q3. [질문]**
A. [답변]

(3~5개 구성)

## 지금 시작하세요
[CTA 섹션]
```

## 블레스본부 차별점 (본문에 자연스럽게 포함)

- **매일 DB 제공**: 메디컬DB, 리워드DB, 보장분석DB, 피싱·해킹보험DB, 법인DB
- **투명한 수수료**: 숨김 없는 수수료 구조
- **1:1 멘토링**: 전담 멘토의 밀착 지원
- **AI 자동화**: 업무 효율을 높이는 AI 도구 활용

## CTA (Call To Action)

모든 포스트 하단에 포함:

```
---

**보험설계사로의 새로운 시작, 블레스본부와 함께하세요.**

📌 카카오 오픈채팅으로 상담하기
📌 블레스본부 채용 안내: [bless-insight-recruit.netlify.app](https://bless-insight-recruit.netlify.app)
```

## 출력 형식

- **형식**: 마크다운 (.md) 파일
- **파일명**: `YYMMDD-키워드.md` (예: `260315-보험설계사-전업-현실.md`)
- **저장 위치**: 사용자와 협의 (기본: 프로젝트 루트 또는 `posts/` 폴더)

## 검증 체크리스트

포스트 생성 후 아래 항목을 모두 확인:

- [ ] 핵심 답변 블록이 포스트 최상단(타이틀 바로 아래)에 배치되었는가
- [ ] FAQ가 3개 이상 포함되었는가
- [ ] 태그가 10개 이상 생성되었는가
- [ ] 본문 길이가 1,500~3,000자 범위인가
- [ ] `references/brand-voice.md`의 금지 표현이 사용되지 않았는가
- [ ] 수입 관련 내용에 "예시"임이 명시되었는가
- [ ] CTA(카카오 오픈채팅 + 채용 페이지 링크)가 포함되었는가
- [ ] 과장되거나 비현실적인 표현이 없는가
