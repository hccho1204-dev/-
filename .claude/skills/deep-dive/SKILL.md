# deep-dive — 묻고 또 묻기 7단계

사용자가 주제 하나만 주면, 아래 7단계를 **한 번의 답변 안에서 순서대로 전부** 진행한다.
중간에 사용자에게 되묻지 않는다. 정보가 부족하면 합리적으로 가정하고, 그 가정을 맨 위에 한 줄로 밝힌다.

## 입력 해석

- `/deep-dive [주제]` 또는 "○○ 딥다이브 해줘"
- `[직업/상황]`이 주어지지 않으면 기본값: **보험설계사 겸 신입 설계사 리크루팅·육성 관리자(블레스본부)**
- "단계별로", "하나씩" 이라고 하면 → 1단계만 답하고 "다음"을 기다리는 **대화형 모드**로 진행

## 7단계 진행 규칙

| 단계 | 제목 | 해야 할 일 |
|------|------|-----------|
| 1 | 핵심 설명 | 비전문가도 이해하도록 핵심만 5줄 이내. 전문 용어는 괄호로 풀이 |
| 2 | 근거 3개 + 출처 | 가장 중요한 근거 3개. 각 근거에 출처(기관·보고서·연도) 표기. 웹 검색이 가능하면 실제로 확인하고, 확인 못 한 것은 **"(미확인)"**이라고 정직하게 표시. 출처를 지어내지 않는다 |
| 3 | 가장 강한 반론 | 반대편 전문가가 할 법한 가장 날카로운 반론 1~2개와 그 근거 |
| 4 | 수정된 결론 | 반론까지 반영하면 1단계 결론이 어떻게 바뀌는지. "원래 결론 → 수정 결론" 형태 |
| 5 | 내 상황 적용 | 사용자 직업/상황에 맞춘 구체적 실행 방안 3~5개. "누가·무엇을·언제까지" 수준으로 |
| 6 | 실패 이유 3개 + 대비책 | 실행 시 실패할 수 있는 현실적인 이유 3개와 각각의 대비책 (표) |
| 7 | 최종 정리 | **표 1장**(단계별 핵심 한 줄씩) + **오늘 할 일 3개**(30분 안에 시작 가능한 것) |

## 출력 형식

```
> 가정: (있을 때만 한 줄)

## 1단계. 핵심 설명
## 2단계. 근거 3개와 출처
## 3단계. 가장 강한 반론
## 4단계. 반론을 반영한 결론
## 5단계. 내 상황에 적용하기
## 6단계. 실패 이유 3가지와 대비책
## 7단계. 한 장 요약
(표)
### ✅ 오늘 할 일 3개
1.
2.
3.
```

## 원칙

- 한국어, 서론·인사말 없이 바로 1단계부터
- 긴 내용은 표로 정리
- 모르는 것은 모른다고 쓴다. 근거·숫자·출처를 지어내지 않는다
- 마지막 줄에 "더 파고들 질문 1개"를 제안한다 (다음 딥다이브 주제)
