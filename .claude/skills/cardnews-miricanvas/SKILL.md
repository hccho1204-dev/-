# cardnews-miricanvas — 2단계: 미리캔버스에서 조립 (손 담당)

회사로 치면 **디자인팀 막내**다. 기획은 건드리지 않는다. **배운 대로, 묻지 않고, 그대로** 만든다.
HTML로 그리지 않는다 — 사람이 쓰는 디자인 툴에서 만들어야 "AI 티"가 안 난다.

## 필요 환경
- Claude Cowork (또는 Claude in Chrome / 브라우저 조작 도구가 있는 환경)
- 사용자 PC 크롬에 **미리캔버스 로그인 상태**
- `cardnews-automation/config/design-spec.md` 가 채워져 있어야 함 (비어 있으면 → 아래 "학습 모드" 먼저)

## 모드 1: 작업 모드 ("폴더 보고 작업 시작해")

### 0) 재료 점검 — 실패하면 시작하지 않는다
```
python3 cardnews-automation/scripts/check_set.py <세트폴더>
```
- `NOT READY` → 목록을 사용자에게 보여주고 멈춤. (기획 문제면 cardnews-plan, 이미지 문제면 cardnews-images로 안내)
- `READY` → 진행. 이후에는 **사용자에게 질문하지 않는다.**

### 1) 읽기
- `plan.json` → 페이지별 텍스트 (줄바꿈 `\n` = Enter)
- `images/01~09` → 번호 = 페이지 번호. **절대 순서를 추측하지 않는다.**
- `config/design-spec.md` → 템플릿 이름, 클릭 순서, 요소별 규격

### 2) 미리캔버스 작업 (design-spec.md 3번 "클릭 순서"를 그대로 따른다)
1. 크롬에서 miricanvas.com → 로그인 확인
2. 마스터 템플릿 **사본 만들기** → 이름 `카드뉴스_{set_id}` (원본 수정 금지)
3. 이미지 01~09 한 번에 업로드
4. 페이지 1~9 반복:
   - 사진 프레임에 같은 번호 이미지 교체
   - 텍스트 박스: 더블클릭 → 전체선택 → plan.json 값 입력
     - cover: label → headline → body
     - body: 장 번호("02" 형식, 템플릿에 있으면) → headline → body
     - ending: headline → cta → disclaimer(비어 있으면 박스 삭제)
   - **폰트·크기·색·위치는 템플릿 그대로.** 바꾸지 않는다.
5. 페이지마다 확인: 글자 넘침 / 자동 줄바꿈으로 조사만 떨어짐 / 사진이 글자를 가림
   - 문제 시 대처는 `references/troubleshooting.md`. 규격(크기)을 바꾸지 말고 줄바꿈 위치만 조정. 그래도 안 되면 해당 장을 "수정 필요"로 기록하고 계속 진행.
6. 다운로드: PNG, 전체 페이지, 고해상도 → 파일을 `<세트폴더>/output/`으로 이동, `01.png`~`09.png`로 이름 정리 (zip이면 풀어서)

### 3) 보고 (작업 끝나고 한 번만)
```
✅ 완료: 카드뉴스_{set_id} (미리캔버스 디자인 링크)
📁 output/01~09.png 저장
⚠️ 확인 필요: 4장 본문 3줄째 조사 떨어짐 → 줄바꿈 위치 조정함 (없으면 "없음")
👉 다음: output 확인 → 인스타 업로드 → caption.md 복사
```
그리고 `memory/topics-used.md`의 해당 줄 "업로드" 칸에 `디자인완료` 기록.

## 모드 2: 학습 모드 ("녹화 보고 design-spec 채워줘")
사용자가 미리캔버스 작업 화면 녹화(영상/스크린샷 여러 장)를 주면:
1. 녹화에서 추출: 템플릿 이름·위치, 클릭 순서, 각 텍스트 요소의 폰트/크기/굵기/색/위치/정렬, 사진 영역.
2. `config/design-spec.md`의 `✏️` 칸을 실제 값으로 교체 (✏️ 표시 삭제).
3. 요소별 **최대 글자수**는 실제 텍스트 박스 폭 ÷ 글자 크기로 추정해 채우고, `scripts/check_set.py`의 `LIMITS` 값도 똑같이 맞춘다.
4. 녹화에서 확인 못한 칸은 추측하지 말고 "확인 필요"로 남기고 사용자에게 목록으로 물어본다. (학습 모드에서만 질문 허용)

## 모드 3: 스크립트화 ("플레이라이트로 자동화 스크립트 짜줘")
`cardnews-automation/scripts/playwright/README.md` 순서대로 진행. `miricanvas_fill.py`의 `SELECTORS`와 TODO만 채운다.

## 절대 규칙
- 마스터 템플릿 원본 수정 금지 / 미리캔버스 계정 설정·결제 화면 접근 금지
- plan.json 문구를 임의로 바꾸지 않는다 (줄바꿈 위치 조정만 허용)
- 이미지 번호 ↔ 페이지 번호 1:1. 다르면 멈춘다.
- 인스타 업로드는 하지 않는다 — 최종 선택과 게시는 사람이 한다.
