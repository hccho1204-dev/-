# 미리캔버스 작업 중 문제 대처표

| 상황 | 하지 말 것 | 할 것 |
|---|---|---|
| 글자가 박스를 넘침 | 글자 크기 줄이기 | 줄바꿈 위치를 의미 단위로 앞당김 → 그래도 넘치면 "수정 필요" 기록 후 다음 장 |
| 조사 하나만 다음 줄로 떨어짐 (과부) | 그냥 두기 | 앞 어절과 함께 다음 줄로 넘기도록 Enter 위치 조정 |
| 사진이 글자를 가림 | 사진 삭제 | 사진 프레임 안에서 사진 위치(크롭)만 위/아래로 이동 |
| 사진 교체가 안 됨 (드래그 실패) | 새 사진 요소 추가 | 기존 사진 선택 → "이미지 교체" 메뉴 사용 |
| 폰트가 다른 걸로 바뀜 | 비슷한 폰트로 대체 | 텍스트 입력 전 서식 유지되는지 확인 — 전체선택 후 입력(붙여넣기 X, 붙여넣기는 서식이 바뀔 수 있음) |
| 로그인 풀림 | 비밀번호 입력 시도 | 멈추고 사용자에게 "크롬에서 미리캔버스 로그인 부탁드립니다" 요청 |
| 템플릿을 못 찾음 | 비슷한 디자인 사용 | design-spec 1번 위치 확인 → 없으면 멈추고 보고 |
| 다운로드가 zip | — | 압축 해제 후 01~09.png로 이름 정리 |
| 화면이 예전과 다름 (UI 업데이트) | 임의 클릭 반복 | 스크린샷 찍어 보고 → design-spec 3번 "클릭 순서" 갱신 제안 |
