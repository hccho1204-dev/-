# 카드뉴스 카피 공식

## 표지 후킹 공식 (hook_type 에 기록)
| hook_type | 공식 | 예시 |
|---|---|---|
| number | 숫자 + 결과 | 보험료 30% 줄인\n5가지 체크 |
| reverse | 상식 뒤집기 | 저축보다\n보험이 먼저입니다 |
| question | 찔리는 질문 | 부모님 간병비,\n누가 내나요? |
| warning | 손해 경고 | 이거 모르고\n가입하면 손해 |
| story | 1인칭 고백 | 27년 영업하며\n가장 후회한 것 |
| list | 저장 유도 | 40대가 꼭 챙길\n보험 3가지 |

- label(상단 작은 글씨): 카테고리나 시리즈명. 예) `돈 상식 #12`, `본부장 노트`
- body(서브 카피): 표지를 넘겨야 할 이유 한 줄. 예) `모르면 매달 손해 보는 이야기`

## 본문 장 흐름 (2~8장)
1. **2장 공감**: 독자의 현재 상황/고민을 그대로 말해준다. "혹시 이런 생각 해보셨나요?"
2. **3~7장 본론**: 리스트형이면 한 장에 한 항목(번호 포함). 스토리형이면 사건 → 깨달음 순서.
3. **8장 정리**: 한 줄 요약 또는 반전. "결국 핵심은 하나입니다."

## 헤드라인 규칙
- 명사형 종결 또는 짧은 단정. ✕ "~에 대해 알아보겠습니다"
- 숫자는 아라비아 숫자.
- 2줄일 때 윗줄 = 맥락, 아랫줄 = 핵심.

## 본문 규칙
- 3줄 이내, 한 줄 22자 이내.
- 1줄: 사실 / 2줄: 이유 / 3줄: 그래서 할 일.

## 마지막 장 (9장) CTA 유형
- 저장 유도: `나중에 다시 보려면\n저장해 두세요`
- 팔로우 유도: `매일 하나씩\n돈 상식 알려드립니다` + cta `팔로우하고 놓치지 마세요`
- 상담 유도: `내 보험 점검이\n궁금하다면` + cta `프로필 링크에서 무료 상담`
- 보험 상품 정보가 포함되면 disclaimer: `가입 전 상품설명서 및 약관을 반드시 확인하세요.`

## 캡션 (caption.md)
```
[첫 줄: 표지보다 한 단계 더 구체적인 후킹]

[3~5줄 요약 — 카드 내용의 핵심 3가지]

📌 저장해두고 필요할 때 꺼내 보세요
👉 @계정 팔로우하면 매일 하나씩 알려드립니다

#해시태그 15~20개 (대형 5 + 중형 7 + 소형/브랜드 5)
```
