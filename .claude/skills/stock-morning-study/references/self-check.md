# 보내기 전 자기점검 5개

모두 ✅여야 보낸다. ❌가 하나라도 있으면 고친 뒤 처음부터 다시 점검한다 (최대 3번).
결과표는 메일 맨 아래에 그대로 붙인다.

| # | 점검 항목 | 통과 기준 |
|---|---|---|
| 1 | **사실 확인** | 지수·종가·환율·금리 숫자마다 출처 링크가 있다. 2개 매체 교차 확인(아니면 "단일 출처" 표시). 날짜가 어제/오늘이 맞다. 지어낸 숫자 0개. |
| 2 | **초등학생 이해도** | 전문용어마다 괄호 풀이가 있다. 비유가 1개 이상 있다. 40자 넘는 문장이 없다. "그래서 나한테 뭐가 중요해?"에 한 줄로 답이 있다. |
| 3 | **투자 권유 금지 + 균형** | "사라/팔라/무조건/확실" 같은 말이 없다. 좋은 점과 걱정되는 점이 둘 다 있다. 레버리지·빚투를 부추기는 말이 없다. 맨 끝에 "투자 판단과 책임은 본인에게" 문구가 있다. |
| 4 | **공부 ↔ 뉴스 연결** | 오늘 강의 주제가 오늘 뉴스 1개 이상에 실제로 적용돼 있다 ("오늘 배운 걸로 뉴스 읽기" 칸). |
| 5 | **형식 완결** | 템플릿 6개 칸(한 줄 요약/공부/뉴스/연결/체크리스트/오늘의 질문)이 다 있다. 제목 형식이 맞다. 읽는 데 5분 이내(약 1,500~2,500자). 링크가 열리는 주소다. |

## 결과표 양식

```
✔ 자기점검 결과 (발송 전)
1. 사실 확인 ............ ✅  (출처 6개, 교차 확인 완료)
2. 초등학생 이해도 ...... ✅  (용어 풀이 5개, 비유: 빵집)
3. 투자 권유 금지·균형 .. ✅
4. 공부↔뉴스 연결 ....... ✅  (지배주주순이익 → LG에너지솔루션)
5. 형식 완결 ............ ✅  (약 2,100자)
```
