# 강의 원문 핵심 정리 — 김지영 (27년차 前 펀드매니저, 숙명여대 재무제표 분석 강의)

출처: CC뉴스 「들을수록 똑똑해지는」 인터뷰 (2026년 가을). 강의를 만들 때 이 문서의 말투·비유·주장을 기준으로 삼는다.

## 1. 시장을 보는 눈
- 지금은 "절망 끝 붕괴"처럼 보이지만 **여기서 크게 더 떨어진다고 보기 어렵다.** 빠지더라도 **반등을 줬다 빠지는** 게 맞다.
- 실적은 아직 괜찮다. 문제는 **살 사람이 없다(매수세 부재)**:
  - 증시 안전판인 **연기금**이 쓸 돈이 없음
  - 개인은 **레버리지 ETF** 손실·물린 주식
  - **금리·물가 상승** → 살 돈이 없음
- 살 사람이 없을 때는 헤지펀드 **공매도**(먼저 팔고 싸게 사서 갚기)에 유리한 환경.
- 삼성전자·SK하이닉스: 실적 기준 **PER 4~5배 수준으로 저평가**라고 봄.
- 시장의 걱정 3가지: ① D램 가격 상승이 계속될까(반도체는 원래 값이 내려가는 물건) ② 고객 주문 취소·지연 ③ **CXMT**(중국 메모리 회사)의 공격적 기술 추격.
- "우려가 수면 위로 올라와서 그게 전부처럼 보이는 상황" → **건전한 조정**. "버블이라고 하기엔 다들 너무 신중하다."
- AI 투자 규모: 철도 시대 GDP 5~6%, 닷컴 버블 1~2%, 지금 2% 이상. LLM 추론 다음엔 **피지컬 AI**, 국방과도 연결 → "수요↑ → 물가↑ → 금리로 잡는다" 공식이 이번엔 안 맞을 수 있다 (빌 애크먼 의견에 공감).

## 2. 왜 재무제표인가
- "재무를 안 보면 뭘 보고 투자할 거야?" 실적 = 기업가치의 대리지표, 그 바탕이 재무제표.
- 회사가 **지금 어디 있고, 어디로 가고, 무엇에 신경 쓰는지** 다 뜯어볼 수 있다.
- **ETF가 거래량 40% 이상** → 사람들이 좋아하는 주식은 더 오르고, 싫어하는 주식은 잊혀짐 → **숫자 보고 고르는 사람에겐 기회.**
- "주식을 오전에 사서 오후에 팔아 소고기 사 먹자고 하는 거 아니잖아요." 집 사듯 오래 둘 자산을 사라.
- "**제발 생각 좀 하세요.** 무시당할수록 이용당하기 쉽다."

## 3. 빵집 비유 (핵심)
- 내 돈 100원 + 은행 대출 100원 = **200원짜리 빵집**
  - 빵집 전체 = **자산** / 은행 빚 = **부채** / 내 돈 = **자본**
- 2호점: 1호점이 60%, 친구가 40% 투자 → 2호점 이익 중 **60%만 내 것**.
- 손익계산서: 매출(빵 판 돈) − 매출원가(재료) − 판관비(직원 월급·월세) = **영업이익** − 이자 − 법인세 = **당기순이익**
- 회계에선 자회사 이익을 **100% 영업이익에 잡고**, 남의 몫(40%)을 **비지배지분 순이익**으로 뺀 뒤 **지배주주순이익(60%)** 을 남긴다.
- **우리한테 오는 이익은 지배주주순이익.** 한국은 영업이익만 이야기하고, 미국은 EPS로 이야기한다.
- 사례: **LG에너지솔루션** — 영업이익·순이익은 괜찮았는데, 비지배지분 순이익은 크게 플러스, **지배주주순이익은 마이너스**였던 적이 있음.

## 4. 현금흐름
- **이익은 종이 위 숫자, 현금은 통장 잔고.**
- 외상으로 만 원 팔았는데 손님이 도망가면 그건 매출이 아니다. 안 팔린 재고도 현금이 안 된다.
- **영업활동현금흐름 − 자본적지출(CAPEX, 공장·설비) = 잉여현금흐름(FCF).**

## 5. 감가상각과 마이클 버리
- 5천만 원 차를 10년 탄다 → 매년 500만 원 비용 = **감가상각**, 10년 = **내용연수**.
- GPU 내용연수를 4년 → 6년(50% 증가)으로 바꾸면 매년 비용이 줄어 **영업이익이 커 보임**.
- 영화 「빅쇼트」의 **마이클 버리**가 "빅테크가 분식하는 것 같다"고 주장.
- 지금까진 버리가 틀린 쪽: GPU 빌려주는 값이 안 떨어지거나 오름. 최신 GPU는 학습용, 옛 GPU는 추론용으로 계속 쓰임.

## 6. 재무제표 5종과 주석
- ① 재무상태표 ② 손익계산서 ③ 현금흐름표 ④ 자본변동표 ⑤ **주석**
- IFRS는 회사에 재량을 많이 줌 → 판단 근거가 전부 **주석**에 있음. "주석에 모든 힌트가 있습니다."
- WSJ 분석: 빅테크 9곳 주석 속 **부외 약정 약 3조 달러** (장부상 부채 약 1조 달러의 3배). 돈 잘 벌면 갚으니 겁낼 필요는 없음.
- 메타 **하이페리온** 데이터센터: 축구장 1,700개 크기, 약 270억 달러. 사모신용사 **블루아울캐피털**이 특수목적법인(SPV)을 세워 채권 발행, 메타는 약 20% 지분의 파트너 겸 임차인 → 장부 어디에도 크게 안 보임.

## 7. AI 기업 자금 조달 (코어위브)
- "**말이 어렵다는 건 꿍꿍이가 있고 아름답게 보이고 싶다는 뜻**" (네오클라우드).
- 네오클라우드 = 엔비디아 GPU를 **담보로 돈을 빌려** 데이터센터를 짓는 회사.
- 걱정: ① 담보인 GPU 가치 하락 ② 고객 3곳(MS·메타·오픈AI)이 매출 70~80% 집중 ③ 무담보채 금리가 7~8% → 15%로 뜀 = 누군가 "망할 것 같다"며 던짐.
- 진짜 질문: **AI에 계속 돈을 대줄 사람이 있느냐.** 글로벌 연기금이 "분산한 줄 알았는데 묶어보니 다 AI".
- 빅테크 본체는 튼튼. 알파벳·아마존처럼 **본업이 받쳐주는 회사**와 코어위브·오라클처럼 본업이 약한 회사는 다르게 봐야 함.
- 리스크: **회사가 생각하는 시간과 투자자가 버틸 수 있는 시간이 다르다.**

## 8. 투자 조언
- 물가 상승 시대엔 예금·채권만으론 실질가치가 깎임 → **주식도 실물자산**, 어느 정도 노출은 가져가되 **장기 안목**.
- **레버리지는 웬만하면 쓰지 마라.** 빠질 때 녹아버린다.
- 주목할 주식 3가지: ① **매출·영업이익이 꾸준히 오르는** 회사(섹터 무관, 꿈보다 실적) ② **현금흐름 좋은** 회사 ③ **주주환원** 하는 회사.
- 직접 돈을 넣어 봐야 **아프면서 성숙**한다.
- "**정말 못 견딜 것 같을 때가 터닝포인트**더라." 투자에도 MBTI 같은 **기질**이 있다 → 내 기질에 맞춰 투자.
