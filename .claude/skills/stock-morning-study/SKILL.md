# stock-morning-study — 매일 아침 7시 주식 공부 + 모닝브리핑

한 통의 메일 = **① 오늘의 주식 공부 1강 + ② 모닝브리핑 뉴스 + ③ 오늘의 투자 체크 + ④ 자기점검 결과**.
읽는 사람은 **코딩·금융을 모르는 비개발자**다. 초등학교 5학년이 읽고 이해할 수 있어야 한다.

## Trigger

- "오늘 주식 공부시켜줘", "모닝브리핑 만들어줘", "오늘의 강의"
- 매일 아침 예약 작업(06:50 KST 시작 → 07:00 전후 도착)

## 전체 흐름

| 단계 | 하는 일 | 참고 파일 |
|---|---|---|
| 1 | 오늘이 며칠째 강의인지 계산 | 아래 "강의 번호 계산" |
| 2 | 커리큘럼에서 오늘 주제 꺼내기 | `references/curriculum.md` |
| 3 | 강의 원문 핵심 확인 | `references/lecture-kim-jiyoung.md` |
| 4 | 뉴스 검색 (국내·미국·환율·금리·반도체/AI) | WebSearch `mode: "extended"` |
| 5 | 템플릿대로 작성 | `references/briefing-template.md` |
| 6 | **자기점검 5개** — 하나라도 ❌면 고치고 다시 점검 | `references/self-check.md` |
| 7 | 저장 + 메일 발송 | `stock-study/briefings/YYYY-MM-DD.md`, Gmail |

## 강의 번호 계산

- 시작일: **2026-10-23 = 1강**
- `강의 번호 = ((오늘 − 2026-10-23)의 날짜 수 mod 30) + 1`
- 30강을 다 돌면 2바퀴째는 같은 주제를 **"심화편"**으로: 실제 기업 재무제표 숫자(DART 전자공시) 하나를 골라 직접 뜯어보는 실습으로 바꾼다.
- 토·일요일도 강의는 보낸다. 뉴스는 "이번 주 정리 + 다음 주 일정"으로 바꾼다.

## 쓰는 규칙 (초등학생 기준)

1. **한 문장 = 한 생각.** 40자 넘으면 나눈다.
2. **어려운 말은 바로 옆에 풀이.** 예: PER(주가수익비율 = 주가가 1년 이익의 몇 배인지).
3. **비유 1개 이상 필수.** 기본 비유는 강의 속 **"지영 빵집"**(자산·부채·자본, 지분 60:40), 자동차 감가상각(5천만 원 ÷ 10년 = 매년 500만 원), 외상 매출(돈 안 주고 도망간 손님).
4. **숫자는 단위까지.** "3.52% 내린 5,533.77" 처럼.
5. **사라/팔라 금지.** "이런 회사를 눈여겨볼 수 있다", "이런 점을 확인해 보자"까지만.
6. 좋은 점과 걱정되는 점을 **항상 같이** 쓴다 (강의: "우려는 건전하다, 돌다리도 두드려 보자").

## 뉴스 검색 방법

- 반드시 `WebSearch` 를 `mode: "extended"` 로 쓴다 (standard는 당일 뉴스가 잘 안 잡힘).
- 최소 검색 4개를 한 번에 보낸다:
  1. `코스피 마감 {어제 날짜} 증시`
  2. `뉴욕증시 마감 {어제 날짜} 나스닥 S&P500`
  3. `원달러 환율 미국채 금리 {날짜}`
  4. `반도체 AI 투자 뉴스 {날짜}` (삼성전자·SK하이닉스·엔비디아·빅테크)
- 같은 숫자가 **2개 이상 매체**에서 확인돼야 쓴다. 하나뿐이면 "(단일 출처)" 표시.
- 찾지 못한 숫자는 **절대 지어내지 말고** "확인 못 함"이라고 쓴다.
