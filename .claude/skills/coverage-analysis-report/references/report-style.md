## 표 스타일

### 공통 규칙

- **헤더행**: 배경 `#FF6B35` (블레스 오렌지), 텍스트 `#FFFFFF` (흰색), Bold
- **홀수행**: 배경 `#FFFFFF` (흰색)
- **짝수행**: 배경 `#F7FAFC` (연한 그레이)
- **구분선**: `#E2E8F0`, 0.5pt
- **셀 패딩**: 상하 4pt, 좌우 6pt

### 평가 등급 표시 (PDF)

PDF에서는 색상 배경 셀로 표시:

- **충분**: 셀 배경 `#F0FFF4`, 텍스트 `#38A169` Bold
- **보통**: 셀 배경 `#FFFFF0`, 텍스트 `#D69E2E` Bold
- **부족**: 셀 배경 `#FFF5F5`, 텍스트 `#E53E3E` Bold
- **미가입**: 셀 배경 `#F7FAFC`, 텍스트 `#A0AEC0` Bold
