### 평가 등급 표시 (PDF)

PDF에서는 이모지 대신 색상 원형 도형 또는 색상 배경 셀로 표시:

- **충분**: 셀 배경 `#E8F8F0`, 텍스트 `#2ECC71` Bold
- **보통**: 셀 배경 `#FEF9E7`, 텍스트 `#F1C40F` Bold
- **부족**: 셀 배경 `#FFF3ED`, 텍스트 `#FF6B35` Bold
- **미가입**: 셀 배경 `#FDEDEC`, 텍스트 `#E74C3C` Bold

### 우선순위 표시

| 우선순위 | 아이콘/색상 | 설명 |
|----------|-------------|------|
| 높음 | `#E74C3C` 빨간 배지 | 즉시 보완 권장 |
| 보통 | `#FF6B35` 오렌지 배지 | 여건에 따라 보완 |

## 차트/그래프 스타일

### 보장 점수 게이지

```
전체 보장 점수: 65 / 100

[████████████████████░░░░░░░░░░] 65점

0         25         50         75        100
위험      부족       보통       양호      우수
```

- 0~25: `#E74C3C`
- 26~50: `#FF6B35`
- 51~75: `#F1C40F`
- 76~100: `#2ECC71`
