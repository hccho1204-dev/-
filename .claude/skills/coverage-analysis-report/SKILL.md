# coverage-analysis-report

고객의 보험 가입 현황을 분석하여 **보장분석 리포트**를 자동 생성하는 스킬.

## Trigger

다음 키워드가 포함된 요청에 트리거:
- "보장분석"
- "보험분석"
- "보험 리포트"
- "보험 진단"
- "보장 진단"
- "보험 점검"
- "보장 현황"
- "가입 현황 분석"
- "보험 포트폴리오"

## 브랜딩

- **소속**: 블레스본부 | 인카금융서비스 VIP총괄
- **본부장**: 조홍철
- **메인 컬러**: `#FF6B35` (블레스 오렌지)
- **리포트 표지**: "보장분석 리포트 — 블레스본부 | 인카금융서비스 VIP총괄 | 본부장 조홍철"

## 프로세스 (5단계)

### 1단계: 고객 정보 수집

사용자에게 다음 정보를 순서대로 확인한다:

| 항목 | 필수 여부 | 예시 |
|------|-----------|------|
| 고객명 | 필수 | 홍길동 |
| 성별 | 필수 | 남/여 |
| 생년월일 | 필수 | 1985-03-15 |
| 직업군 | 필수 | 간호사 / 사무직 / 운전직 등 |
| 가입 보험 목록 | 필수 | 보험사, 상품명, 가입일, 주요 담보, 보험료 |
| 가족 사항 | 선택 | 배우자, 자녀 수 |
| 특이 건강 이력 | 선택 | 기존 질환, 수술 이력 |

고객 정보는 다음 JSON 형식으로 구조화한다:

```json
{
  "customer": {
    "name": "홍길동",
    "gender": "남",
    "birth_date": "1985-03-15",
    "age": 41,
    "occupation": "사무직",
    "family": {
      "spouse": true,
      "children": 2
    }
  },
  "policies": [
    {
      "insurer": "삼성생명",
      "product_name": "무배당 통합보험",
      "start_date": "2018-05-01",
      "monthly_premium": 150000,
      "coverages": [
        {"type": "사망", "amount": 100000000},
        {"type": "암진단", "amount": 30000000},
        {"type": "입원일당", "amount": 50000}
      ]
    }
  ]
}
```

### 2단계: 7대 보장영역 분석

각 영역에 대해 가입 현황을 분석하고 4단계로 평가한다.

#### 7대 보장영역

| # | 보장영역 | 핵심 항목 | 권장 기준(성인 기준) |
|---|----------|-----------|---------------------|
| 1 | 사망보장 | 일반사망, 재해사망 | 소득의 3~5년치 |
| 2 | 암보장 | 일반암, 소액암, 유사암 진단비 | 일반암 3,000만 원 이상 |
| 3 | 뇌/심장보장 | 뇌출혈, 뇌경색, 급성심근경색, 허혈성심장 | 각 3,000만 원 이상 |
| 4 | 실손보장 | 실손의료비(입원/통원) | 가입 여부 확인 |
| 5 | 후유장해 | 재해후유장해, 상해후유장해 | 1억 원 이상 |
| 6 | 입원/수술 | 입원일당, 수술비, 질병수술 | 입원일당 5만 원 이상 |
| 7 | 운전자/일상배상 | 운전자보험, 일상생활배상책임 | 가입 여부 확인 |

#### 평가 기준 (4단계)

| 등급 | 의미 | 색상 코드 |
|------|------|-----------|
| 충분 | 권장 기준 충족 | 🟢 초록 `#38A169` |
| 보통 | 권장 기준의 50~99% | 🟡 노랑 `#D69E2E` |
| 부족 | 권장 기준의 50% 미만 | 🔴 빨강 `#E53E3E` |
| 미가입 | 해당 보장 없음 | ⚪ 회색 `#A0AEC0` |

### 3단계: 리포트 구성

리포트는 다음 섹션 순서로 구성한다:

```
1. 표지
   - "보장분석 리포트"
   - 고객명, 분석일자
   - 블레스본부 | 인카금융서비스 VIP총괄 | 본부장 조홍철

2. 분석 요약
   - 전체 보장 점수 (100점 만점)
   - 7대 영역 한눈에 보기 (색상 표시)
   - 월 총 보험료
   - 핵심 코멘트 2~3줄

3. 보장영역별 현황표
   - 영역별 가입 상품, 보장금액, 평가 등급
   - 시각적 색상 표시

4. 주요 발견사항
   - 잘 갖춰진 보장 (칭찬 포인트)
   - 보완이 필요한 보장 (구체적 설명)
   - 중복 보장 여부

5. 우선순위별 개선 제안
   - 높음 / 보통 / 낮음으로 구분
   - 각 제안에 이유 설명
   - 특정 상품 직접 권유 금지 (영역과 방향만 제시)

6. 가입 상세 내역
   - 보험사별 가입 상품 전체 목록
   - 각 상품의 담보 상세

7. 면책 및 안내
   - 면책 문구
   - 상담 안내 (CTA)
   - 푸터: 블레스본부 | 인카금융서비스 VIP총괄 | 본부장 조홍철
```

### 4단계: PDF 생성

`scripts/generate_report.py` 스크립트를 사용하여 PDF를 생성한다.

```bash
python scripts/generate_report.py --input data.json --output 보장분석_홍길동_260315.pdf
```

### 5단계: 검증

생성된 리포트에 대해 아래 체크리스트를 확인한다.

## 출력 형식

- **형식**: PDF 파일
- **파일명**: `보장분석_고객명_YYMMDD.pdf` (예: `보장분석_홍길동_260315.pdf`)
- **중간 데이터**: JSON 파일로 분석 데이터 보존 (`보장분석_고객명_YYMMDD.json`)

## 필수 규칙

### 면책 문구

모든 리포트 마지막 페이지에 반드시 포함:

> 본 보장분석 리포트는 고객님께서 제공해 주신 정보를 기반으로 작성된 **참고 자료**입니다.
> 정확한 보장 내용은 반드시 **보험증권 원본**을 통해 확인하시기 바랍니다.
> 본 자료는 보험 상품의 가입을 권유하거나 특정 상품을 추천하는 것이 아닙니다.

### 금지 사항

- **특정 보험 상품 직접 권유 금지**: "A보험사의 B상품을 가입하세요" 같은 표현 불가
- **기존 보험 해지 적극 권유 금지**: "이 보험은 해지하세요" 같은 표현 불가
- 해지 관련 언급이 필요한 경우 "전문 설계사와 상담 후 결정하시길 권합니다"로 안내
- 확정적 미래 예측 금지 (보험료 인상, 보장 변경 등)

### CTA

리포트 마지막에 포함:

```
더 자세한 상담이 필요하시면 블레스본부로 연락해 주세요.
📌 카카오 오픈채팅 상담
📌 bless-insight-recruit.netlify.app
```

- [ ] 면책 문구가 포함되었는가

- [ ] 수입/보험료 관련 수치가 정확한가
- [ ] PDF 파일명이 `보장분석_고객명_YYMMDD.pdf` 형식인가
- [ ] 블레스 오렌지(#FF6B35) 메인 컬러가 적용되었는가
- [ ] CTA가 포함되었는가
- [ ] 푸터에 "블레스본부 | 인카금융서비스 VIP총괄 | 본부장 조홍철"이 포함되었는가
