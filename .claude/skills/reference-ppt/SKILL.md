# reference-ppt — 레퍼런스 디자인 + 지정 폰트로 PPT 만들기

평범한 PPT가 아니라 "사람이 만든 것 같은" 실무형 결과를 내는 게 목표.

## 준비물 3가지 (폴더에서 찾기)

| 준비물 | 찾는 법 | 없으면 |
|---|---|---|
| ① 내용 자료 | 보고서·기획서·엑셀 | 사용자에게 내용 요청 |
| ② 디자인 레퍼런스 | 파일명에 `디자인`, `레퍼런스`, `템플릿` 포함 pptx/pdf/이미지 | 깔끔한 기본 디자인(흰 배경+포인트 컬러 1개) |
| ③ 폰트 | 사용자가 준 링크(눈누 등) 또는 폰트 이름 | Pretendard |

## 실행 순서

1. **레퍼런스 분석**: 레퍼런스 PPT의 색상(HEX), 제목/본문 크기, 여백, 표지·목차·본문·마무리 장 구성, 도형 스타일을 표로 뽑는다. pptx면 슬라이드 마스터·테마를 그대로 재사용하는 것이 1순위.
2. **폰트 확인**: 링크에서 폰트 이름과 라이선스(OFL·상업용 가능 여부)를 확인. 웹폰트/파일을 받을 수 있으면 받는다.
3. **목차 설계**: 분량(기본 10장 내외)에 맞춰 장별 제목 + 핵심 메시지 1문장을 먼저 표로 보여주고 바로 제작 진행.
4. **장표 원칙**: 한 장 = 메시지 하나. 제목은 결론형 문장("매출 23% 성장") . 본문 글머리 4개 이하, 숫자는 차트/큰 숫자 강조로.
5. **저장**: `발표자료_주제.pptx`. 폰트가 없는 PC에서도 깨지지 않게 폰트 파일 동봉 안내 또는 PDF도 함께 저장.
6. **검수**: 모든 장을 이미지로 렌더링해서 글자 넘침·겹침·빈 공간을 확인하고 고친 뒤 전달.

## 인터랙티브 HTML 버전 (요청 시)

"웹으로", "HTML로", "인터랙티브", "링크로 공유" 요청이면:
- 한 파일 HTML, 키보드 ←→ / 클릭으로 장 넘김
- 마우스를 올리면 카드가 살짝 떠오르고, 장이 열릴 때 차트·도표가 0에서 채워지는 애니메이션
- 폰트는 웹폰트 링크로 연결 → 어느 PC에서 열어도 안 깨짐
- 공유 링크가 필요하면 아티팩트로 게시하고, **민감한 회사 자료는 공개 링크로 올리지 말라고** 안내
- `bless-html-slides` 스킬이 있으면 그 규칙을 함께 따른다.

## 수정 요청 처리

- 전체 톤/구성 변경 → 프롬프트로 다시 생성
- 글자 하나, 위치 조금 → "파워포인트에서 직접 고치는 게 더 빠릅니다" 라고 안내

## 프롬프트 예시

```
폴더 안에 있는 보고서를 기반으로 회사에서 발표할 때 쓸 PPT를 만들어줘.
디자인은 폴더 안에 '디자인 레퍼런스' PPT를 참고하고 분량은 10장 내외로 만들어줘.
폰트는 이걸 사용해줘: (눈누 폰트 주소)
```
```
(위와 동일) + 마우스를 대면 애니메이션이 작동하고 차트나 도표가 채워지는 인터랙티브형 발표자료로 만들어줘.
```

pptx 생성 세부 기법은 `pptx` 스킬이 있으면 함께 따른다.
