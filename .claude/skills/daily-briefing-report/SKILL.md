# daily-briefing-report — 매일 아침 자동 동향 보고서

## A. 보고서 만들기 (매 실행 시)

1. **조사 범위**: 기본 = 직전 실행 이후 ~ 지금 (처음이면 최근 24시간). 주제 키워드 + 주요 기업명으로 웹 검색, 국내/해외 각각.
2. **선별**: 중복 기사 묶기, 광고성·추측성 기사 제외, 영향도 높은 순 5~8건.
3. **보고서 양식** (`브리핑_주제_YYMMDD.docx`, A4 2장 이내):
   ```
   [주제] 데일리 브리핑 — 2026.10.07(수) 07:00 기준
   1. 오늘의 핵심 3줄
   2. 주요 뉴스 (건별: 제목 / 2~3줄 요약 / 왜 중요한가 / 출처 링크·언론사·날짜)
   3. 기업 동향 표 | 기업 | 무슨 일 | 영향(↑/↓/→) |
   4. 숫자로 보는 오늘 (주가·판매량 등 확인된 숫자만)
   5. 오늘 체크할 일정
   ```
4. **사실 규칙**: 모든 항목에 출처 링크. 확인 안 된 숫자·루머는 쓰지 않거나 "(미확인 보도)" 표기. 투자 권유 문구 금지.
5. **결과 위치**: 지정 폴더에 저장. 연결돼 있으면 Google Drive 업로드 또는 메일 초안(임시보관함)으로도 가능.

## B. 반복 예약 설정 (처음 한 번)

1. 사용자에게서 받기: 주제, 시간(기본 매일 07:00), 요일(기본 매일), 받을 곳(폴더/드라이브/메일 초안).
2. 예약(루틴/스케줄) 기능으로 등록:
   - 시간대는 한국 기준: `CRON_TZ=Asia/Seoul`
   - 매일 7시 → `CRON_TZ=Asia/Seoul 0 7 * * *` (정각 몰림 피하려면 `52 6 * * *` 같은 몇 분 전 권장)
   - 평일만 → 마지막 칸 `1-5`
   - 예약 프롬프트에는 이 스킬 이름과 주제·저장 위치를 **완결된 문장으로** 적는다 (매번 새로 시작해도 이해되게).
3. 등록 후: 첫 실행 시각, 예약 끄는 법/바꾸는 법을 안내.

## 다른 스킬과 조합

- `sns-content-creator` 와 묶으면 → 매일 아침 브리핑 + 카드뉴스 원고까지 자동 생성
- `mail-brief` 와 묶으면 → 브리핑을 팀 공유 메일 초안으로 저장

## 프롬프트 예시

```
매일 아침 7시마다 밤사이 있었던 전기차 관련 주요 뉴스와 기업 동향을 조사해줘.
그리고 조사한 내용을 A4 용지 두 장짜리 MS워드 보고서로 작성해줘.
```
