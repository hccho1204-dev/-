# 커넥터 찾기 (connector-finder)

비개발자도 따라 할 수 있게, 쉬운 방법부터 순서대로 찾는다.

## 찾는 순서 (쉬운 것 → 어려운 것)
| 순서 | 방법 | 쉬운 설명 | 난이도 |
|---|---|---|---|
| 1 | claude.ai 기본 커넥터 | 설정 → 커넥터에서 클릭 한 번 | ★ |
| 2 | MCP 서버 | Claude 전용 "플러그"를 꽂는 것 | ★★ |
| 3 | CLI | 터미널에서 쓰는 명령어 프로그램 | ★★★ |
| 4 | API | 서비스가 열어둔 데이터 창구. 열쇠(키) 필요 | ★★★★ |

## 순서
1. 사용자가 원하는 것을 한 줄로 정리한다. (예: "건축물대장에서 주소로 층수·면적 조회")
2. 이미 연결된 커넥터로 되는지 먼저 확인한다. (`ai-system/wiki/커넥터.md`, 현재 세션 도구 목록)
3. 웹 검색: `"<서비스명> MCP"`, `"<서비스명> MCP github"`, `"<서비스명> CLI"`, `"<서비스명> 오픈 API"`, 공공데이터포털.
4. 후보를 최대 3개 표로 보여준다.
   | 후보 | 종류 | 무료? | 필요한 것 | 믿을 만한가(공식/별 수/최근 업데이트) |
5. 1순위 후보의 연결 방법을 **번호 매긴 따라하기**로 안내한다. API 키는 채팅에 붙여넣지 말라고 안내하고 환경 설정에 넣게 한다.
6. 연결에 성공하면 `ai-system/wiki/커넥터.md` 표에 한 줄 추가한다.

## 주의
- 출처가 불분명한 MCP는 "공식 아님"이라고 표시한다.
- 개인정보·금융 데이터를 다루는 커넥터는 권한 범위를 꼭 설명한다.
