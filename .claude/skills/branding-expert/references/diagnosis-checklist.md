# 브랜드 진단 체크리스트 (25문항)

각 문항 0~4점. 정보가 없으면 "?"로 두고, 결과표에 "확인 필요"로 표시.
점수 기준: 0 = 전혀 아님 / 1 = 약함 / 2 = 보통 / 3 = 좋음 / 4 = 매우 분명함

## A. 사람 (법칙 1, 8) — 20점

| # | 질문 | 점수 |
|---|---|---|
| A1 | 고객을 인구통계가 아니라 **쓰는 브랜드·보는 콘텐츠**로 설명할 수 있다 | |
| A2 | 대표 페르소나 1명을 **이름·하루·주변 인물**까지 장면으로 그릴 수 있다 | |
| A3 | 고객이 우리를 쓰는 **구체적 장면 3개**를 말할 수 있다 | |
| A4 | 고객이 채우려는 감정이 **플렉스(과시)인지 남모르는 만족인지** 안다 | |
| A5 | 최근 한 달 안에 **현장에서 고객을 직접 관찰**했다 | |

## B. 사랑 (법칙 2, 3, 4) — 20점

| # | 질문 | 점수 |
|---|---|---|
| B1 | 고객이 우리를 말할 때 스펙보다 **감정·취향**을 말한다 | |
| B2 | 가격을 몰라도 **"갖고 싶다"** 는 반응이 나온다 | |
| B3 | 우리 소개 문구에 "최고 품질, 첨단 기술, 우리 회사는" 같은 **공급자 언어가 없다** | |
| B4 | 기술·기능은 **고객이 사랑하게 만드는 재료**로만 쓰인다 | |
| B5 | 우리가 없어지면 아쉬워할 **팬**이 있다 | |

## C. 포지션 (법칙 6, 9, 11) — 20점

| # | 질문 | 점수 |
|---|---|---|
| C1 | "갖고 싶은 극" 또는 "철저한 가성비 극" 중 **어디인지 분명**하다 | |
| C2 | AI에게 물으면 **한 문장으로 구분되게** 설명될 키포인트(정통/역사/디자인/가성비 등)가 있다 | |
| C3 | 벤치마크 대상이 같은 급이 아니라 **소비자가 경험한 최고 수준**이다 | |
| C4 | 소비자의 시간·관심을 다투는 **라이프스타일 경쟁자**를 정의했다 | |
| C5 | 라인업이 넓지 않고 **좁고 날카롭다** (현장 집중력) | |

## D. 경험 (법칙 5) — 20점

| # | 질문 | 점수 |
|---|---|---|
| D1 | 기본 품질(맛·성능)은 **당연히 통과**한다 | |
| D2 | **누구와 함께** 하고 싶은 브랜드/공간인가가 설계되어 있다 | |
| D3 | 고객이 **사진기를 꺼내는 순간**이 있다 | |
| D4 | SNS에 **자발적 후기**가 올라온다 (광고 없이) | |
| D5 | 부정 후기가 쌓이는 상태에서 **마케팅 예산을 늘리고 있지 않다** | |

## E. 생명력·현장 (법칙 7, 10, 현장 3질문) — 20점

| # | 질문 | 점수 |
|---|---|---|
| E1 | 잘될 때도 **꺾임 신호**를 점검하는 루틴이 있다 | |
| E2 | 실적 하락을 **외부 핑계(날씨·불경기·환율)** 로 설명하지 않는다 | |
| E3 | 우리 브랜드의 **쌓인 자산(지킬 것)** 목록이 있다 | |
| E4 | **내 물건을 팔아 줄 사람**(현장 판매자·추천자)이 누군지 알고 관리한다 | |
| E5 | **떠들어 줄 사람**(가장 강하게 공감할 집단)이 누군지 안다 | |
