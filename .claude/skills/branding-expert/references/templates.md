## §4. 신생 브랜드 런칭 계획 (법칙 11)

| 항목 | 내용 |
|---|---|
| 카테고리 (AI가 분류할 이름) | |
| 한 문장 포지션 (내로우) | |
| 극 선택 | 갖고 싶은 극 / 철저한 가성비 극 |
| "왜 아무도 안 했나?" 답변 | (법칙 12) |
| 제품 준비도 | 기본 품질 통과 여부 |
| 초기 집중 기간 | 예: 런칭 후 6~8주 총력 |
| 동원 채널 | SNS / 인플루언서 / 오프라인 / 현장 판매자 |
| 첫 확산 집단 ("떠들어 줄 사람") | 명량의 군인처럼 가장 강하게 공감할 집단 |
| 팔아 줄 사람 | 현장 판매자·추천자 |
| 하지 말 것 | 라인업 확장, 예산 분산, 완만한 성장 기대 |

**AI 추천 대비**: 고객이 AI에게 물을 질문 5개 → 그때 우리가 답으로 나오려면 필요한 키워드·후기·정보

| 고객이 AI에게 물을 질문 | 우리가 떠야 할 이유(키포인트) | 지금 부족한 것 |
|---|---|---|

## §5. 신제품 아이디어 검증 (법칙 9, 12)

| 테스트 | 질문 | 결과(통과/보류/탈락) | 메모 |
|---|---|---|---|
| 링 안 테스트 | 카테고리 이름(예: 짜장면)으로 그대로 불릴 수 있나? | | |
| 왜 없었나 테스트 | 아무도 안 한 이유가 사업성 부족은 아닌가? | | |
| 한 그릇 테스트 | 한 입이 아니라 한 개를 다 먹을까? 또 살까? | | |
| 본인 테스트 | 만든 사람은 직접 먹어 봤나/얼마나 먹겠나? | | |
| 벤치마크 테스트 | 같은 급이 아니라 최고 수준(미쉐린) 대비 몇 %인가? | | |
| 사진기 테스트 | 받았을 때 사진을 찍고 싶은가? | | |
| 관찰 근거 테스트 | 소비자 관찰에서 나온 아이디어인가, 머릿속 발명인가? | | |

종합 판정: 진행 / 수정 후 진행 / 중단 + 이유

## §6. 위기·타이밍 판단 (명량 방식)

| 단계 | 할 일 | 내용 |
|---|---|---|
| 1 | 양측 입장 정리 | 하면 생기는 위험 / 안 하면 생기는 손실 |
| 2 | 감정 반응 테스트 | 의사결정자들이 직접 보고: 아픔이 떠오르나 vs 자긍심이 차오르나 |
| 3 | 위험 요소 도려내기 | 아픔을 건드리는 대사·이미지·문구 삭제 |
| 4 | 메시지 재포커싱 | 위기를 이기는 의미로 (예: "어려울수록 뭉치는 국민") |
| 5 | 첫 확산 집단 선정 | 가장 강하게 공감할 사람들에게 먼저 |
| 6 | 성공 후 역풍 대비 | 공을 고객에게 돌리는 메시지 |
| 7 | 최종 책임자 지정 | "제가 책임지겠다" — 누가 결정하고 책임지나 |
