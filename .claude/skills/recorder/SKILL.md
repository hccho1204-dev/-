# recorder — 업무 녹화 → 스킬 자동 저장

한 번 보여주면, 다음부터는 "○○ 해줘" 한마디로 끝나게 만든다.

## 3단계 흐름

| 단계 | 사용자가 하는 일 | Claude가 하는 일 |
|---|---|---|
| ① 녹화 | 평소처럼 업무를 한 번 한다 (영상·캡처·메모 중 편한 것) | (라이브 모드면) 단계를 받아 적는다 |
| ② 요청 | "이 파일 읽고 스킬로 만들어줘" | 기록 분석 → 단계·변수·규칙 추출 → `SKILL.md` 저장 |
| ③ 시작 | "상품등록 해줘" | 저장된 스킬대로 실행 |

## Trigger

- "이 파일 읽고 스킬로 만들어줘" + 녹화 파일 첨부
- "녹화 시작" / "녹화 끝" (라이브 녹화 모드)
- "내가 하는 업무 스킬로 저장해줘", "레코더 스킬"
- `.rec`, `.mp4`, `.mov`, 스크린샷 여러 장, 단계 메모를 주며 "자동화해줘"

## 받는 녹화 형식 (아무거나 OK)

| 형식 | 예시 | 처리 방법 |
|---|---|---|
| workflow.rec (텍스트 로그) | `templates/workflow.rec` 양식 | 그대로 읽는다 |
| 화면 녹화 영상 | `.mp4` `.mov` `.webm` | `scripts/extract_frames.sh`로 장면 바뀔 때마다 캡처 → 한 장씩 본다 |
| 스크린샷 묶음 | 1.png, 2.png … | 파일명/촬영 순서대로 본다 |
| 단계 메모 | "1. 엑셀 열고 2. ..." | 그대로 읽는다 |
| 음성 메모 받아쓰기 | 녹음 텍스트 | 말버릇·잡담 걷어내고 행동만 뽑는다 |
| 라이브 녹화 | 채팅으로 "녹화 시작" → 단계 설명 → "녹화 끝" | 받아 적어 `workflow.rec`로 저장 후 ②로 넘어간다 |

## ② 요청 단계 — Claude 작업 순서 (반드시 이 순서)

### Step 1. 녹화 읽기
- 영상이면: `bash .claude/skills/recorder/scripts/extract_frames.sh <영상> <출력폴더>` 실행 후 프레임을 순서대로 Read.
  - ffmpeg가 없으면 사용자에게 "스크린샷 몇 장으로 대신 주세요"라고 안내.
- 화면 속 글자(버튼 이름, 메뉴 경로, 입력값)를 최대한 그대로 받아 적는다.

### Step 2. 단계 뽑기 — 표로 정리
각 단계를 아래 5칸으로 쪼갠다.

| # | 어디서 (앱/사이트/파일) | 무엇을 (행동) | 넣는 값 | 확인할 것 (성공 표시) |
|---|---|---|---|---|

- 같은 행동이 여러 번 반복되면 "반복 블록"으로 묶는다.
- 실수하고 되돌린 동작, 망설인 동작은 빼고 **최종 성공 경로만** 남긴다.

### Step 3. 바뀌는 값 / 고정 값 나누기
| 구분 | 의미 | 예 (상품등록) |
|---|---|---|
| **입력값(변수)** | 매번 달라지는 것 → 실행할 때 사용자에게 받는다 | 상품명, 가격, 사진 |
| **고정값(상수)** | 매번 같은 것 → 스킬에 박아 둔다 | 카테고리 경로, 배송비 정책 |
| **판단 규칙** | "이럴 땐 이렇게" | 재고 0이면 '품절' 체크 |

### Step 4. 빈칸 처리
- 녹화만으로 모르는 부분은 **질문하지 말고** 가장 그럴듯한 기본값으로 채운 뒤 `⚠️ 확인 필요` 표시.
- 단, 돈이 나가거나 / 외부에 공개되거나 / 삭제되는 단계는 스킬 안에 "실행 전 사용자 확인" 규칙을 반드시 넣는다.

### Step 5. 도구 매칭
각 단계를 Claude가 실제로 할 수 있는 방법에 연결한다.

| 단계 성격 | 연결 도구 |
|---|---|
| 웹사이트 클릭·입력 | `agent-browser` 스킬 / 브라우저 자동화 |
| 엑셀·CSV 정리 | `xlsx` 스킬, Python |
| 문서·PPT 생성 | `docx`, `pptx` 스킬 |
| 메일·캘린더·드라이브·노션·슬랙 | 연결된 커넥터(MCP) |
| 글쓰기 | 녹화 속 결과물 문체를 예시로 넣는다 |
| 도구가 없는 단계 | "사용자가 직접: ○○ 하세요" 안내 단계로 남긴다 |

### Step 6. 스킬 파일 저장
- 이름: 업무를 한글로 짧게 (예: `상품등록`). 폴더명은 영문 소문자-하이픈 (예: `product-register`).
- 저장 위치: `.claude/skills/<폴더명>/SKILL.md`
- 양식: `templates/SKILL_TEMPLATE.md`를 채운다. 원본 녹화는 `.claude/skills/<폴더명>/recording/`에 함께 보관.
- `description`에는 **사용자가 실제로 말할 문장**을 3개 이상 넣는다 (그래야 다음에 알아서 켜진다).

### Step 7. 리허설 (드라이런)
- 녹화 속 값을 그대로 넣어 스킬 순서를 머릿속으로 한 번 돌려 본다.
- 녹화 결과와 같은 결과가 나오는지 체크리스트로 확인 → 어긋나면 스킬 수정.

### Step 8. 보고 (사용자에게)
아래 형식으로 짧게.

```
✅ 스킬로 저장했어요: <스킬이름>.skill
📁 위치: .claude/skills/<폴더명>/SKILL.md

| 단계 수 | 매번 물어볼 값 | 자동 처리 | 확인 필요 |
|---|---|---|---|
| N | 상품명, 가격 | 카테고리, 배송비 | 1곳 |

▶ 이제 이렇게 말하면 됩니다: "<스킬이름> 해줘"
⚠️ 확인 필요: (있으면 1줄씩)
```

## 라이브 녹화 모드

1. 사용자가 "녹화 시작 [업무이름]" → `🔴 녹화 중: <업무이름>` 표시 후 대기.
2. 사용자가 단계를 말할 때마다 번호 붙여 `workflow.rec`에 한 줄씩 추가. 응답은 `✓ 3단계 기록` 정도로만 짧게.
3. 스크린샷이 오면 해당 단계에 첨부로 연결.
4. "녹화 끝" → 기록 전체를 표로 보여주고 곧바로 ② 요청 단계 Step 2부터 실행.

## 스킬 고치기

- "○○ 스킬 수정해줘: 3단계에서 ~" → 해당 SKILL.md만 고치고 수정 전/후를 나란히 보여준다.
- 새 녹화를 다시 주면 기존 스킬과 비교해 달라진 단계만 반영한다.

## 절대 규칙

- 비밀번호·카드번호·주민번호 등 민감정보는 스킬에 저장하지 않는다. 녹화에 보이면 `{{사용자 입력}}`으로 바꾼다.
- 녹화에 없는 단계를 지어내지 않는다. 추측은 `⚠️ 확인 필요`로 표시.
- 결제·발송·게시·삭제는 스킬 실행 중에도 반드시 사용자 확인 후 진행.
