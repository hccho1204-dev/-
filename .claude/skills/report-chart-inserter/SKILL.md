# report-chart-inserter — 보고서에 차트 자동 삽입

## 실행 순서

1. **보고서 읽기**: 문단별로 숫자가 나오는 부분(매출, 비율, 증감, 연도별 추이 등)을 찾아 목록화.
2. **차트 후보 고르기**: 숫자가 3개 이상 묶여 비교·추이가 의미 있는 곳만. 숫자 1~2개뿐이면 차트 대신 강조 박스.
3. **차트 종류 고르기**:
   | 데이터 모양 | 차트 |
   |---|---|
   | 시간에 따른 변화 | 선 그래프 |
   | 항목끼리 비교 | 가로/세로 막대 |
   | 전체 중 비중 (5개 이하) | 도넛 |
   | 목표 대비 실적 | 막대 + 목표선 |
4. **차트 만들기**: 본문 숫자를 **그대로** 사용 (반올림·추정 금지). 제목, 단위, 출처(본문 몇 쪽/표 몇) 표기. PNG 고해상도(가로 1600px 이상).
5. **삽입**: 해당 수치를 설명하는 문단 바로 아래에 넣고 `[그림 n] 제목` 캡션 추가. 문서 기존 색상 톤에 맞춤.
6. **저장**: 원본은 그대로 두고 `원본파일명_차트추가.docx` 로 저장.

## 규칙

- 본문 숫자와 차트 숫자가 하나라도 다르면 실패 — 삽입 전 대조표를 만들어 확인.
- 한 페이지에 차트 2개 이하. 장식용 차트 금지.
- 끝나면 채팅에 "몇 번째 문단 아래 → 어떤 차트" 목록을 표로 보여준다.

## 프롬프트 예시

```
폴더 속 보고서를 읽고 수치와 내용에 맞는 차트와 그래프를 만든 다음 적절한 위치에 추가해줘.
```

차트 색·형태는 `dataviz` 스킬, 워드 처리는 `docx` 스킬이 있으면 함께 따른다.
