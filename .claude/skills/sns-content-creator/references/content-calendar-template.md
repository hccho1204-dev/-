# 30일 콘텐츠 캘린더 템플릿

## 주간 믹스 비율

| 카테고리 | 비율 | 주당 게시 수 (주 5회 기준) | 목적 |
|----------|------|---------------------------|------|
| 모집 | 40% | 2회 | 설계사 리크루팅 |
| 정보 | 35% | 2회 | 전문성·신뢰 구축 |
| 브랜딩 | 25% | 1회 | 친밀감·문화 전달 |

## 요일별 기본 배정

| 요일 | 카테고리 | 형식 | 게시 시간 |
|------|----------|------|-----------|
| 월 | 정보 | 카드뉴스 | 12:00 (점심) |
| 화 | 모집 | 릴스 | 19:00 (저녁) |
| 수 | 정보 | 피드 | 07:30 (출근길) |
| 목 | 모집 | 카드뉴스/피드 | 12:00 (점심) |
| 금 | 브랜딩 | 릴스/피드 | 19:00 (저녁) |

## 게시 시간 가이드

| 콘텐츠 형식 | 최적 시간 | 이유 |
|-------------|-----------|------|
| 릴스 | 저녁 7~9시 | 퇴근 후 숏폼 탐색 시간대 |
| 카드뉴스 | 점심 12~1시 | 점심시간 정보 소비 피크 |
| 피드 (평일) | 출근길 7~8시 | 아침 피드 스크롤 시간대 |
| 피드 (저녁) | 저녁 8~10시 | 이직 고민·자기계발 시간대 |

## 편성 규칙

1. **같은 카테고리 3일 연속 금지** — 모집-모집-모집 ✗, 모집-정보-모집 ✓
2. **릴스 주 2회 이상** 필수 — 알고리즘 노출에 유리
3. 매월 **1개의 월간 테마** 설정 (예: "3월 — 봄맞이 새 시작")
4. 주제의 **30% 이상**은 월간 테마와 연결
5. 시즌 이벤트 반영 (새해, 명절, 연말정산, 자동차보험 갱신기 등)
6. 주말 게시는 선택 사항 (브랜딩 위주 라이트 콘텐츠)

## 편성 검증 체크리스트

- [ ] 같은 카테고리가 3일 연속으로 배정되지 않았는가
- [ ] 릴스가 주 2회 이상 배정되었는가
- [ ] 모집 40% / 정보 35% / 브랜딩 25% 비율이 맞는가
- [ ] 월간 테마와 연결된 주제가 30% 이상인가
- [ ] 시즌 이벤트가 반영되었는가
- [ ] 게시 시간이 형식별 최적 시간에 맞는가
