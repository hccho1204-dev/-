# 30일 콘텐츠 캘린더 템플릿

## 주간 믹스 비율

| 유형 | 비율 | 주당 게시 수 (주 5회 기준) | 목적 |
|------|------|---------------------------|------|
| 모집 | 40% | 2회 | 설계사 리크루팅 |
| 정보 | 35% | 2회 | 전문성·신뢰 구축 |
| 브랜딩 | 25% | 1회 | 친밀감·문화 전달 |

## 게시 시간 가이드

| 콘텐츠 유형 | 최적 시간 | 이유 |
|-------------|-----------|------|
| 릴스 | 저녁 7~9시 | 퇴근 후 탐색 시간대 |
| 카드뉴스 | 점심 12~1시 | 점심시간 정보 소비 |
| 피드 (모집) | 저녁 8~10시 | 이직 고민 시간대 |
| 피드 (정보) | 오전 8~9시 | 출근길 정보 탐색 |
| 피드 (브랜딩) | 오후 6~7시 | 하루 마무리 공감 시간 |

## 주간 패턴 예시

| 요일 | 유형 | 형식 | 주제 예시 |
|------|------|------|-----------|
| 월 | 정보 | 카드뉴스 | 보험 상식/팁 |
| 화 | 모집 | 릴스 | 설계사 전환 스토리 |
| 수 | 정보 | 피드 | 보험 트렌드/뉴스 |
| 목 | 모집 | 피드/카드뉴스 | 블레스본부 차별점 |
| 금 | 브랜딩 | 릴스/피드 | 팀 일상/동기부여 |

## 캘린더 출력 형식

```markdown
# 📅 YYYY년 MM월 콘텐츠 캘린더

## 1주차 (MM/DD ~ MM/DD)

| 날짜 | 요일 | 유형 | 형식 | 주제 | 게시시간 | 상태 |
|------|------|------|------|------|----------|------|
| MM/DD | 월 | 정보 | 카드뉴스 | [주제] | 12:00 | ⬜ |
| MM/DD | 화 | 모집 | 릴스 | [주제] | 19:00 | ⬜ |
| MM/DD | 수 | 정보 | 피드 | [주제] | 08:30 | ⬜ |
| MM/DD | 목 | 모집 | 카드뉴스 | [주제] | 12:00 | ⬜ |
| MM/DD | 금 | 브랜딩 | 릴스 | [주제] | 19:00 | ⬜ |

## 2주차 (MM/DD ~ MM/DD)
...

## 3주차 (MM/DD ~ MM/DD)
...

## 4주차 (MM/DD ~ MM/DD)
...

---

## 월간 요약
- 총 게시 수: __개
- 모집: __개 (40%)
- 정보: __개 (35%)
- 브랜딩: __개 (25%)
- 릴스: __개 / 카드뉴스: __개 / 피드: __개
```

## 상태 표시

| 아이콘 | 상태 |
|--------|------|
| ⬜ | 미작성 |
| 🟡 | 작성 중 |
| ✅ | 작성 완료 |
| 📤 | 게시 완료 |

## 월간 테마 설정 규칙

1. 매월 **1개의 월간 테마**를 설정 (예: "3월 - 봄맞이 새 시작")
2. 주제의 30% 이상은 월간 테마와 연결
3. 시즌 이벤트 반영 (새해, 명절, 연말 등)
4. 보험 시즌성 반영 (자동차보험 갱신기, 연말정산 등)
