# sns-content-creator

블레스본부 SNS 콘텐츠를 자동 생성하는 스킬.

## Trigger

다음 키워드가 포함된 요청에 트리거:
- "릴스 스크립트"
- "인스타 콘텐츠"
- "카드뉴스"
- "해시태그"
- "콘텐츠 캘린더"
- "SNS 콘텐츠"
- "인스타그램 글"

## 브랜드 톤

`../tistory-aeo-post/references/brand-voice.md`의 규칙을 동일하게 적용한다.
- 현실적이고 솔직한 어조
- 과장 금지
- 공감형 스토리텔링
- 금지 표현: "무조건", "반드시", "100%", "돈 벌기 쉬운" 등
- 수입 언급 시 "예시"임을 명시

## 콘텐츠 유형 (4가지)

### 1. 인스타 릴스 스크립트 (15~60초)

#### 구조

```
[HOOK - 첫 3초]
(시청자를 잡는 한 마디)

[본문 - 10~50초]
(핵심 메시지 전달)

[CTA - 마지막 5초]
(행동 유도)
```

#### HOOK 공식 (4가지 중 택1)

| 유형 | 예시 |
|------|------|
| 질문형 | "보험설계사 월급이 진짜 얼마인지 아세요?" |
| 충격형 | "간호사 퇴사하고 3개월 만에 일어난 일" |
| 공감형 | "경단녀라서 할 수 있는 게 없다고요?" |
| 반전형 | "보험설계사가 돈 못 번다고? 이건 몰랐을걸요" |

#### 출력 형식

```markdown
# 릴스 스크립트: [제목]

- 길이: 약 __초
- 유형: 모집 / 정보 / 브랜딩
- HOOK 유형: 질문형 / 충격형 / 공감형 / 반전형

---

## HOOK (0~3초)
[스크립트]

## 본문 (3~__초)
[스크립트]

## CTA (__~__초)
[스크립트]

---

## 화면 구성 메모
- HOOK: [화면 연출 아이디어]
- 본문: [자막/B-roll 아이디어]
- CTA: [팔로우 유도 화면]

## 해시태그
[references/hashtag-sets.md 참고하여 15~20개]
```

### 2. 인스타 피드 캡션

#### 구조

```markdown
# 피드 캡션: [제목]

---

[첫줄 - 호기심 유발 한 줄]

[본문 - 3~5단락]
공감 → 정보 → 인사이트 순서로 전개

[CTA]
"프로필 링크에서 더 알아보세요"
"궁금한 점은 DM 주세요"

[해시태그]
[references/hashtag-sets.md 참고하여 20~30개]
```

### 3. 카드뉴스 텍스트 (6~10장)

#### 구조

```markdown
# 카드뉴스: [제목]

- 총 장수: __장
- 유형: 모집 / 정보 / 브랜딩

---

## 1장 (표지)
**[타이틀]**
[서브타이틀]

## 2장
**[소제목]**
[본문 2~3줄]

## 3장
**[소제목]**
[본문 2~3줄]

...

## N장 (마지막 - CTA)
**블레스본부와 함께 시작하세요**
📌 카카오 오픈채팅 상담
📌 bless-insight-recruit.netlify.app

---

## 캡션
[피드에 올릴 캡션 텍스트]

## 해시태그
[20~30개]
```

#### 카드뉴스 텍스트 규칙
- 각 장 본문은 2~3줄 (모바일 가독성)
- 핵심 키워드는 **볼드** 처리
- 마지막 장은 반드시 CTA

### 4. 30일 콘텐츠 캘린더

#### 주간 믹스 비율

| 유형 | 비율 | 주당 게시 수 (주5회 기준) |
|------|------|--------------------------|
| 모집 | 40% | 2회 |
| 정보 | 35% | 2회 |
| 브랜딩 | 25% | 1회 |

#### 출력 형식

`references/content-calendar-template.md` 참고하여 30일 캘린더 생성.

## 주제 풀

### 모집 콘텐츠
- 설계사 전환 스토리
- 수입 구조 현실적 설명
- DB 지원 시스템 소개
- 블레스본부 차별점
- 합류 프로세스 안내

### 정보 콘텐츠
- 실손보험 가이드
- 암보험 체크포인트
- 자동차보험 팁
- 보험 리모델링
- 보험 용어 해설

### 브랜딩 콘텐츠
- 설계사 일상 (하루 루틴)
- 팀 활동/교육 현장
- 본부장 인사이트
- 성과 축하/팀 문화
- 동기부여 메시지

## 출력

- **형식**: 마크다운 (.md) 파일
- **파일명**: `YYMMDD-유형-키워드.md` (예: `260315-릴스-보험설계사수입.md`)
