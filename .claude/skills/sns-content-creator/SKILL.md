# sns-content-creator

블레스본부 SNS 콘텐츠를 자동 생성하는 스킬.

## Trigger

다음 키워드가 포함된 요청에 트리거:
- "릴스 스크립트"
- "인스타 콘텐츠"
- "SNS 글"
- "카드뉴스"
- "해시태그"
- "콘텐츠 캘린더"
- "숏폼 스크립트"
- "인스타 릴스"
- "인스타 피드"
- "SNS 콘텐츠"

## 브랜드 톤

- 현실적이고 솔직한 어조
- 과장 금지
- 공감형 스토리텔링
- 금지 표현: "무조건", "반드시", "100%", "돈 벌기 쉬운", "누구나 가능" 등
- 수입 언급 시 반드시 "예시"임을 명시
- `../tistory-aeo-post/references/brand-voice.md`의 규칙을 동일하게 적용

## 콘텐츠 유형 (4가지)

---

### 1. 인스타 릴스 스크립트 (15~60초)

#### 구조

```
[HOOK - 첫 3초]
시청자를 잡는 한 마디. 4가지 HOOK 공식 중 택1.

[본문 - 10~50초]
핵심 메시지 3개를 순차 전달.
각 메시지마다 화면 연출 메모 포함.

[CTA - 마지막 3~5초]
팔로우 / 댓글 / 프로필 링크 유도.
```

#### HOOK 공식 (4가지 중 택1)

| 유형 | 공식 | 예시 |
|------|------|------|
| 질문형 | "혹시 ~하고 계신가요?" | "혹시 보험설계사 수입이 얼마인지 궁금하신가요?" |
| 충격형 | "[숫자]%가 모르는 사실" | "보험 가입자 80%가 모르는 사실" |
| 공감형 | "~할 때 진짜 막막하죠" | "경력 단절되면 진짜 막막하죠" |
| 반전형 | "~? 절대 하지 마세요. 단..." | "보험설계사? 절대 하지 마세요. 단, 이것만 알면..." |

#### 출력 형식

```markdown
# 릴스 스크립트: [제목]

- 길이: 약 __초
- 카테고리: 모집 / 정보 / 브랜딩
- HOOK 유형: 질문형 / 충격형 / 공감형 / 반전형

---

## HOOK (0~3초)
[스크립트]
🎬 화면: [화면 연출 - 얼굴 클로즈업, 텍스트 오버레이 등]

## 본문 (3~__초)

### 핵심 메시지 1
[스크립트]
🎬 화면: [화면 연출]

### 핵심 메시지 2
[스크립트]
🎬 화면: [화면 연출]

### 핵심 메시지 3
[스크립트]
🎬 화면: [화면 연출]

## CTA (__~__초)
[스크립트]
🎬 화면: [팔로우 유도 화면 / 프로필 링크 안내]

---

## 캡션
[릴스와 함께 올릴 캡션 텍스트]

## 해시태그
[references/hashtag-sets.md 참고하여 15~20개]
```

---

### 2. 인스타 피드 캡션

#### 구조

```
[첫줄] - 호기심 유발 한 줄 (피드에서 "더 보기" 누르게 만드는 문장)

[본문 3~5단락]
- 줄바꿈으로 가독성 확보 (모바일 기준)
- 공감 → 정보 → 인사이트 순서로 전개
- 각 단락 사이 빈 줄 1개

[CTA]
- 댓글 유도: "궁금한 점 댓글로 남겨주세요"
- 또는 프로필 링크: "프로필 링크에서 더 알아보세요"
- 또는 저장 유도: "나중에 다시 보려면 저장해두세요"

[해시태그]
- 캡션과 줄바꿈 5줄 후 배치
- references/hashtag-sets.md 참고하여 20~30개
```

#### 출력 형식

```markdown
# 피드 캡션: [제목]

- 카테고리: 모집 / 정보 / 브랜딩

---

[첫줄 호기심 유발]

[본문 단락 1 - 공감]

[본문 단락 2 - 정보]

[본문 단락 3 - 인사이트]

[CTA]

.
.
.
.
.

[해시태그 20~30개]
```

### 3. 카드뉴스 텍스트 (6~10장)

#### 구조

```
1장 (표지): 타이틀 + 서브타이틀
2~N-1장 (본문): 슬라이드별 소제목 + 본문 2~3줄
N장 (마지막): CTA
```

#### 슬라이드 규칙

- 각 장 본문은 **2~3줄** (모바일 가독성)
- 핵심 키워드는 **볼드** 처리
- 한 장에 메시지 1개만 담기 (정보 과부하 방지)
- 표지는 호기심 유발, 마지막 장은 반드시 CTA

#### 출력 형식

```markdown
# 카드뉴스: [제목]

- 총 장수: __장
- 카테고리: 모집 / 정보 / 브랜딩

---

## 1장 (표지)
**[타이틀]**
[서브타이틀]

## 2장
**[소제목]**
[본문 2~3줄]

## 3장
**[소제목]**
[본문 2~3줄]

...

## N장 (CTA)
**블레스본부와 함께 시작하세요**
📌 카카오 오픈채팅 상담
📌 bless-insight-recruit.netlify.app

---

## 캡션
[피드에 올릴 캡션 텍스트]

## 해시태그
[20~30개]
```

### 4. 30일 콘텐츠 캘린더

#### 주간 믹스 비율

| 카테고리 | 비율 | 주당 게시 수 (주5회 기준) |
|----------|------|--------------------------|
| 모집 | 40% | 2회 |
| 정보 | 35% | 2회 |
| 브랜딩 | 25% | 1회 |

#### 요일별 형식 배정

| 요일 | 카테고리 | 형식 |
|------|----------|------|
| 월 | 정보 | 카드뉴스 |
| 화 | 모집 | 릴스 |
| 수 | 정보 | 피드 |
| 목 | 모집 | 카드뉴스/피드 |
| 금 | 브랜딩 | 릴스/피드 |

#### 편성 규칙

- **같은 카테고리 3일 연속 금지**
- **릴스 주 2회 이상** 필수
- 월간 테마 1개 설정, 30% 이상 연결
- 시즌 이벤트 반영 (명절, 연말정산 등)

#### 출력 형식

`references/content-calendar-template.md` 참고.

## 주제 풀

### A. 모집 콘텐츠 (40%)

- 설계사 전환 성공스토리 (간호사 → 설계사, 경단녀 → 설계사 등)
- 수입 구조 현실적 설명 (고정급+성과급, DB 수익 모델)
- 블레스본부 차별점 (DB 매일 제공, 1:1 멘토링, AI 도구)
- 간호사/경력단절여성 전환 사례
- DB 지원 시스템 소개 (메디컬DB, 리워드DB, 보장분석DB 등)
- 멘토링 시스템 소개
- 합류 프로세스 안내

### B. 정보 콘텐츠 (35%)

- 실손보험 세대별 차이 (1~4세대)
- 암보험 체크포인트 (일반암 vs 소액암 vs 유사암)
- 자동차보험 절약 팁
- 보험금 청구 방법 (서류, 절차, 꿀팁)
- 보험 용어 풀이 (갱신/비갱신, 순수보장/만기환급 등)
- 보장분석 필요성
- 보험 리모델링 체크리스트

### C. 브랜딩 콘텐츠 (25%)

- 블레스본부 일상 (출근 루틴, 사무실 풍경)
- 팀 활동/교육 현장
- 본부장 인사이트 (조홍철 본부장 시리즈)
- "우리가 가면 길이 됩니다" 시리즈
- 성과 축하/팀 문화
- 동기부여 메시지

## 출력

- **형식**: 마크다운 (.md) 파일
- **파일명**: `YYMMDD-유형-키워드.md` (예: `260315-릴스-보험설계사수입.md`)
