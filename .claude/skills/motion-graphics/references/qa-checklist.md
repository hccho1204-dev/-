# 2겹 검수 체크리스트

> 원칙: **만든 AI에게 "잘 만들었어?"라고 묻지 않는다.** 무조건 "네"라고 한다(자기 숙제 자기 채점).
> 검수는 제작과 분리된 서브에이전트(Agent 도구로 새로 띄움) + 스크립트가 한다.
> 감은 눈으로, 사실과 숫자는 기계로.

## 1겹 — 눈 검수 (1분)

```bash
bash .claude/skills/motion-graphics/scripts/contact_sheet.sh out/final.mp4 out/qa/sheet.png
```
영상 전체를 24장으로 뽑아 한 장에 깐다. 검수 에이전트가 이미지를 보고 아래를 체크한다.

| # | 항목 | 실패 시 |
|---|---|---|
| E1 | 실제로 없는 말을 누가 한 것처럼 써 놓았나 (가짜 인용) | 재제작 |
| E2 | 0부터 올라가는 연출 때문에 중간에 "0원" 같은 가짜값이 보이나 | 수정 |
| E3 | 진짜 로고를 찌그러뜨리거나 변형했나 | 수정 |
| E4 | 효과(글로우·블러·글리치) 때문에 자막이 안 읽히나 | 수정 |
| E5 | 휴대폰으로 봤을 때 글씨가 너무 작나 (세로 영상 기준 글자 높이 화면의 3% 미만) | 수정 |
| E6 | 1초 넘게 아무것도 안 움직이는 빈 화면이 있나 | 수정 |
| E7 | 장면 경계가 톤의 연결 방식을 따르나 (이어지기 톤에서 뚝 끊김 = PPT 느낌) | 수정 |
| E8 | 꼭 지킬 것 5개(자막 크기·출처·남의 캐릭터·진짜 로고·채널 링크) | 수정 |

## 2겹 — 숫자 검수 (기계)

### N1. 숫자 검문 (실패 = 무조건 재제작)
화면에 나온 숫자가 대본에 진짜 있는지 대조한다.
```bash
python3 .claude/skills/motion-graphics/scripts/check_numbers.py script.txt onscreen.txt
```
- `onscreen.txt`: 화면에 나오는 모든 텍스트(자막·그래픽 글자). 소스 코드/컴포지션에서 뽑거나, 콘택트시트를 보고 검수 에이전트가 받아 적는다.
- 사례: 대본에 없는 "60개"를 AI가 혼자 지어 넣은 적이 있다.

### N2~N5. 측정 + 톤 목표 비교
```bash
bash .claude/skills/motion-graphics/scripts/measure_video.sh out/final.mp4
```

| # | 항목 | 기준 |
|---|---|---|
| N2 | 소리 크기 (`loudness`) | 톤카드 목표 ±1 LUFS, 피크 -1 dBTP 이하. 감이 아니라 측정기로 |
| N3 | 밝기 (`brightness`) | 톤카드 범위 안. 예: 미니멀 UI인데 어두우면 톤 이탈 |
| N4 | 장면 속도 (`shot_sec`) | **목표의 ±30% 안** (AI는 놔두면 급해진다 — 재생성 시 평균 1.7배 빨라짐) |
| N5 | 움직임 (`motion`) | 톤카드 범위 안 |
| N6 | 멈춘 화면 (`freeze_max`) | 1초 초과 시 경고 |
| N7 | 목소리 대조 | 음성 인식 결과를 대본과 비교해 평균 일치율 0.8 이상. 미만이면 목소리 교체 (mistake-log M008) |

> 이어지기 톤은 하드컷이 없어 `shot_sec`가 영상 전체 길이로 나온다. `measure_video.sh <영상> <톤> timing.json`으로 `scene_sec_design`도 함께 본다 (M007).

## 결과 보고 양식

```
[검수 결과] <프로젝트명> / 톤 <코드>
눈 검수: E1 ✅ E2 ❌(12초 0원 노출) ...
숫자 검수: N1 ✅ / N2 -14.3 LUFS ✅ / N3 0.21 ❌(목표 0.85~0.97) / N4 1.6초 ❌(목표 2.4 ±30%) / N5 ✅ / N6 ✅
판정: 재제작 / 수정 / 통과
새 실수 → mistake-log 추가 대상: <있으면 적기>
```

## 검수 후 반드시
