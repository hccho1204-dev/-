# lemo-opuscar 윈도우·한국어 설정 메모

코드로만 영상을 만드는 클로드 코드 스킬 lemo-opuscar(MIT)를 윈도우 11에서 한국어로 돌리면서 실제로 막힌 곳과 푼 방법이에요. 2026년 10월 6일 기준, 직접 돌려 본 것만 적었어요.

## 먼저 알아 둘 것

- 공식 안내는 윈도우면 **WSL(윈도우 안의 리눅스)**을 쓰라고 해요. 아래는 WSL 없이 그냥 윈도우에서 돌린 기록이에요.
- 필요한 것: 클로드 코드(클로드 구독 또는 쓴 만큼 내는 결제 계정), Node 20 이상, ffmpeg, Python 3.11 이상 또는 uv
- 한 편에 30~60분, 클로드 사용량이 꽤 들어요(README 기준)

## 1. 설치 — 명령 창에 두 줄

```bash
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab
```

클로드 코드 채팅창이 아니라 **명령 창(터미널)**에 쳐요. 첫 사용 때 안내서·도구·스타일 설명이 `~/lemo-opuscar` 로 내려와요.

## 2. 윈도우에서 막힌 곳

### 설치 스크립트가 파이썬 패키지를 안 깔아요

설치 스크립트가 맥·리눅스식 파이썬 경로(`.venv/bin`)를 찾는데, 윈도우는 `.venv/Scripts` 예요. 라이브러리 폴더에서 직접 깔면 돼요.

```bash
cd ~/lemo-opuscar
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
uv pip install --python .venv/Scripts/python.exe faster-whisper
```

마지막 줄은 받아쓰기 검사용이에요. 영어 음성(Kokoro)은 한국어가 없어서 안 깔아도 돼요.

### 데모 소스 받기가 깃 배시에서 실패해요

깃 배시가 경로를 멋대로 바꿔서 그래요. 앞에 설정 한 줄을 붙이면 받아져요.

```bash
MSYS_NO_PATHCONV=1 sh <스킬 폴더>/scripts/setup.sh demo watercolor
```

### 데모를 직접 렌더하면 폰트가 없다고 나와요

데모가 쓰는 폰트 파일이 저장소에 안 들어 있어요. 오류에 찍힌 이름(예: Inter, JetBrains Mono, Newsreader)을 google/fonts 에서 받아 데모의 `fonts/` 폴더에 넣으면 렌더돼요.

### 받아쓰기 검사가 그래픽카드 부품(cublas)을 못 찾아요

제 경우 클로드가 알아서 CPU로 바꿔 돌렸어요. 멈추면 "받아쓰기는 CPU로 돌려"라고 알려 주세요. 45초 영상은 CPU로 충분했어요.

## 3. 한국어로 만들기

### 음성 — 기본 엔진엔 한국어가 없어요

기본 영어 음성(Kokoro)은 한국어를 지원하지 않아요. 둘 중 하나로 바꿔요.

- **무료 온라인 음성**: 라이브러리의 `tts_zh.py` 가 쓰는 edge-tts 에 한국어 목소리를 지정

```bash
.venv/Scripts/python.exe core/tts/tts_zh.py lines.json out --voice ko-KR-SunHiNeural
```

- **내 목소리 클론**: 쓰는 TTS 도구가 있으면 요청할 때 "이 도구로 음성을 만들어(출력은 <id>.wav + dur.json)"라고 알려 주면 클로드가 그걸 써요. 저는 Fish Audio 클론을 썼어요.

숫자는 읽을 문장에서 한글로 풀어 쓰라고 해 두는 게 안전해요.

### 받아쓰기 검사 — 한국어로 지정

자동 언어 감지로 돌리면 한국어를 중국어로 처리해서 전부 실패했어요. 한국어로 지정하면 통과해요.

```bash
.venv/Scripts/python.exe core/tts/asr_check.py lines.json voices --lang ko --model small
```

받아쓰기가 단어를 잘못 들으면 클로드가 문장을 바꿔 다시 만들어요. 제 경우 "오븐 문이"가 "5분 분이"로 들려서 "오븐을 열면"으로 고쳐졌어요.

### 한글 폰트

라이브러리에 한글 폰트는 없어요. 구글 폰트 CSS 주소에 `&text=` 로 쓰는 글자만 넣어 받으면 작게 받을 수 있어요(Noto Sans KR 등). 받은 파일에 확장자가 없으면 `.woff2` 를 붙여요.

## 4. 요청 예시 — 한 번 묻는 걸 미리 답해 두기

클로드는 처음에 딱 한 번 질문해요(목소리·자료·스토리보드). 미리 적어 두면 질문 없이 끝까지 가요.

```
수채화(Watercolor Brush) 스타일로 45초짜리 영상 만들어줘.
주제는 "우리 동네 작은 빵집의 하루".

미리 답해 둘게(질문 없이 바로 진행해줘):
- 언어: 한국어 나레이션 + 한국어 자막. 따뜻한 해요체.
- 목소리: (쓸 음성 도구와 명령)
- 음악·사진·로고: 내 것 없음. 가게 이름은 지어내도 됨.
- 스토리보드 확인: 필요 없음, 끝까지 만들어줘.
- 내 컴퓨터는 Windows 11. 막히면 우회하고 뭘 우회했는지 알려줘.
```
