# 톤카드 11종

> 출처: Opus로 만든 모션그래픽 영상 1,938개 수집(레딧·유튜브·X·스레드·인스타그램·깃허브) → 중복 제거 1,267개 → 같은 자로 측정(밝기·전환 속도·움직임 양·음량) → 비슷한 것끼리 묶어 11개 톤.
>
> ⚠️ **목표 숫자는 초기값**이다. 내 채널에서 잘 나온 영상을 `scripts/measure_video.sh`로 재서 그 값으로 교체할 것. 영상에서 공개된 이름은 1~5번이며, 6~11번은 초안 이름이라 실제 묶음 결과에 맞게 바꿔 쓴다.

## 톤카드 한 장의 구성

1. **결정 사항 11개** — 주인공 / 바탕색 / 강조색 / 글꼴 / 자막 위치 / 장면 길이 / 움직임 방식 / 연결 방식 / 카메라 / 소리 / 금지 사항
2. **대표작 사진 10장** — `assets/tones/<코드>/01.png ~ 10.png`. "깔끔하게"는 사람·AI마다 다르지만 사진은 안 흔들린다. (사진은 직접 모아 넣는다)
3. **목표 숫자** — 측정값. 숫자로 정해 두면 검수도 숫자로 한다.

### 목표 숫자 항목 정의 (measure_video.sh 출력과 동일)

| 항목 | 뜻 | 단위 |
|---|---|---|
| `brightness` | 화면 평균 밝기 | 0(검정)~1(흰색) |
| `shot_sec` | 장면이 바뀌는 평균 간격 | 초 |
| `motion` | 프레임 간 평균 변화량 | 0~100 |
| `loudness` | 전체 음량 | LUFS |
| `freeze_max` | 가장 길게 멈춘 화면 | 초 (1초 넘으면 경고) |

허용 범위: **`shot_sec`는 목표의 ±30% 안**(가장 중요 — AI는 놔두면 급해진다), 나머지는 표에 적힌 범위.

## T01 · 다크 네온 테크

| 결정 사항 | 내용 |
|---|---|
| 주인공 | 빛나는 선(라인)·데이터 흐름 |
| 바탕색 | #05060A 근처의 거의 검정 |
| 강조색 | 형광 1~2색(시안 #00F0FF, 마젠타 #FF2BD6) |
| 글꼴 | 고딕 계열 굵은 산세리프 + 숫자는 모노스페이스 |
| 자막 위치 | 하단 중앙, 흰색, 화면 폭 80% 이내 |
| 장면 길이 | 평균 2.0초 |
| 움직임 | 선이 그려지며 등장, 글로우 펄스 |
| 연결 방식 | **이어지기** — 앞 장면의 빛나는 선이 다음 장면의 윤곽이 된다 |
| 카메라 | 느린 줌인·패럴랙스 |
| 소리 | 신스 베이스, 전환 시 짧은 "휙" 효과음 |
| 금지 | 형광색 3색 이상 / 흰 바탕 / 글로우 때문에 자막이 번지는 것 |

목표 숫자: `brightness 0.08~0.18` · `shot_sec 2.0` · `motion 6~14` · `loudness -14±1`

## 연결 방식 요약

> 잘 만든 영상과 아쉬운 영상을 같은 톤끼리 비교했을 때 가장 일관된 차이는 **"장면을 어떻게 잇느냐"**였다(톤 9개 중 9개에서 같은 방향). 같이 나타났다는 것이지 증명은 아니다.

- **이어지기 톤**(T01·T03·T04·T05·T07·T09·T10): 장면 경계에서 무언가(선·요소·카메라·색)가 반드시 다음 장면으로 넘어가야 한다. 하드컷 금지.
- **끊기 톤**(T02·T08·T11): 끊어야 맛이 산다. 단, 아무 데서나가 아니라 **박자·단어 시간표**에 맞춰 끊는다.
- **혼합**(T06): 기본은 이어지기, 강조 단어에서만 끊기.
