# 과제지 양식 (TASK.md)

> 2단계에서 이 양식을 채워 `work/<프로젝트명>/TASK.md`로 저장한다. 제작 에이전트는 **이 파일만 보고** 끝까지 진행한다.

```markdown
# 과제지 — <프로젝트명>

## 0. 역할과 목적
- 역할: 당신은 모션 디자이너다.
- 목적(단 하나): 이 도구로만 할 수 있는 걸 보여 줘라.
- 길이: <N>초 (음성 길이와 동일)
- 화면 비율: <9:16 / 16:9 / 1:1>

## 1. 재료 (먼저 다 읽고 시작)
- 대본: ./script.txt
- 목소리: ./voice.wav
- 배경음악: ./bgm.mp3
- 단어 시간표: ./timing.json  ← 장면 경계는 반드시 이 시간에 맞춘다

## 2. 톤카드: <코드> <이름>
(references/tone-cards.md 에서 해당 카드 전체를 그대로 붙여넣기)
- 결정 사항 11개
- 대표작 사진: assets/tones/<코드>/01~10.png  ← 먼저 보고 시작
- 목표 숫자: brightness / shot_sec / motion / loudness
- 연결 방식: <이어지기 / 끊기>

## 3. 꼭 지킬 것 5개
1. 자막은 크게 (휴대폰에서 읽혀야 함)
2. 남의 자료엔 출처
3. 남의 캐릭터는 그리지 않기
4. 브랜드는 진짜 로고 (변형·찌그러뜨림 금지)
5. 마지막엔 채널 링크: <링크>

나머지는 전부 자유.

## 4. 누적 실수 규칙 (references/mistake-log.md 전부 붙여넣기)
- ...

## 5. 작업 순서
1. 기획: 시간표 기준 장면 나누기 (장면 평균 길이 = 목표 shot_sec)
2. **전환 설계 먼저** — 장면 경계마다 표 작성:
   | # | 시각(초) | 앞 장면 | 다음 장면 | 왜 이어지는가 | 무엇이 넘어가는가 |
3. 그림/애니메이션 제작
4. 렌더: ./out/final.mp4
5. 끝나면 "제작 완료"만 보고. **자기 채점 금지** — 검수는 별도로 한다.
```
