# motion-graphics — 톤카드 하네스

목표는 "AI가 영상을 만들어 준다"가 아니라 **AI에게 맡겨도 매번 비슷한 품질이 나오게 하는 것**이다.

## Trigger

- "모션그래픽 만들어줘", "모션 영상", "이 대본으로 영상"
- "톤카드", "톤 바꿔서 다시"
- "영상 검수", "영상 QA"

## 왜 이 스킬이 필요한가

| 문제 | 원인 | 해결 |
|---|---|---|
| "멋있게 만들어 줘" → 매번 다른 결과 | 메뉴판 없이 "맛있게 해 주세요"만 말함 | **톤카드** = 메뉴판 |
| 다시 돌리면 장면 전환이 평균 1.7배 빨라짐 | AI는 놔두면 급해진다 | 목표 숫자 + 숫자 검수 |
| 지시문이 길수록 더 흔들림 | 규칙 과잉 → 결과가 굳음 | 목적 1 + 필수 5 + 나머지 자유 |
| 장면은 예쁜데 PPT 넘기듯 뚝뚝 끊김 | 그림부터 그림 | **연결(전환) 설계를 그림보다 먼저** |
| 만든 AI에게 "잘됐어?" → 항상 "네" | 자기 숙제 자기 채점 | 2겹 검수, 제작 AI는 채점 금지 |

## 작업 흐름 (5단계)

### 0단계 — 톤부터 묻는다 (필수, 생략 금지)
작업을 시작하면 **가장 먼저** 사용자에게 묻는다:

> 어떤 톤으로 하시겠어요? (코드만 말씀하세요)

`references/tone-cards.md`의 11개 톤 코드 목록을 표로 보여준다. 사용자가 코드를 말하기 전에는 기획을 시작하지 않는다.

### 1단계 — 재료 준비
아래 4가지를 한 폴더(`work/<프로젝트명>/`)에 모은다. 하나라도 없으면 사용자에게 요청한다.

| 재료 | 파일 | 비고 |
|---|---|---|
| 대본 | `script.txt` | 숫자 검수의 기준 원본 |
| 목소리 | `voice.wav` / `.mp3` | |
| 배경음악 | `bgm.mp3` | |
| 단어 시간표 | `timing.json` 또는 `.srt` | "몇 초에 어떤 단어가 나오는지". 이게 있어야 화면이 말과 맞는다 |

시간표가 없으면 음성 인식(예: whisper 단어 타임스탬프)으로 만들어 `timing.json`으로 저장한다.

### 2단계 — 과제지 만들기
`references/task-sheet-template.md`를 채워 `work/<프로젝트명>/TASK.md`를 만든다. 포함할 것:
1. 고른 톤카드 전체(결정 사항 11개 · 대표작 사진 · 목표 숫자 · 연결 방식)
2. 재료 경로 4개
3. 지시: **목적 1개 + 필수 5개** (아래)
4. `references/mistake-log.md`의 누적 실수 규칙 전부

"시험 문제지처럼 이것만 보면 뭘 해야 할지 다 알 수 있게" 만든다.

### 3단계 — 자율 제작 (기획 → 전환 설계 → 그림 → 렌더)
과제지만 보고 혼자 진행한다. 순서를 지킨다:
1. **기획**: 시간표를 기준으로 장면을 나눈다. 장면 길이는 톤카드 목표 숫자를 따른다.
2. **전환 설계 (그림보다 먼저)**: 각 장면 경계마다 아래를 적는다.
   - 이 장면이 **왜** 다음 장면이 되어야 하는가 (내용상 이유)
   - 무엇이 다음 장면으로 **이어지는가** (요소·색·움직임·카메라)
   - 톤카드의 연결 방식(끊기 / 이어지기)을 따르는가
   → 연극 비유: 막을 내리고 무대를 바꾸지 말고, 배우가 걸어가는 사이 무대가 바뀌게 한다.
3. **그림/애니메이션 제작**
4. **렌더링** → `out/final.mp4`

### 4단계 — 2겹 검수 (핵심)
`references/qa-checklist.md`를 따른다. **제작한 에이전트는 채점하지 않는다** — 검수는 별도 서브에이전트(Agent 도구)나 스크립트가 한다.

- **1겹 · 눈 검수**: `scripts/contact_sheet.sh`로 영상 전체를 24장 한 장에 깔아 1분 안에 훑는다.
- **2겹 · 숫자 검수**:
  - `scripts/check_numbers.py` — 화면 숫자가 대본에 진짜 있는지 대조. 없는 숫자 = **무조건 재제작**
  - `scripts/measure_video.sh` — 밝기·장면 전환 속도·움직임 양·음량·멈춘 화면 측정 후 톤카드 목표와 비교

원칙: **감은 눈으로, 사실과 숫자는 기계로, 만든 AI는 채점 금지.**

### 5단계 — 실수를 규칙으로 (복리)
검수에서 실수가 나오면 고치고 끝내지 않는다. **`references/mistake-log.md`에 한 줄 추가**한다. 다음 과제지부터 자동으로 들어가므로 같은 실수가 다시 나오지 않는다.

## AI에게 주는 지시 (이것만 준다)

규칙을 꽉 채운 영상이 오히려 제일 별로였다(굳어 버림). 그래서 지시는 최소한으로.

**목적 1개**
> 이 도구로만 할 수 있는 걸 보여 줘라.

**꼭 지킬 것 5개**
1. 자막은 크게 (휴대폰 기준으로 읽혀야 함)
2. 남의 자료엔 출처 표기
3. 남의 캐릭터는 그리지 않기
4. 브랜드는 진짜 로고 사용 (찌그러뜨리거나 변형 금지)
5. 마지막엔 채널 링크

**나머지는 전부 자유.** 자유는 주되 방향은 톤카드로 잡는다.

## 잘 나온 프롬프트의 공통점 (톤카드에 이미 녹여 둠)

| 요소 | 예 |
|---|---|
| 길이를 숫자로 | "15초" |
| 역할 부여 | "모션 디자이너로서" |
| 장면 구성 직접 지정 | 장면 수·순서 |
| 스타일은 이름 하나로 | "볼드 플랫" |
| 소리도 요청 | 효과음·음악 |
| 하지 말 것 한 줄 | "텍스트 겹침 금지" |
| 재료 먼저 읽히기 | 대본·시간표 먼저 |

## 오늘의 세 줄 요약

1. "멋있게"라고 하지 말고 **톤카드**를 줘라 — 규칙 · 사진 · 숫자
2. 장면 전환은 효과가 아니라 **설계**다 — 그림보다 연결을 먼저
3. 검수는 **두 겹**, 그리고 **만든 AI가 채점하지 않게**
