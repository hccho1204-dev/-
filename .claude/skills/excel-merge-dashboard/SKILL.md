# excel-merge-dashboard — 폴더 속 엑셀 하나로 합치기

부서마다 양식이 다른 엑셀을 사람이 일일이 열어보지 않아도 되게, 한 파일로 합치고 한눈에 보이는 요약·차트까지 만든다.

## 실행 순서

1. **파일 찾기**: 작업 폴더에서 `*.xlsx`, `*.xls`, `*.csv` 를 모두 찾는다. 결과물(`통합_*.xlsx`)과 임시파일(`~$*`)은 제외.
2. **구조 파악**: 각 파일의 시트·헤더 행·열 이름을 읽는다. 헤더가 1행이 아닐 수 있으니 첫 10행을 확인.
3. **열 이름 맞추기(매핑)**: 같은 뜻의 다른 이름을 하나로 통일한다.
   - 예: `매출`, `매출액`, `판매금액`, `Revenue` → **매출**
   - 예: `부서`, `팀`, `소속` → **부서**
   - 애매한 매핑은 결과 파일 `매핑표` 시트에 원래 이름 → 통일 이름으로 기록.
4. **출처 열 추가**: 모든 행에 `원본파일`, `원본시트` 열을 붙인다.
5. **정리**: 숫자 열의 쉼표·원 단위 문자 제거 후 숫자로 변환, 날짜 형식 통일, 완전 빈 행 삭제.
6. **결과 파일 만들기** (`통합_YYMMDD.xlsx`, 원본과 같은 폴더):
   | 시트 | 내용 |
   |---|---|
   | 요약 | 사용자가 요청한 기준(예: 부서별 매출·주요 실적) 피벗표 + 막대/선 차트 |
   | 통합데이터 | 합친 전체 데이터 (필터·틀고정 적용) |
   | 매핑표 | 열 이름 통일 내역 |
   | 확인필요 | 숫자로 못 바꾼 값, 중복 의심 행 |
7. **서식**: 머리글 굵게+배경색, 숫자 천 단위 쉼표, 열 너비 자동, 엑셀 수식(SUM 등)은 살아있는 수식으로 넣기.

## 규칙

- **원본 파일은 절대 수정하지 않는다.** 새 파일로만 저장.
- 사용자가 기준을 안 주면 기본: 부서별 / 월별 합계 + 상위 5개 항목.
- 끝나면 채팅에 3줄 요약: 합친 파일 수, 총 행 수, 핵심 수치 1~2개 + 결과 파일 경로.

## 프롬프트 예시

```
폴더 속 엑셀 파일을 하나로 합쳐줘. 부서별 매출, 주요 실적을 쉽게 확인할 수 있게.
```

엑셀 파일 생성 세부 기법은 `xlsx` 스킬이 있으면 함께 따른다.
