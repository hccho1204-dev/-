# 우리 가족 생일 잔치 — 감성 포토 모션그래픽 (20초)

사진 5장(assets/p1~p5.jpg)으로 만든 따뜻한 생일 영상. 세로 9:16 / 가로 16:9.

| 시간 | 장면 |
|---|---|
| 0~4초 | 어둠 속 촛불이 켜짐 + 오르골 '생일 축하합니다' · "2026. 10 / 우리 집 작은 생일 잔치" |
| 4~6.7초 | 식탁 사진 · "올해도 같은 식탁에 마주 앉았습니다" |
| 6.7~10초 | 카드 읽는 사진 · "카드 한 장을 천천히, 오래 보셨지요" |
| 10~12.7초 | 박수 사진 · "촛불 앞에서 아이처럼 박수 치시던 손" |
| 12.7~16초 | 웃음 사진(클라이맥스) · "그리고, 이 웃음." "이걸 보려고 왔습니다" |
| 16~20초 | 폴라로이드 3장 + 손글씨 "사랑하는 부모님, 오래오래 건강하세요" + Happy Birthday |

## 다시 만들기
```
python3 music.py        # 음악 (90BPM 피아노·오르골, 직접 합성 → 저작권 걱정 없음)
node render.js          # out/birthday_9x16.mp4, out/birthday_16x9.mp4
node render.js storyboard
```
문구는 index.html 의 SHOTS / intro / outro 에서 바꿀 수 있습니다.
