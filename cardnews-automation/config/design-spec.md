# 미리캔버스 디자인 규격 (Cowork가 매번 이대로 작업)

> **처음 1번**: 미리캔버스에서 직접 작업하는 모습을 화면 녹화한 뒤,
> Cowork에게 "이 녹화 보고 design-spec.md 채워줘"라고 하면 자동으로 채워집니다.
> `✏️` 칸이 모두 채워져야 2단계가 안정적으로 돌아갑니다.

## 1. 템플릿
- 미리캔버스 템플릿 이름: ✏️ `카드뉴스_마스터템플릿`
- 템플릿 위치: ✏️ 내 디자인 > 폴더 `카드뉴스`
- 작업 방식: 템플릿을 **복제(사본 만들기)** 후 사본을 수정 (원본은 절대 수정 금지)
- 사본 이름 규칙: `카드뉴스_{세트폴더명}`
- 캔버스 크기: 1080 × 1350 px (인스타 4:5)
- 페이지 수: 9

## 3. 클릭 순서 (녹화에서 추출)
1. ✏️ miricanvas.com 접속 → 로그인 상태 확인
2. ✏️ 내 디자인 → `카드뉴스_마스터템플릿` → 우클릭 → 사본 만들기
3. ✏️ 사본 열기 → 좌측 메뉴 "업로드" → 내 파일 업로드 → `images/01~09.png` 한 번에 업로드
4. ✏️ 페이지 1 사진 클릭 → 업로드한 01.png 를 사진 위로 드래그(교체)
5. ✏️ 텍스트 박스 더블클릭 → 전체선택(Ctrl+A) → 새 문구 입력
6. ✏️ 2~9페이지 반복
7. ✏️ 우측 상단 "다운로드" → PNG → 전체 페이지 → 고해상도 → 다운로드
8. ✏️ 다운로드된 zip/파일을 세트 폴더 `output/`로 이동

## 4. 줄바꿈 규칙
- `plan.json`의 `\n`은 미리캔버스에서 Enter(줄바꿈)로 입력.
- 단어 중간에서 자동 줄바꿈이 생기면 → 글자 크기를 2pt씩 줄이지 말고, **문장을 줄이도록 기획으로 되돌림** (디자인 규격은 고정).
- 조사 하나만 다음 줄로 넘어가는 "과부" 금지 → 줄바꿈 위치를 의미 단위로 조정.
