# 인스타 카드뉴스 자동화 프로젝트

> 머리(기획)는 AI 세션 ①, 이미지는 AI 세션 ②, 손(디자인 조립)은 Claude Cowork가 **미리캔버스**에서.
> 나는 마지막에 **고르고 올리기만** 한다.

HTML로 만들어 이미지로 바꾸는 방식은 "AI 티"가 난다. 이 프로젝트는 **사람이 쓰는 디자인 툴(미리캔버스)을 AI가 직접 조작**해서 만든다. 그래서 폰트·줄바꿈·배치가 사람이 만든 것처럼 나온다.

---

## 한눈에 보는 흐름

| 단계 | 누가 | 무엇을 | 결과물 (세트 폴더 안) | 시간 |
|---|---|---|---|---|
| 1-A 기획 | 세션 ① (Claude 또는 Codex) | 주제 → 표지 카피·장별 헤드라인·본문 | `plan.md`, `plan.json`, `caption.md` | 5분 |
| 1-B 이미지 | 세션 ② (새 창) | 기획안 → 톤이 통일된 이미지 9장 | `image-prompts.md`, `images/01~09.png` | 5분 |
| 2 디자인 | Claude Cowork (내 PC 크롬) | 미리캔버스 템플릿에 사진+글자 끼워 넣기 | `output/01~09.png` | 자동 |
| 3 검수·업로드 | 나 | 확인 후 인스타 업로드 | — | 3분 |
| (나중) 스크립트화 | Playwright | 굳어진 2단계를 스크립트로 | — | — |

**세션을 나누는 이유:** 기획·이미지·디자인을 한 세션에서 다 하면 퀄리티가 떨어진다. 역할을 나누면 "기획은 기획대로 채택, 제작은 제작대로 검수"가 되어 매번 같은 퀄리티가 나온다.

## 폴더 구조

```
cardnews-automation/
├── README.md                ← 지금 이 파일 (사용 설명서)
├── config/
│   ├── brand.md             ← 내 계정 정보·톤·금지어 (처음 1번 채우기)
│   └── design-spec.md       ← 미리캔버스 폰트/크기/위치 (처음 1번 녹화해서 채우기)
├── memory/
│   ├── approved.md          ← 채택한 기획안 누적 (갈수록 내 취향을 학습)
│   └── topics-used.md       ← 이미 다룬 주제 (중복 방지)
├── sets/
│   └── 2026-09-24_주제/     ← 카드뉴스 1세트 = 폴더 1개
│       ├── plan.md          ← 기획안 (사람이 읽는 용)
│       ├── plan.json        ← 기획안 (AI/스크립트가 읽는 용)
│       ├── caption.md       ← 인스타 본문 + 해시태그
│       ├── image-prompts.md ← 이미지 프롬프트 9개
│       ├── images/01.png ~ 09.png   ← 번호 필수!
│       └── output/          ← 미리캔버스에서 완성본 다운로드 위치
└── scripts/
    ├── new_set.py           ← 새 세트 폴더 만들기
    ├── rename_images.py     ← 다운받은 이미지를 01~09로 자동 이름 변경
    ├── check_set.py         ← 2단계 들어가기 전 재료 점검
    └── playwright/          ← (나중 단계) 미리캔버스 자동화 스크립트 뼈대
```

## 처음 1번만 하는 준비 (약 30분)

1. **`config/brand.md` 채우기** — 계정 주제, 타깃, 톤, 금지어. (기본값이 들어 있으니 고칠 부분만 고치세요.)
2. **미리캔버스 템플릿 1개 만들기** — 9장짜리 카드뉴스 디자인을 직접 1번 만들어 둡니다. 표지 1장 + 본문 7장 + 마지막 1장. 이름은 `카드뉴스_마스터템플릿`.
3. **작업 녹화 → 스킬 학습** — 미리캔버스에서 사진 바꾸고 글자 바꾸는 과정을 화면 녹화하고, Cowork에게 이렇게 말합니다:
   > "이 녹화 영상 보고 `cardnews-automation/config/design-spec.md` 채워줘. 폰트, 글자 크기, 위치, 클릭 순서까지."
4. **컴퓨터에 이 폴더 두기** — Cowork가 읽을 수 있도록 내 PC에 이 저장소를 받아 둡니다 (GitHub Desktop → Clone, 또는 Cowork에서 폴더 연결).

## 매일 루틴 (따라하기)

### 1단계-A: 기획 (세션 ①)
Claude(또는 Codex) 새 대화에서:
```
/cardnews-plan 오늘 주제: 40대 경력단절 여성이 보험설계사 시작할 때 현실
```
주제가 없으면:
```
/cardnews-plan 오늘 주제 3개 추천해줘
```
→ `sets/날짜_주제/` 폴더에 `plan.md`, `plan.json`, `caption.md`가 저장됩니다.
→ 어색한 문장만 살짝 고치고 "채택"이라고 말하면 `memory/approved.md`에 쌓입니다.

### 1단계-B: 이미지 (세션 ② — 반드시 새 창)
```
/cardnews-images sets/2026-09-24_경력단절-설계사-현실
```
→ 9장 공통 스타일로 프롬프트 9개를 만들고, 연결된 이미지 생성 도구가 있으면 바로 생성합니다.
→ 도구가 없으면 `image-prompts.md`의 프롬프트를 ChatGPT/Gemini에 **순서대로** 붙여 넣어 생성 → 다운받은 뒤:
```
python3 cardnews-automation/scripts/rename_images.py sets/2026-09-24_경력단절-설계사-현실 ~/Downloads
```
→ 최신 9장이 `images/01.png ~ 09.png`로 자동 정리됩니다.

### 2단계: 디자인 (Claude Cowork)
Cowork에서 딱 한 마디:
```
/cardnews-miricanvas sets/2026-09-24_경력단절-설계사-현실 폴더 보고 작업 시작해
```
→ 재료 점검 → 크롬 → 미리캔버스 → 템플릿 복제 → 사진·표지 카피·헤드라인·본문 입력 → 9장 PNG 다운로드 → `output/`에 저장.
→ 이 시간엔 다른 일 하셔도 됩니다.

### 3단계: 검수·업로드 (나)
`output/` 9장 확인 → 인스타 앱에서 캐러셀 업로드 → `caption.md` 복사해서 붙여넣기.

### 한 번에 돌리기
```
/cardnews-daily
```
오늘 할 일을 순서대로 안내하고, 어디까지 됐는지 체크해 줍니다.

## 다음 단계 (나중에, 작업이 완전히 굳으면)

Cowork가 매번 화면을 보면서 하는 것보다, 스크립트로 굳히면 훨씬 빠르고 가볍습니다.
Cowork에게 이렇게만 말하면 됩니다:
> "이 미리캔버스 작업, Playwright로 자동화 스크립트 짜줘. `scripts/playwright/miricanvas_fill.py` 뼈대 채워서."

자세한 내용은 `scripts/playwright/README.md` 참고.

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| Cowork가 사진 순서를 헷갈림 | 파일명이 `01.png`~`09.png`인지 확인 → `check_set.py` 실행 |
| 글자가 넘쳐서 줄이 이상함 | `config/design-spec.md`의 "장당 최대 글자수"를 줄이고 기획 다시 |
| 이미지 톤이 장마다 다름 | 이미지는 **한 세션에서 9장 연속** 생성. 중간에 새 창 열지 않기 |
| 미리캔버스 로그인 풀림 | Cowork 쓰는 크롬에 미리 로그인해 두기 |
| 매번 비슷한 주제 | `memory/topics-used.md` 확인 — 기획 스킬이 자동으로 피합니다 |
