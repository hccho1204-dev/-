# 간호조무사 리크루팅 영상 (20초)

치위생사 버전(`recruit-dental`)과 같은 **스카우트 톤**입니다. 힘든 점 대신 "당신의 경력이 필요합니다 → 경력으로 인정합니다"를 전달합니다.

- **문구 출처**: 블로그 글 「간호조무사 이직 추천 직업, 보험설계사가 답인 이유」(실손·진단비·수술비 설명, 의료 용어와 약관 이해, 환자 응대 경험)
- **음악**: 120 BPM, 정확히 20초, 처음부터 밝게 → 8초에 터짐 (직접 합성, 상업적 사용 가능)
- **비율**: 세로 9:16 (주력), 가로 16:9
- **주의**: 수입 약속·투잡·매일 DB 문구 없음

## 스토리보드

| 시간 | 장면 | 내용 |
|---|---|---|
| 0~4초 | WANTED | WANTED 글자 배경 + 구인 카드 · 의료 십자 배지 · **병원을 아는 사람** |
| 4~8초 | 필요한 이유 | **간호조무사님, 당신의 경력이 필요합니다** · "실손·진단비 상담은 병원을 아는 사람이 제일 잘하니까" |
| 8~11초 | 경력 인정 | 병원에서 보낸 1 → 3 → 5 → **10** YEARS · 그 시간, 그대로 **경력으로 인정합니다** |
| 11~14초 | 경력 매칭 | 의료 지식 → 보험 설명 전문성 / 의료 용어 익숙함 → 빠른 약관 이해 / 환자 응대 경험 → 상담 능력 |
| 14~16초 | 지원 | 병원 경력 그대로 인정 · 1:1 전담 멘토링 · AI 자동화 도구 |
| 16~20초 | 행동 | **간호조무사 경력자 상담 받습니다** · @incarvip_bless DM 주세요 |
