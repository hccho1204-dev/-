골라서 바로 붙이기

API는 다른 서비스의 기능을 빌려 쓰는 창구예요. 날씨, 환율, 공휴일 같은 정보를 내 홈페이지에 띄울 수 있죠. 여기서 먼저 눌러 보고, 마음에 들면 Claude 프롬프트 복사를 눌러 Claude에게 붙여넣으세요.

바로 써보기 12개

키(가입) 없이 바로 되는 것만 골랐어요. 가게 홈페이지, 블로그, 사내 화면에 바로 붙일 만한 것들이에요. 예시 데이터 표시는 이 화면에서 실제 호출이 막혀 저장된 응답을 보여준다는 뜻이에요. 파일로 열면 실시간으로 바뀝니다.

전체 목록에서 찾기

원하는 기능을 한글이나 영어로 검색하세요. 예: 날씨, 번역, 영화, food, crypto. 처음에는 가입 없이 쓰는 것만 보여줘요.

Claude에게 붙이는 3단계

1. 고르기위에서 눌러 보고 쓸 만한 API를 고릅니다. "가입·키 없이"가 제일 쉬워요.
2. 프롬프트 복사"Claude 프롬프트 복사"를 누르면 API 주소, 조건, 요청사항이 다 들어간 글이 복사돼요.
3. 붙여넣기Claude 대화창에 붙여넣고 "우리 카페 홈페이지에" 처럼 한 줄만 덧붙이세요. HTML 파일이 바로 나옵니다.
