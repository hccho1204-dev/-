# 광교오후학교 × 블레스50플러스 — 코믹 반전 홍보 숏폼

- 파일: `gwanggyo_promo_shorts.mp4` (세로 1080x1920, 60초, 배경음·효과음 포함)
- 용도: 유튜브 쇼츠 / 인스타 릴스 / 틱톡 홍보 후킹 영상

## 구성
| 시간 | 장면 |
|---|---|
| 0~3초 | 후킹: "비 오는 밤, 20년 만에 나타난 남자 / 그가 기다린 진짜 이유는...?" |
| 3~30초 | 애절한 피아노 + 비 + 멜로 대사 (명조체 자막) |
| 30~33초 | 반전: "차를 빼줘야 내가 나가지." (노란 큰 자막) |
| 33~41초 | 음악 뚝 → 카메라 빠지며 이중주차 공개, 부재중 전화 18통, 사이드 ON |
| 41~53초 | 남편 등장 → 얼굴 굳음 → 와이퍼 끼익 + 슬픈 트롬본 |
| 53~60초 | 엔딩: "차는 못 빼드려도, 인생 2막 길은 열어드립니다!" 광교오후학교 with 블레스50플러스, 문의 유도 |

## 문구 바꿔서 다시 만들기
`make_video.py` 안의 `SUBS`(대사), `DIRS`(지문), `render_end`(엔딩 문구)를 고친 뒤:
```
pip install pillow numpy imageio-ffmpeg
python3 make_video.py
```
